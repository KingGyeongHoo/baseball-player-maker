# 프로 누적 시즌평가와 계약

게임용 밸런스이며 실제 프로 규정이나 연봉을 나타내지 않는다. 상수는 `lib/sim/pro-contract-rules.ts`에서 관리한다.

## 평가 체계

공통 OVR은 능력치 요약이다. 고교 평판은 기존 방식으로 유지한다. 프로 평판은 폐지하고 출전평가·당해 시즌평가·누적 평가만 사용한다. 국대·WBC 선발은 대상 시즌 1군 기록을 반영한 출전평가를 사용하며 WBC는 전년도 기록으로 평가한다. 이적 심사의 기존 평판 비중도 출전평가로 대체한다. 이전 저장의 프로 평판·보너스는 불러올 때 비활성화하며 고교 평가 이력·확정 시즌평가·계약은 보존한다.

프로 이벤트의 과거 평판 보상은 작은 야구 지능 성장으로 전환한다. 올스타 선발·미스터 올스타는 각각 야구 지능 3주·2주 훈련분을 한 번 지급한다. 점수에 이벤트 보너스를 직접 더하지 않는다. 스카우팅의 프로 평판·툴 20~80·보직 적합도 숫자·실험용 비교점수는 표시하지 않는다.

## 현재 출전평가

`clamp(보직 기량 + 7 × (시즌 성과 × 85% + 최근 성과 × 15%) - 신고선수 6점 - 관리 기간 12점, 0, 100)`

- 시즌 성과: 타자는 시즌 OPS, 투수는 시즌 삼진·볼넷·홈런 비율과 ERA를 함께 사용한다. 1군·2군 기록을 분리하고, 타자 100타석·투수 120BF의 사전 표본으로 적은 출전의 영향을 줄인다. 고정 게임 기준은 OPS .720, 투구 핵심 비율 .130, ERA 4.00이다. 포지션의 주력 투타 분야만 사용한다.
- 2군 성과는 65% 비중으로 반영하며 1군 근거가 쌓일수록 줄인다. 시즌 성과의 보정은 최대 ±5.95점이다. WAR의 2군 35% 환산과는 다른 용도다.
- 최근 성과: 기존 최근 50타석·60아웃(20이닝) 창의 보정 성적을 사용한다. 표준편차 1 이내의 변화는 무시하고 표본이 적으면 영향을 줄인다. 극단적인 호·부진도 최대 ±1.05점이다. 별도 화면 점수로 표시하지 않는다.
- 피로 감점은 없으며 부상·강제 휴식·투수 휴식일·교체 제한은 별도로 유지한다.
- 1·2군 등록은 같은 현재 포지션의 현재 출전평가를 직접 비교한다. 더 높은 2군 선수에게 별도의 기량 8점 차이·성적 표본·누적평가 추가 격차를 요구하지 않는다. 14일 심사·이동 후 14일 제한·출전 가능 상태·정원·FA 주전 보장을 적용한다. 작은 성적 표본은 점수 계산에서 이미 보정하므로 등록 심사에서 다시 막지 않는다.

## 시즌 평가

시즌평가는 **WAR 기반**으로 당해 시즌 기록만 사용한다. 현재 출전평가(기량·시즌 중심 성적)와 구분한다. 타격·투구·수비·실제 포지션 기여를 게임용 WAR로 계산하고, 역할·리그 수준을 환산한 WAR를 `71 + 2 × 환산 WAR`로 기존 0~100점과 F~S 등급에 맞춘다. 예를 들어 환산 WAR 1.5는 74점, 5.5는 82점이다. [산식과 제한](pro-war-assessment.md)을 따른다.

선수 목록·프로필·선발·승격의 출전평가는 같은 산식을 사용한다. 계약 화면의 시즌평가·예상 누적 평가는 WAR 환산을 사용하고 능력치·피로·최근 성적을 직접 더하지 않는다. 건강한 무출전 선수의 0 WAR는 71점이며, 적은 기록을 풀 시즌으로 확대하지 않는다. 2군은 자체 환경에서 계산하고 35%로 반영하며 기여 상한은 환산 2승이다. 1군 출전량이 늘수록 2군 비중을 줄인다.

수비는 새로 시작하는 경기부터 개인별 처리 기회·성공·기대 성공과 실제 포지션 아웃을 기록한다. 과거에 없던 수비 기록을 소급해 만들지 않는다. 주루 세부 기여·실책·병살·포수 프레이밍은 포함하지 않는다. 이미 확정된 시즌 평가·체결 계약·급여·제안 조건은 바꾸지 않는다. 새 시즌 결산은 한 번만 저장하며 재시도·불러오기로 덮어쓰지 않는다.

누적 평가는 유효한 모든 시즌 점수의 산술 평균이다. 프로 입단 전 고교 시즌은 넣지 않는다. 한 시즌 내내 부상으로 활동 불가이고 실제 타격·투구 기록도 없다면 미평가로 보관하고 평균에서 제외한다. 단순 무출전의 건강한 선수는 0 WAR의 환산 점수로 평가한다. 무소속 시즌도 미평가다.

기존 저장은 실제로 보관된 완료 프로 시즌만 복원한다. 1군 출전경기수는 완료 경기 원본 또는 중복이 없는 기록 합계에서만 복원한다. 시즌 종료 관찰 점수가 있으면 우선 사용하고, 없으면 당시 보관 능력으로 재구성해 ‘과거 자료 복원’이라고 표시한다. 존재하지 않는 과거 시즌이나 정밀한 소속 일수는 만들지 않는다. 과거 소속은 보관된 시즌 종료 소속을 사용한다.

## 연봉

기준 점수 = 올해 평가 × 70% + 누적 평균 × 30%. 첫 평가 전에는 현재 기록의 WAR 환산 점수를 사용한다. 올해가 미평가이면 누적 평균을 사용하며, 누적 자료도 없으면 현재 기록의 WAR 환산 점수를 사용한다. 실제 제안에는 예산과 신분·재협상을 적용한다.

정식 신인 기준은 5,000만 원, 신고선수는 3,000만 원이다. 아래 기준점 사이를 선형 보간하고 10만 원 단위로 내림한다. 일반 제안의 상한은 10억 원이며 75점 이상이면 1회 재협상에서 예산 내 8% 인상이 가능하다. 신고 재영입은 인상하지 않는다.

| 기준 점수 | 일반 기준 연봉 |
| --- | ---: |
| 65 이하 | 5,000만 원 |
| 71 | 6,000만 원 |
| 73 | 9,000만 원 |
| 75 | 1억 4,000만 원 |
| 77 | 2억 2,500만 원 |
| 79 | 3억 5,000만 원 |
| 81 | 5억 원 |
| 85 | 7억 원 |
| 100 이상 | 10억 원 |

FA도 같은 기준으로 가격을 산정하며 77점 미만은 1년, 그 이상은 나이·구단 예산에 따라 2~4년이다. 기존 체결 계약·급여 구간·누적 수령액은 소급 변경하지 않는다. 구버전의 미수락 시장 제안만 새 규칙으로 다시 계산한다.

## 방출과 재계약 불가

- 잔류군·신고선수 3시즌 연속: 시즌 결산에서 방출한다. 일별 하위 소속이 과반이거나 시즌 종료까지 하위 소속이면 지속으로 본다. 1·2군 28일 이상과 20타석 또는 9아웃의 실제 출전이 있으면 해당 시즌은 탈출로 인정한다. 잠깐 등록만 바꿔도 지속 기간이 지워지지는 않는다.
- 1군 출전 부족: 1군 정규 시즌 출전이 한 해 20경기 이하인 상태가 3~5개 활동 시즌 지속되면 방출한다. 0~20경기는 해당하고 21경기 이상이면 이 조건의 연속 기간을 끊는다. 등록 일수·승격 통보만으로는 끊지 않는다. 완료 경기의 실제 타격·투구·수비 출전을 세며, 같은 경기 투타 겸업은 1경기다. 트레이드 전후 1군 기록을 합치고 2군·포스트시즌·미완료 경기·몰수 경기는 제외한다.
- 신인 유예 후 누적 저평가: 프로 입단 연도부터 최초 3시즌을 통째로 제외한 나머지 유효한 시즌 점수의 산술 평균으로 별도의 재계약 판정용 누적 평가를 만든다. 이 평균이 E/F인 상태가 3~5개 평가 시즌 지속되면 방출한다. 4년차 첫 평가부터 연속 기간을 세므로 이 조건만으로는 빨라도 6년차 결산에 적용된다. 첫 3년의 좋거나 나쁜 점수는 이 평균에 넣지 않는다. D 이상으로 누적 평균이 회복되면 이 조건의 기간을 끊는다. 현재 한 해 점수만 D로 올라도 누적이 E/F이면 유지된다. 연봉·FA용 전체 누적 평균은 처음부터 모든 유효한 프로 시즌을 반영한다.
- 위 두 조건은 따로 센다. 하나라도 충족하면 방출하며 두 조건의 기간을 더하지 않는다. 기본 4시즌, 33세 이상 또는 역할 능력이 전년 대비 2점 넘게 하락하면 3시즌, 25세 이하이고 전년 대비 역할 능력이 0.5 이상 성장하면 5시즌까지 유예한다. 시즌 전체 부상으로 미평가인 시즌은 횟수를 늘리지 않고 판정을 보류한다. 연도 기록이 누락되면 연속 기간을 끊는다. 옛 기록에서 출전경기수를 알 수 없으면 0경기로 꾸미지 않고 출전 부족 조건의 기간을 끊는다. 과거 투타 경기 합계만 있고 중복 경기수를 복원할 수 없는 경우도 미상으로 둔다.
- 판정은 플레이어와 NPC 모두 적용한다. 최소 포지션 확보 규칙으로 의무 방출을 무효화하지 않는다. 이번 시즌 급여를 정산한 뒤 방출하며 잔여 보장액은 기존 보장액·구단 비용 이력에 남긴다.

## 타 구단 신고 재영입

정식 재계약 불가 선수는 다른 구단의 1년 신고 계약만 검토한다. 32세 이하·현재 역할 기량 45 이상을 기본 조건으로 하고, 어린 나이·성장·포지션 부족이 재영입 가능성을 높인다. 시드 기반 판정으로 같은 제안 시점의 조회·새로고침이 결과를 재추첨하지 않는다. 구단 정원과 예산도 충족해야 한다.

계약은 신고 연봉 3,000만 원·1년이며 기존 정식 전환 조건을 달성하면 전환일부터 정식 급여를 적용한다. 해당 연도 종료까지 전환에 실패하면 방출한다. 성공적으로 전환한 시즌은 이전 잔류 연속 기간을 끊고 다음 시즌부터 출전 부족·누적 저평가의 지속 기간도 새로 센다. 재계약 판정용 누적 평균과 연봉용 전체 누적 평균의 과거 점수는 지우지 않는다. 방출 이력과 시즌 평가 자체는 계속 보관한다.

## 표시와 자동 진행

선수 목록의 점수·등급·정렬은 고교에서 평판, 프로에서 출전평가를 사용한다. 프로 계약 화면에는 올해 평가·누적 평균·평가 기반 연봉·시즌 이력·재계약 판정과 신고 재영입 기한을 표시한다.

자동 진행 중 이벤트 선택과 결과 확인은 직접 처리한다. 확인이 끝나면 켜져 있던 자동 진행을 이어가고 직접 일시정지한 상태는 유지한다. 선택 창에는 일시정지 버튼이나 자동 재개 안내 문구를 넣지 않는다. 일시정지는 하단 진행 도구에서 사용한다. 시즌·드래프트 종료와 계산 오류는 자동 진행을 끈다.

## 등록 심사와 누적 평가

현재 출전평가가 높은 2군 선수가 같은 포지션의 1군 선수보다 우선한다. 이전의 누적 등급별 추가 격차와 기량·성적 표본 허들은 더 이상 승격 조건으로 사용하지 않는다. 누적 평가는 계약·연봉·은퇴 평가에 유지하고 등록 판단에서는 동점 우선순위와 잉여 인원 조정에 참고한다. FA 주전·보직 보장은 계약 기간 동안 해당 군 이상의 등록과 실제 기용 우선권을 보장한다. [선수단 규칙](pro-squads.md), [FA 이행 규칙](pro-farm-and-fa.md)을 따른다.

## FA 원소속팀 잔류

FA 시장은 원소속팀 잔류와 타 구단 이적을 모두 제공한다. 원소속팀이 예산·정원·계약 제한을 충족하면 잔류 제안 1개를 먼저 표시하고, 나머지 자리에 타 구단 제안을 넣어 전체 3개 이내로 비교한다. 시장 갱신도 같은 기준을 사용한다. 구단 예산이 부족하거나 정식 재계약이 제한된 선수에게 잔류안을 강제로 만들지는 않는다.

화면은 FA 잔류/이적 제안과 수락 버튼을 구분한다. 잔류도 FA 연봉·기간·1회 재협상 규칙을 사용한다. 수락하면 소속과 기존 재직 이력·경기 기록·급여 이력을 유지하고, 이동 이력에는 같은 구단의 FA 잔류로 보관한다. 제안의 잔류 여부는 저장되며 구버전 제안도 기존 계약 구단을 기준으로 표시할 수 있다. 이미 체결한 계약이나 저장된 최종 조건을 불러오기만으로 다시 계산하지 않는다.

33세부터 타 구단의 FA 관심 기준은 50점에서 나이 한 살당 1점씩 높아지며 추가분은 최대 16점이다. 기량과 성적이 충분하면 고령 선수도 일반 FA 제안을 받는다. 33세 이상 FA에게 타 구단 제안이 하나도 없으면 원소속팀은 기량 45 이상·구단 관심 40 이상·예산과 정원 충족 여부로 마지막 제안을 검토한다. 조건은 1년·정식 선수 최저 연봉(5,000만 원), 재협상 불가다. 선수는 이 계약을 수락하거나 은퇴하며, 기다리기나 무소속 훈련으로 우회하지 않는다. 원소속팀 제안도 없으면 즉시 은퇴한다. 젊은 선수의 기존 계약 탐색·무소속 재도전 흐름은 유지한다.

## 영구결번

은퇴 시 입단·재직·이동 이력에 구단이 하나뿐이고 누적 시즌 평가 등급이 S이면 해당 구단이 마지막 등번호를 영구결번으로 등록한다. 1·2·3군과 육성선수는 같은 구단으로 취급한다. 누적 평가는 기존 유효 시즌 점수 평균과 동일한 S 경계(소수 첫째 자리로 반올림한 점수 81 초과)를 사용하며, 현재 능력치나 마지막 시즌 점수만으로 판단하지 않는다. 별도의 최소 재직 시즌 조건은 없다.

은퇴 화면과 커리어 개인 수상 내역에 표시하고, 해당 구단 모든 군의 등번호 배정·선택·이적 및 신인 합류에서 이 번호를 제외한다. NPC 은퇴에도 같은 기준을 적용하며 선수 상세가 정리된 뒤에도 구단의 영구결번 기록은 저장한다.

## 은퇴 대시보드

상단은 고교·대학·프로 1·2군·포스트시즌을 합산한 야구인생 통산 기록이다. 선수생활의 발자취는 입학·지명 또는 입단·첫 1군 기록·첫 올스타·첫 수상·국가대표·FA 잔류와 이적·트레이드·은퇴를 날짜순으로 표시한다. 직접 프로로 시작한 선수에게 고교 입학이나 드래프트를 추가하지 않으며 발생하지 않은 기록은 생략한다. 정확한 날짜가 남지 않은 지명·선발 이력은 연도만 표시한다.

하단은 올스타 선정, 개인 수상, 시즌 MVP, 국가대표 발탁 횟수다. 올스타·대표 선발과 MVP를 구분하고, 시즌 MVP는 개인 수상 수에서 제외한다. 개인 수상에는 골든글러브·기록 타이틀·미스터 올스타와 대표팀 MVP를 포함하며 영구결번은 별도로 표시한다. 중복 보관된 같은 수상은 한 번만 센다. 청소년 대표는 발자취의 ‘첫 청소년대표 발탁’으로 구분하고, 국가대표 발탁 횟수와 ‘첫 국가대표 발탁’은 성인 대표·WBC만 사용한다.
