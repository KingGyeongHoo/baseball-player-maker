# 프로 기록 밸런스

프로 경기의 타석 확률, 선수 생성 분포, 타순과 휴식일, 투수 운용을 조정한다. 고교·대학의 타석 확률 설정은 유지한다. 기록을 시즌 말에 덮어쓰거나 최대·최소 수치로 잘라내지 않는다.

## 목표와 표본

`lib/sim/pro-balance.ts`의 `proSeasonTargets`가 합의한 목표를 보관한다.

- 타자 평균은 100타석 이상 선수별 시즌 기록, 최고 타율·OPS는 446타석 이상이다.
- 타율·OPS·ERA 평균은 합산 분모로 계산한다. 안타·홈런·타점·승패·홀드·세이브 평균은 선수별 산술평균이다.
- 최저 ERA는 144이닝 이상, 평균 ERA는 30이닝 이상이다.
- 선발 승패 비교는 20회 이상 선발 등판, 마무리 평균은 각 팀의 주전 마무리 대상이다. 중계는 RP 포지션의 30이닝 이상 선수다.
- 최고 안타 185~205개, 홈런 35~55개, 타점 118~158개. 평균은 각각 75~85개, 7~11개, 36~44개다.
- 최고 타율 .350~.380, 평균 .260~.280. 최고 OPS .978~1.138, 평균 .710~.770.
- 최저 ERA 1.3~1.8, 평균 3.9~4.2. 선발 최다승 17~23, 평균승 9~12, 최다패 13~17, 평균패 6~9.
- 중계 최다 홀드 32~41, 평균 5~8. 주전 마무리 최다 세이브 31~37, 평균 20~28.
- 이닝은 중심값 없이 ±5만 제안됐으므로 역할별 목표를 임의로 확정하지 않았다. 소화 이닝은 검증 결과에 표시한다.

## 동작

프로 전용 확률은 타격과 투구의 능력 차이를 반영한다. 삼진은 아웃 중 조건부 확률이며 안타·볼넷 확률과 혼동하지 않는다. 스카우팅 예상 기록도 같은 프로 설정을 사용하고, 기존 저장 데이터의 이전 평가 기준은 새 기준으로 갱신한다.

프로 세계를 새로 생성할 때 NPC의 주력 능력에 선수별 공통 편차와 개별 능력 편차를 함께 적용한다. 기존 저장 선수의 능력치를 다시 배정하지 않는다. 기존 세이브에서도 이후 경기에는 새 확률과 운용이 적용되며, 이미 완료한 경기 기록은 보존된다.

야수는 능력과 시드·날짜에 따른 휴식일에 실제 벤치 선수로 교체한다. 쉬게 한 주전은 그날 다른 수비 자리에 다시 투입하지 않는다. 중심 타자 셋은 중심 타순에 배치한다.

투수 운용 v2는 정규시즌에서 휴식을 충족한 선발 중 실제 선발 등판 수가 적은 선수를 우선한다. 월요일 휴식 뒤에도 같은 에이스만 반복해서 나오는 현상을 줄이며, 포스트시즌은 기존 능력 우선 선발을 유지한다. 선발 교체는 스태미나·당일 편차·점수 차를 반영한다. 동점에서는 5이닝 이후 불펜을 우선하고, 앞서는 선발은 더 맡긴다.

주전·대체 마무리, 셋업맨, 필승조의 이른 연결 등판, 여섯 번째 선발의 긴 구원 등판을 구분한다. 대체 마무리는 주전 마무리의 등판일에 2이닝 연결을 맡을 수 있다. 불펜 선택에는 전날 등판과 누적 투구량을 반영하고, 구단별 시드·날짜로 역할을 배분한다. 긴 구원 담당 선발은 2일, 다른 선발은 3일 이상의 온전한 휴식을 확보한다. 교체 가능한 투수가 없으면 휴식 기준을 완화해 비상 등판한다. 경기당 투구 한도를 넘기는 교체를 반복해 통계상 홀드만 나누는 방식은 쓰지 않는다.

## 재현과 검증

`npm run test:pro-balance`는 능력의 영향, 시드 재현, 적법한 수비 명단, 실제 기록 보존, 다중 시드 720경기 시즌을 검증한다.

`npm run test:compile` 다음 `node scripts/pro-balance.mjs`를 실행한다. PowerShell에서 `$env:PRO_BALANCE_SEEDS='10'`으로 시즌 수를 지정할 수 있다. 보고서는 `outputs/pro-balance/latest.json`에 목표, 시즌별 관측 범위, 목표 충족 시즌 수와 개별 결과를 저장한다. `PRO_BALANCE_START`로 시작 시드 번호, `PRO_BALANCE_REPORT`로 별도 보고서 이름을 지정할 수 있다. 예를 들어 시작 10·시즌 수 5·이름 validation은 추가 5시즌을 `validation.json`에 기록한다.

이는 1군 720경기 일정과 일일 NPC 피로 정책을 사용하는 고정 능력·고정 명단 검증이다. 성장·부상·승강·트레이드·노화는 제외하므로 전체 커리어 검증과 구분한다. 매 경기 안타·삼진·득점 대응과 승패 합계도 검사한다.

v2 최종 검증은 조정에 사용한 시드 0~9와 추가 시드 10~14, 총 15시즌·10,800경기를 사용했다. 시즌별 지표를 평균한 결과는 다음과 같다.

| 항목 | 결과 | 목표 |
| --- | ---: | ---: |
| 중계 평균 홀드 | 7.23 | 5~8 |
| 시즌 최다 홀드 | 모든 시즌 32~39 | 32~41 |
| 주전 선발 평균 승 | 9.33 | 9~12 |
| 주전 선발 평균 패 | 8.94 | 6~9 |
| 투수 합산 ERA의 시즌 평균 | 4.12 | 3.9~4.2 |

개별 시즌의 모든 지표를 강제로 맞추지는 않는다. 일부 시즌의 안타·타점·최저 ERA·선발 최다 패·세이브가 범위를 벗어나는 결과도 보고서에 그대로 표시한다. 특히 위 평균값이 모든 개별 시즌의 목표 충족을 뜻하지 않는다. 선수 성장과 등록 변동을 포함한 장기 커리어의 기록 분포는 별도 검증 범위다.
