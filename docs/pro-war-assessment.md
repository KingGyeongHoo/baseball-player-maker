# WAR를 기존 출전평가 점수로 환산

출전평가 자체를 경기 기록 기반 WAR로 계산한다. 기존 능력 점수에 WAR를 더하거나 혼합하지 않는다. 이름과 기존 0~100점·F~S 등급은 유지하며, 선수 목록·프로필·올해 예상 누적 평가·시즌 결산은 같은 환산 점수를 사용한다.

## 점수와 의사결정

`출전평가 = clamp(71 + 2 × 환산 WAR, 0, 100)`

| 환산 WAR | 출전평가 | 등급 |
| ---: | ---: | --- |
| -5.5 | 60 | F |
| 0 | 71 | E |
| 1.5 | 74 | D |
| 2 | 75 | C |
| 4 | 79 | A |
| 5.5 | 82 | S |

능력치·피로·평판·최근 성적·신고 신분을 이 점수에 직접 더하지 않는다. **능력치는 실제 경기 결과와 별도의 기량·컨디션 기반 선발·승격 판단에 계속 사용한다.** 높은 능력은 더 좋은 결과를 낼 확률을 높이고, 기록으로 남은 결과가 WAR가 된다. 출전 기회가 없어 WAR를 못 쌓았다는 이유만으로 승격을 봉쇄하지 않는다.

시즌 결산 점수의 산술 평균이 누적 출전평가다. 연봉·FA의 올해 70%·누적 30%, 장기 재계약 판정과 누적 평가에 따른 잔류 보호는 기존 구조를 유지한다. 전 시즌 부상·무소속은 미평가이며, 건강한 무출전은 0 WAR에 해당하는 71점이다. 적은 기록을 풀 시즌으로 확대하지 않는다.

## 경기 기록과 리그 기준

당해 `seasonByLevel.first/second` 정규 기록을 군별로 사용한다. 트레이드 전후는 선수 시즌 합계를 한 번만 사용하고, 승리·타점·팀 순위·과거 시즌·포스트시즌·올스타를 정규 WAR에 더하지 않는다. 리그 환경은 프로 선수 기록과 해당 연도 은퇴 보존 합계로 만든다. 시즌 결산에서 한 번 계산해 플레이어와 NPC에 같은 기준을 적용한다.

시즌 초에는 600타석의 가중 출루율 0.320, 180이닝의 FIP 핵심항 0.9·ERA 4.0을 사전 표본으로 혼합한다. 실제 기록이 쌓이면 해당 리그의 환경을 따른다. 승리당 득점은 `1.5 × 리그 ERA + 4`를 8~12로 제한한다.

## 타격·투구 WAR

```text
가중 출루 합계 = 0.69 BB + 0.89 단타 + 1.27 2B + 1.62 3B + 2.10 HR
타격 평균 대비 득점 = (가중 출루 합계 - 리그 가중 출루율 × PA) / 1.2
타격 대체 수준 가산 = 20 × PA / 600
타격 WAR = (평균 대비 득점 + 대체 수준 가산) / 승리당 득점

IP = outs / 3
리그 FIP 핵심항 = (13 HR + 3 BB - 2 SO) / 리그 IP
FIP 방어 득점 = (리그 FIP 핵심항 × 선수 IP - (13 HR + 3 BB - 2 SO)) / 9
ERA 방어 득점 = 리그 ERA × 선수 IP / 9 - 선수 ER
투구 대체 수준 가산 = IP / 9
투구 WAR = (0.7 × FIP 방어 득점 + 0.3 × ERA 방어 득점 + 대체 수준 가산) / 승리당 득점
```

기존 게임이 기록하는 사건만 사용한다. 사구가 없으므로 FIP 사구 항은 없다. 무아웃 강판도 실제 볼넷·홈런·자책점을 음수 기여로 계산한다. 실제 기록과 역할 규모를 함께 비교하기 위해 점수 환산 시 구원의 투구 WAR만 3배로 정규화한다(60이닝 구원과 180이닝 선발 기준). 원시 WAR 표시에는 이 배수를 적용하지 않는다. 투타 겸업은 실제 타격·투구 기여를 합친다.

## 수비 기여와 포지션

새 프로 경기에는 `fieldingVersion: 1`을 넣고 개인별 `fielding` 기록을 수집한다. 타석별 시드로 수비 담당 야수를 배정하고 그 야수의 실제 유효 수비 능력으로 안타 확률을 계산한다. 추가 경기 난수는 소비하지 않는다. 야수가 막을 수 없는 볼넷·홈런·삼진을 제외한 타구만 수비 기회로 기록하고, 아웃 처리 성공과 동일 타자·투수·상황에서 기준 수비수의 기대 처리 확률을 누적한다. 포수는 뜬공 처리만 포함하며 프레이밍·도루 저지·송구 보살·실책은 따로 구현하지 않는다.

```text
리그 기회당 처리 차이 = 리그 (실제 처리 - 기대 처리) / (리그 기회 + 사전 표본 500)
수비 득점 = (실제 처리 - 기대 처리 - 리그 기회당 처리 차이 × 개인 기회) × 0.75
수비 WAR = 수비 득점 / 승리당 득점
```

모든 실제 수비 아웃 시점의 출전 위치를 누적한다. 포지션 보정은 4,050아웃(150경기)당 포수 +12.5, 유격수 +7.5, 중견수·2루수·3루수 +2.5, 좌·우익수 -7.5, 1루수 -12.5, DH -17.5득점이다. 여러 포지션은 실제 해당 위치 아웃으로 배분한다. DH에는 수비 기회·성공을 부여하지 않고 역할 보정만 적용한다. 투수에게 야수 포지션 보정을 중복 적용하지 않는다.

수비·포지션 기록은 완료 경기만 시즌·군별·구단별·통산 합계에 반영한다. 몰수 경기의 미완료 수비 기록은 폐기한다. 기존 저장에서 기록이 없던 경기·기간에는 수비 WAR·포지션을 소급 추정하지 않는다. 구버전에서 진행 중이던 경기는 기존 경기 계산을 마친 뒤 다음 새 경기부터 수집한다. 주루 세부 기여는 아직 포함하지 않는다.

## 1군·2군 환산

1군은 `타격 WAR + 역할 보정 투구 WAR + 수비 WAR + 포지션 WAR`를 사용한다. 2군은 자체 리그 환경에서 같은 항목을 계산한 뒤 35%로 반영하며, 양의 기여는 환산 2승으로 제한한다. 1군 출전량이 600타석 또는 선발 540아웃·구원 180아웃에 가까워질수록 2군 비중을 줄이고, 해당 규모를 채우면 2군 기여를 더하지 않는다. 2군 성적만으로 1군 스타급 평가를 만들지 않는다.

## 저장·검증·범위

새 시즌 평가에 군별 타격·투구·수비·포지션 WAR, 실제 표본과 환산 WAR·점수를 고정한다. 확정된 과거 평가·체결 계약·급여·저장된 제안 조건은 소급 변경하지 않는다. 과거 평가에 WAR가 없으면 당시 점수를 보존하며 가상의 WAR를 복원하지 않는다. 저장·불러오기·재결산으로 확정 값을 다시 계산하지 않는다.

`tests/pro-war.test.mjs`는 타자·선발·구원·겸업, 능력치와 환산 점수의 분리, 수비·포지션·실제 경기 수비 집계, 적은 출전, 군별 기준, 은퇴 합계, NPC 동일 적용, 계약·누적 연결, 저장 호환·UI를 검증한다.

이는 공식 fWAR/bWAR·KBO WAR가 아닌 **게임용 WAR 추정치**다. 가중치·역할 환산·대체 수준·포지션 기준은 게임 밸런스 상수다. 개념 근거: [FanGraphs 타자 WAR](https://library.fangraphs.com/war/war-position-players/), [FanGraphs 투수 WAR](https://library.fangraphs.com/war/calculating-war-pitchers/). 실제 기록에 없는 고급 수비·주루 데이터를 만들어 넣지 않는다.
