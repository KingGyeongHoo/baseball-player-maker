## 1. 목표와 범위

프로 이벤트는 **실력을 키우고, 출전 기회를 만들고, 자신에게 맞는 역할로 커리어를 이어가는 선택**을 다룬다. 신고선수·2군·1군 후보·주전·베테랑에게 같은 사건이 같은 빈도로 나오지 않게 한다.

야구 훈련, 동료·코치·분석 담당자와의 야구 활동, 경기, 몸 관리, 보직, 포스트시즌, 성인 대표팀과 함께 가족·팬·동료의 일상·취미도 소재로 한다. 금전 소비나 연애 시스템은 추가하지 않는다. 실제 구단·리그의 제도를 재현하는 문서가 아니라 게임용 사건 설계다.

### 2026-11-10 확장

기본 카탈로그는 75종·선택 행동 163개다. 2026-11-11 재편으로 야구 68종·일상 7종이며, 일반 주간 이벤트는 두 분류의 적격 후보가 있으면 야구 90%·일상 10%를 먼저 추첨한다. [재편 목록과 실제 추첨](event-catalog-composition.md)을 참고한다. 기존 PE01–PE30에 추가된 PE31–PE75를 전부 단일 사건으로 새로 작성했다. 레그킥·이중 키킹·스플리터·커터·스위퍼·태그업·러닝 송구 등 실제 훈련 동작을 다룬다. 실제 선택·결과·확률은 `lib/sim/pro-event-catalog.json`에 기록한다.

PE46–PE52, PE61–PE67, PE75도 과거 선택 없이 독립적으로 발생한다. 원인 사건·경과일·같은 팀을 요구하던 후속 연결과 후속 후보 우선 추첨을 제거했다. 야구 분류 안에서 투수는 구속·제구·변화구를 각각 26⅔%, 타자는 컨택·파워·스피드·수비를 각각 20%로 먼저 추첨한다. 나머지는 피지컬 10%·야구 지능 10%다. 정해진 주제 안에서 기존 주요 캠프·보직 사건의 우선순위를 적용한다. 추가 야구 사건은 투수 핵심 능력별 6개·타자 핵심 능력별 4개로 맞췄다. 적격 후보가 없는 주제의 확률은 가능한 주제에 비례 재분배한다.

이후 기존분까지 재배분해 지능 중심 사건은 PE58·PE71의 2개만 남겼다. PE12·PE19·PE25·PE26·PE27·PE29·PE30은 구속부터 수비까지 각 능력에 하나씩 옮겼다. 출전 요청·포스트시즌·대표팀·보직 평가 기능은 유지하고 공용 사건의 동작·보상·실제 추첨 주제는 선수 분야에 맞춰 해석한다. [현행 전체 개수와 재배분 목록](event-catalog-composition.md)을 따르며 아래 과거 원안의 지능 보상·행동 문구보다 JSON 카탈로그가 우선한다.

추가 사건도 일반 사건의 주간 35%·최소 14일 간격·시즌 12회 한도를 공유한다. 새 채널이나 추가 성장 횟수를 만들지 않는다. 생활 사건은 대부분 자기 팀의 경기 없는 날에 나오며, 이동·원정 소재는 이틀 안에 예정된 원정 경기가 있어야 한다. 부상·강제 휴식 중에는 기존 복귀·휴식 사건을 사용한다. 훈련 사건은 실제 훈련 배분과 포지션을 확인한다.

새 결과는 실제 능력 성장·적응 손실·피로 변화·회복으로 표현한다. 기술별 성공률과 피로가 다르며, 아무런 변화가 없는 새 결과는 두지 않는다. 기술 보상은 기존 성장·각성 규칙을 사용한다. 사적인 초대를 거절해도 출전평가를 깎지 않는다. 저장된 미선택 사건과 선택 기록은 그대로 이어간다.

**현행 일상:** 7종만 유지하며 휴식·수면·가족·친구의 안부 중심이다. 새 훈련 사건은 실제 훈련일과 타격·투구·수비 자격을 확인한다. 포수·내야·외야 전용 동작도 실제 수비 자격을 확인한다.

## 2. 선택 화면과 공통 규칙

### 2.1 선택 전과 선택 후

- 한 사건에는 **선택지 2개 또는 3개**를 둔다.
- 선택 전에는 상황과 행동 문구만 보여준다. 효과 수치·분기 확률·각성 가능성·추천 색상·성공 예고를 표시하지 않는다. 툴팁과 접근성 문구도 같다.
- 선택 후 기본 결과를 한 번 추첨하고, 각성 대상이면 공통 각성 판정을 한 번 한다. 결과 문구와 **실제 적용된 변화량**을 보여준다.
- 이벤트가 열리면 자동 진행을 멈춘다. 선택·결과 확인 후에는 사용자가 진행을 재개한다. 같은 결과를 클릭·불러오기·탭 이동으로 다시 추첨하지 않는다.
- 출전 신분·부상 상태·계약의 연봉과 기간 같은 기존 공개 규칙은 감추지 않는다. 새 보직의 이름과 14일 평가 과정도 행동의 내용이므로 설명할 수 있다. 숨기는 것은 능력 보상과 확률형 결과다.
- 경기 중 결과 문구는 준비나 접근의 결과를 설명한다. 아직 계산하지 않은 안타·홈런·삼진·승패를 미리 확정해서 쓰지 않는다.

예시:

> **배트의 무게 중심**  
> 장비 담당자가 지금보다 무게 중심이 다른 배트를 권했다. 타격 훈련에서 시험해볼까?  
> [다른 배트를 시험한다] [익숙한 배트를 유지한다]

선택 후에는 “스윙 궤도가 자연스럽게 이어졌다.”와 실제 컨택·피로 변화, 각성 여부 등을 보여준다. 문서의 효과 표는 설계용이며 선택 전에 화면에 노출하지 않는다.

### 2.2 결과 표의 해석

모든 사건 표는 `선택 | 확률 | 결과 문구 | 효과` 순서다. **확률은 해당 선택을 골랐을 때의 조건부 확률**이며 선택별 합계는 100%다. 같은 선택 이름의 여러 행은 서로 배타적인 결과다.

100% 결과도 허용한다. 요청 전달·평가 시작처럼 행동 자체가 확정되는 선택에 실패 추첨을 억지로 붙이지 않는다. 평가 시작과 실제 승격·주전 확보는 구분한다.

### 2.3 기본 대상과 제외 조건

- 기본 대상은 `careerMode=pro`, 현역, 구단 소속, 진행 가능한 상태의 선수다. 신규 사건은 대학 커리어에 노출하지 않는다.
- 무소속 선수는 구단 코치·동료·경기 전제가 맞지 않으므로 이번 30종에서 제외한다. 무소속 훈련과 구직은 기존 흐름을 따른다.
- 훈련 사건은 활동 가능하고 실제 훈련일이며 티켓을 하나 이상 사용한 경우만 후보가 된다. 경기·휴식·복귀·대표팀 사건에는 이 조건을 일괄 적용하지 않는다.
- 부상 결장 중에는 PE18만 별도 후보가 될 수 있다. PE18도 허용된 영상·몸 관리만 다룬다. 강제 휴식 중에는 PE19의 회복 중심 사건만 허용한다.
- 이름이 필요한 코치·동료·경쟁자는 현재 구단 정보에서 정한다. 존재하지 않는 동료나 이적한 경쟁자를 현재 팀원처럼 등장시키지 않는다.
- 겸업의 타격·투구 전용 사건은 해당 분야를 기준으로 보상을 계산한다. 보직 전환 PE09·PE10·PE11·PE29는 겸업 선수를 제외하고 기존 프로 겸업 심사 흐름을 따른다.

## 3. 성장·평판·피로·경기 효과

### 3.1 영구 능력 보상

`컨택 +3주분`은 **현재 선수에게 컨택 티켓 5개를 배분한 정상 훈련 3주에 해당하는 컨택 증가량**이다. 일반 보상은 3~4주분, 큰 성과는 6주분, 캠프 대성공은 8주분을 쓴다.

- 선택 직전 상태를 기준으로 현행 훈련 보상 함수처럼 일별 성장 둔화를 반영한다. 주간 증가량에 단순히 주수를 곱하지 않는다.
- 해당 분야 재능·나이 효율·신고선수 90%를 각각 한 번 적용한다. 일반 능력치는 1~100 범위를 유지한다.
- 피지컬의 스태미나·회복력·어깨는 피지컬 티켓 5개를 세 능력으로 나누는 현행 성장량, 야구 지능은 현행 자연 성장량을 기준으로 삼는다.
- 여러 능력에 각각 주수를 적으면 각 능력이 그 주수만큼 오른다. 동일 능력이 별칭을 통해 중복 지정되면 한 번만 처리한다.
- 시간을 건너뛰거나 가상의 훈련 일수만큼 피로·노화·재능 노출량을 추가하지 않는다. 피로는 표에 적힌 변화만 별도로 적용한다.
- 기술 보상에 사용한 티켓 5개는 기준량이다. 실제 플레이어의 훈련 배분을 바꾸거나 티켓을 소비하지 않는다.
- 이미 제거한 약한·보통·강한 훈련 강도나 총 티켓 예산을 다시 도입하지 않는다. [현행 훈련](training.md)을 우선한다.

| 별칭 | 대상 능력 |
| --- | --- |
| 정교함 | 타격 분야는 컨택, 투구 분야는 제구 |
| 힘 | 타격 분야는 파워, 투구 분야는 구속 |
| 주 분야 핵심 | 타자 컨택·파워·스피드·수비 / 투수 구속·제구·변화구 |
| 약점 | 해당 분야 핵심 중 가장 낮은 능력 |
| 강점 | 해당 분야 핵심 중 가장 높은 능력 |
| 투구 약점 | 구속·제구·변화구 중 가장 낮은 능력 |
| 타격 약점 | 컨택·파워·스피드·수비 중 가장 낮은 능력 |

별칭은 사건을 열 때 고정한다. 동점은 위 목록의 순서로 정한다. 일반적인 주 분야 사건은 현재 주 역할, 경기 중 사건은 실제 투타 역할을 사용한다. 겸업 전용 PE14는 각 선택의 타격·투구 분야를 명시한다.

### 3.2 공통 각성

양수 영구 능력 보상이 있는 **확정된 기본 결과 전체에 한 번만** 5% 각성·95% 원래 효과를 적용한다. 능력마다 따로 추첨하지 않는다.

```text
각성 주수 = min(12, 기본 보상 주수 × 2)
3주 → 6주 / 4주 → 8주 / 6주·8주 → 12주
각성 최소 상승량 = 3 × (100 - 선택 직전 능력치) / 40
최종 상승량 = min(100 - 현재 능력치, max(기본 보상, 각성 주수 훈련량, 각성 최소 상승량))
```

각성은 기본 능력 보상을 대체한다. 피로·평판·부상·요청·경기 보정은 원래 결과대로 적용하며 각성을 다시 추첨하지 않는다. 경기 보정·피로 회복·평판·보직 평가만 있는 결과에는 각성이 없다. 5% 캠프 대성공에 각성이 동시에 나올 확률은 0.25%다.

2026-11-09 조정: 능력치 60에서 최소 +3, 80에서 +1.5, 90에서 +0.75다. 야구 지능·피지컬도 같은 최소분을 적용하며 최소분은 재능·나이·신고선수 배율로 줄이지 않는다. 훈련 환산 부분은 현행 배율을 적용한다. 확정한 과거 기록은 유지하고 이후 해결하는 사건부터 적용한다.

각성 문구는 [공통 이벤트 문서](baseball-events.md)의 “정교한 타격에 눈을 떴다!” 등 해당 능력 문구를 쓴다. 능력 상한에서 실제 증가가 0이면 올랐다고 표시하지 않는다.

### 3.3 평판·피로·부상

- `평판 +N`은 프로 이벤트 보정값에 N을 더한다는 뜻이다. 현재 프로 보정의 ±10 한도와 최종 평판 0~100 한도를 유지한다. 능력·실적의 변화까지 반영한 최종 평판 차이는 결과 화면에 따로 계산한다. 현재 평판식은 [평판 문서](reputation-evaluation.md)를 따른다.
- 동료와 연습했다거나 코치 제안을 거절했다는 이유만으로 대외 평판을 매번 올리거나 깎지 않는다. 이번 카탈로그의 직접 평판 보상은 대표팀 성과처럼 맥락이 있는 사건에 집중한다.
- 피로 `+`는 누적, `-`는 회복이며 0~100으로 제한한다. `피로 -8`은 8% 회복이 아니라 8점 회복이다.
- `경미 부상·7일`은 기존 경미 부상 상태와 회복 규칙을 사용한다. 기존 더 긴 부상이나 더 큰 페널티를 덮어써서 가볍게 만들지 않는다.
- 회복 선택은 피로를 줄일 뿐 의학적 부상 기간을 임의 단축하거나 이미 받은 능력 페널티를 지우지 않는다.

### 3.4 한 타석·한 상대 타자의 경기 보정

PE20–PE24는 실제 경기 엔진의 다음 판정 **한 번**에만 보정한다. 아래 수치는 능력치나 시즌 누적 성적에 직접 더하는 값이 아니다.

| 표기 | 현재 경기 판정에서의 뜻 |
| --- | --- |
| 볼넷 판정 ±N%p | 먼저 시행하는 볼넷 판정 확률의 변화 |
| 안타 판정 ±N%p | 볼넷이 아닐 때의 안타 판정 확률 변화 |
| 홈런 판정 ±N%p | 안타가 나온 뒤 장타 종류를 정할 때의 홈런 확률 변화 |
| 삼진 판정 ±N%p | 안타가 아닌 아웃에서 삼진 여부를 정하는 확률 변화 |

홈런·삼진 보정을 전체 타석당 홈런율·삼진율의 직접 변화라고 표시하지 않는다. 예를 들어 홈런 판정 +4%p가 곧 그 타석의 최종 홈런 확률 +4%p라는 뜻은 아니다. 투수 사건의 수치는 상대 타자에게 적용되므로 안타·볼넷 감소가 투수에게 유리하다.

경기 ID·타자 ID·투수 ID에 묶어 저장하고 해당 승부가 끝나면 제거한다. 확률은 기존 범위로 제한하고, 홈런은 2루타·3루타와 합계가 범위를 넘지 않게 한다. 경기 종료·취소·상대 교체로 대상 승부가 사라지면 보정을 폐기한다. 저장 후 재개해도 한 번만 사용한다.

카탈로그의 준비 결과는 실제 안타·아웃·승패를 보장하지 않는다. 기록은 이후 경기 시뮬레이션 결과로만 늘어난다.

## 4. 등장 빈도와 우선순위

다음은 신규 스케줄러에 대한 제안이다. 현행 프로 선택 사건은 주초·훈련일·티켓 사용 조건을 공유하므로, 휴식일·경기 장면·대표팀까지 처리하려면 발생 경로를 분리해야 한다.

| 통로 | 대상 | 초기 발생 규칙 |
| --- | --- | --- |
| 일반 상황 | PE01–PE19 중 PE13 제외, PE28–PE30 | 주초에 35%로 그 주의 적격 날짜·사건 하나를 예약. 일반 선택 사이 최소 14일, 시즌 최대 12회 |
| 실제 경기 | PE20–PE24 | 적격 경기에서 처음 맞는 장면에 20%로 판정. 경기당 시도 1회, 발생 사이 최소 7일, 시즌 최대 6회 |
| 주요 일정 | PE13, PE25–PE27 | 명시한 일정·자격을 충족하면 발생. 일반 사건 확률과 별도이며 사건별 제한 적용 |
| 확정 통보 | 정식 전환·승격·수상 등 기존 처리 | 기존 조건 달성 시 확정. 30종 및 확률형 발생 예산에 포함하지 않음 |

- 같은 날짜에는 새 선택 사건을 최대 1개만 연다. 일반·경기 통로는 직전 선택 사건에서 최소 3일이 지나야 한다. 주요 일정은 그 순간을 놓치지 않도록 3일 제한에서 제외하되 당일 1개 제한은 지킨다. 확정 통보는 선택 횟수 제한으로 늦추지 않는다.
- 일반 사건은 최근 등장한 일반 사건 3개 ID를 후보에서 제외한다. 동일 ID의 재등장 간격은 일반 사건 56일, 경기 사건 28일이다. 사건별 시즌 1회 등 조건도 함께 적용한다. 주요 일정은 개별 커리어·시즌·시리즈 제한을 쓰고 일률적인 56일 제한을 적용하지 않는다.
- 여러 후보가 있으면 일회성 단계 사건을 우선하고, 그 밖의 적격 사건 중 균등 선택한다. 후보가 없으면 그 주는 사건 없이 지나가며 보상을 대체 지급하지 않는다.
- 주초 예약 때 날짜와 사건을 고정하고, 실제 발생 직전 신분·부상·소속·출전 조건을 재검사한다. 조건이 사라지면 취소하며 같은 주에 유리한 사건을 다시 뽑지 않는다.
- 첫 1군 경기 PE13은 주초에 미리 추측하지 않고 실제 첫 출전 명단이 확정된 준비 단계에서 연다. 일반 통로의 35% 추첨·시즌 12회 예산과 별도다. 이미 데뷔한 선수가 카탈로그 적용 후 첫 경기를 치르는 경우에는 재생하지 않는다.
- 당일 주요 일정 판정을 일반·경기 사건보다 먼저 한다. 같은 날 주요 일정이 겹치면 PE13 → PE26 → PE25 순으로 하나만 열고 나머지는 생략한다. PE27은 충돌하지 않는 훈련 소집일을 잡는다. 일반 예약이 밀리면 그 주에는 취소하며 주요 사건 뒤에 이어 열지 않는다.
- 정식 전환·등록 이동·부상 처리 → 진행 중인 선택 결과 확인 → 주요 일정 → 보직 평가 결과 알림 → 경기 선택 → 일반 사건 순으로 충돌을 정리한다. 보직 평가 결과 알림이 주요 일정과 겹치면 다음 적격 날짜로 미룬다.
- 경기 사건은 일반 훈련 사건의 14일 제한·티켓 사용량과 무관하다. 휴식 사건도 티켓 0이라는 이유로 막지 않는다.

이 상한은 30개를 전부 보게 하는 장치가 아니다. 일상·경기·주요 일정 전체를 합친 시즌 수와 영구 성장량을 검증해 조정한다. 특히 영구 보상이 없는 경기 사건과 8주분 다중 능력 보상이 있는 PE08을 같은 가치로 세지 않는다.

나이 성장 효율·노화 시작 보정·이미 적용한 노화량은 그대로다. 이 사건이 영구 노화 면역이나 젊은 시절 성장 배율을 주지는 않는다.

### PE29. 남은 강점을 살릴 역할

- 분류: 베테랑 전환.
- 조건: 33세 이상 정식 단일 역할 선수, 캠프 또는 정규 시즌, 보직 평가 없음. 선발은 RP, DH가 아닌 야수는 DH를 목표로 제안. 이미 RP·CP·DH인 선수는 이번 유형에서 제외. 시즌 1회.
- 추가 조건: 정규 시즌에는 최근 14일 타자 8 PA 이하 또는 투수 10 BF 이하이고 팀 완료 경기 5개 이상. 캠프에는 개막 등록 경쟁에서 같은 역할의 다른 선수보다 역할 점수가 낮을 때.
- 상황: “코치가 남아 있는 강점을 {목표 역할}에서 살려보자고 한다. 14일 동안 새로운 역할을 평가받을까?”

| 선택 | 확률 | 결과 문구 | 효과 |
| --- | ---: | --- | --- |
| 새로운 역할을 평가받는다 | 100% | 다른 역할로 커리어를 이어갈 준비를 시작했다. | 목표 보직 평가 14일 시작, 야구 지능 +3주분 |
| 현재 역할의 강점을 더 다듬는다 | 100% | 익숙한 역할에서 자신의 강점을 다시 정리했다. | 강점 +4주분, 피로 +4 |

PE09·PE10·PE11과 동일한 평가·요청 대기를 공유한다. 정식 전환 이력을 되돌리거나 계약·연봉을 선택과 동시에 바꾸지 않는다.

### PE30. 신인에게 설명하며 되짚은 기술

- 분류: 베테랑 전환.
- 조건: 33세 이상, 정상 훈련일. 같은 구단에 프로 1~2년차인 같은 투타 분야의 현역 선수가 실제 존재. 시즌 1회.
- 상황: “같은 분야의 신인이 연습을 지켜봐달라고 부탁했다. 동작을 설명해줄까, 개인 훈련을 이어갈까?”

| 선택 | 확률 | 결과 문구 | 효과 |
| --- | ---: | --- | --- |
| 동작과 판단을 설명해준다 | 65% | 설명하는 과정에서 경기 판단의 기준이 더 분명해졌다. | 야구 지능 +4주분, 피로 +2 |
| 동작과 판단을 설명해준다 | 35% | 익숙한 동작을 말로 풀어내며 자신의 기술도 다시 정리했다. | 강점 +3주분, 피로 +3 |
| 개인 훈련 계획을 이어간다 | 75% | 개인 과제에 집중하며 보완할 부분을 다듬었다. | 약점 +3주분, 피로 +2 |
| 개인 훈련 계획을 이어간다 | 25% | 계획한 양을 마치고 몸을 가볍게 정리했다. | 피로 -3 |

멘토·호감도 같은 별도 능력을 만들지 않는다. 이 표의 보상은 플레이어에게만 적용하며 신인에게 별도 성장량을 자동 지급하지 않는다. 대화 상대는 이벤트 시작 때 고정해 저장한다.

## 9. 보직 평가와 별도 자격

### 9.1 보직 평가의 공통 흐름

대상은 PE09·PE10·PE11·PE29다. 최초 선택에서 기준 충족 시 보직 전환에 동의한다. 14일 평가 후에는 결과 알림만 제공하며 두 번째 선택은 만들지 않는다.

1. 사건을 열기 전에 목표 포지션·현재 역할·적성을 고정한다. 현재 진행 중인 보직 평가, 감독의 다른 역할 제안, 겸업 평가가 있으면 새 사건을 열지 않는다. 현행 28일 요청 대기가 끝나지 않은 경우도 제외한다.
2. 시작할 때 기존 요청 대기를 28일로 설정하고 평가 종료일을 오늘+14일로 보관한다. 같은 선수가 메뉴와 사건을 번갈아 써서 기간·보상을 중복 획득하지 못하게 한다.
3. 평가 중에는 기존 역할·출전 자격으로 경기를 진행한다. 훈련 배분을 몰래 변경하지 않으며, 사건의 일회성 능력 보상 외에 숨은 성장 배율을 주지 않는다.
4. 기간 중 정상 훈련에 참여한 날짜 수를 기록한다. 평가 종료일까지 5일 이상 참여하고, 종료 시 활동 가능하며, 목표 투타 분야 OVR과 목표 역할 점수가 모두 45 이상일 때 다음 단계로 간다. 이는 게임용 초기 기준이다.
5. 근거가 충분하면 처음 동의한 목표 보직으로 전환하고 결과 알림을 제공한다. 추가 선택·능력 보상·각성 추첨은 없다.
6. 전환하면 목표 포지션·주 역할·필요한 출전 자격을 현행 보직 적용 절차로 갱신한다. 일반적인 전환 후 훈련 설정 변경이 있다면 이를 함께 표시하고 사용자에게 확인할 수 있게 한다. 겸업 자격은 새로 만들지 않는다.
7. 사전 전환 동의가 없는 구버전 저장의 평가는 현재 역할을 유지하고 알린다. 이미 열려 있던 구버전 수락·유지 선택은 원래대로 처리할 수 있다.
8. 5일의 훈련 근거가 부족하거나 적성·건강 조건이 맞지 않으면 평가 미완료를 통보하고 기존 역할을 유지한다. 재평가는 기존 요청 대기와 사건 제한을 따른다.

평가 종료는 선택 이벤트를 생성하지 않는다. 종료 판단에 당시 없던 경기 기록이나 미래 능력치를 끌어오지 않는다.

**PE09의 목표 포지션 후보:** 현재와 다른 기존 야수 출전 자격에 아래 인접 후보를 더한다. 새 포수 자격은 이 사건으로 제안하지 않으며, DH 전환은 PE11에서 다룬다.

| 현재 포지션 | 추가로 평가할 수 있는 후보 |
| --- | --- |
| C | 1B |
| 1B | 3B |
| 2B | SS |
| 3B | 1B |
| SS | 2B |
| LF | RF |
| CF | LF, RF |
| RF | LF |
| DH | 기존 야수 출전 자격에 있는 포지션만 |

목표는 같은 야수 분야이며 타격 OVR·목표 역할 점수 45 이상이어야 한다. 기존 출전 자격으로 CF를 검토하는 경우에는 수비·스피드 각각 55 이상도 요구한다. 가능한 후보 중 목표 역할 점수가 높은 포지션, 동점이면 같은 구단의 해당 포지션 경쟁자가 적은 쪽, 다시 같으면 `C→1B→2B→3B→SS→LF→CF→RF` 순으로 정한다. 후보가 없으면 PE09를 내지 않는다.

포지션별 정교한 수비 측정이 없으므로 이 기준은 거친 게임 적성 기준이다. 평가 통과만으로 프로 수준의 수비가 입증됐다거나 즉시 주전이 되었다고 서술하지 않는다. 실제 경기 기용은 출전 자격·구단 경쟁·몸 상태를 다시 따른다.

PE10·PE29의 투수 목표는 RP, PE11·PE29의 야수 목표는 DH다. 해당 목표가 현재 역할과 같으면 사건을 제외한다. PE29가 적격인 베테랑에게 같은 시기에 PE09·PE10·PE11을 함께 후보로 넣지 않는다.

### 9.2 평가 출전 요청의 공통 흐름

PE12의 요청은 현행 `requestedEvaluationUntil`과 같은 21일 검토 상태에 연결한다. 요청 중복·28일 대기는 메뉴와 공유한다. 새 유리한 출전 점수나 가짜 출장 기록을 추가하는 효과가 아니다.

- 해당 레벨의 실제 일정과 수비·투구 자격, 경쟁자, 컨디션이 맞을 때 기존 평가 출전 절차가 기회를 배정한다.
- 실제 기회가 배정되면 기존 처리대로 요청 상태를 소비한다. 21일 안에 기회가 없으면 요청은 만료되며 그 사실을 알린다.
- 이적·승격으로 소속·레벨이 바뀌면 기존 요청을 새 구단에 자동 승계하지 않고 종료한다. 새로운 상황에서는 현행 요청 규칙을 따른다.
- 신고선수의 성장 90%, 출전 평가 불이익, 정식 전환 전 1군 등록 제한을 유지한다. 정식 전환은 완료된 2군 기록으로만 판정한다.

### 9.3 성인 대표팀 합동훈련 대상 선정

PE27은 고교 대표팀 이벤트와 분리된 **게임용 성인 대표팀 훈련 초청**이다. 현재 국적 데이터가 없으므로 이번 안에서는 게임 월드의 구단 소속 현역 프로 선수를 대상으로 한다. 실제 국가별 대표팀 명단이나 실제 소집 제도라고 표시하지 않는다.

**선정 시점 (과거 설계, 현행은 [대회별 일정](pro-wbc.md) 적용):** 리그의 마지막 공식 경기가 끝난 뒤 시즌 결산·기록 보관을 마치고, 계약 시장·다음 시즌 노화·시즌 전환에 따른 보정값 변경을 처리하기 전의 상태를 고정한다. 다음 날을 소집 안내일로 사용한다. 이 날짜 진행과 결산 화면의 선택 처리는 신규 연결이 필요하다.

**자격:** 정식 선수, 구단 소속 현역, 활동 가능·강제 휴식 아님, 피로 80 미만. 당해 정규 시즌 1군 타격 100 PA 이상 또는 투구 90아웃 이상을 해당 분야에서 충족해야 한다. 2군·포스트시즌·다른 연도 기록으로 표본 조건을 대신하지 않는다.

| 초청 구분 | 최대 인원 | 후보 분류 |
| --- | ---: | --- |
| 선발 | 6 | 현재 주 포지션 SP, 투구 표본 충족 |
| 불펜 | 6 | 현재 주 포지션 RP·CP, 투구 표본 충족 |
| 포수 | 2 | 현재 주 포지션 C, 타격 표본 충족 |
| 내야 | 4 | 현재 주 포지션 1B·2B·3B·SS에서 각각 1명 |
| 외야 | 4 | 현재 주 포지션 LF·CF·RF, 타격 표본 충족 |
| 타격 자원 | 1 | 앞에서 선발하지 않은 타격 분야 선수 중 타격 표본 충족자. DH 포함 |
| 합계 | 23 | 선수별 한 자리만 사용 |

각 구분에서 **현재 프로 평판 → 해당 역할 점수 → 선수 ID** 순으로 선발한다. 내야는 `1B→2B→3B→SS`, 전체 구분은 표의 순서로 처리한다. 겸업도 현재 주 포지션으로 한 번만 분류하며 반대 분야에서 추가 자리를 차지하지 않는다. 타격 자원도 주 분야가 타격인 선수만 대상으로 한다.

현행 명단은 투수 15명·타자 15명으로 최대 30명이며, 자격자가 부족하면 해당 분야의 차순위로 보충한다. 표본 기준을 몰래 낮추거나 고교 선수로 메우지 않는다. 한 자리를 거절했다고 다른 선수에게 반복 제안하며 플레이어를 끌어올리는 추가 충원은 첫 범위에 넣지 않는다.

초청 여부·명단·평가 기준일을 저장하고 다시 열어도 같은 명단을 사용한다. 초청받은 플레이어에게만 PE27 선택을 노출한다. NPC의 보상 처리는 이번 플레이어 선택 이벤트 범위 밖이며, NPC에게만 자동 대성공 보상을 일괄 지급하지 않는다.

합동훈련의 주수는 가상 훈련량 보상의 단위다. 몇 주의 국제대회 일정·경기 기록을 생성하지 않는다. 경기 일정과 연결된 국제대회를 도입하려면 별도의 기획을 추가한다.

### 9.4 겹치는 경기 장면

한 승부에 사건이 여러 개 맞더라도 하나만 시도한다. 투수는 `PE22 만루 → PE24 피로 → PE23 한 점 차`, 타자는 `PE21 뒤진 후반 → PE20 강한 구위` 순으로 우선한다. 해당 경기 첫 적격 장면에서 한 번 판정한 뒤 실패했어도 같은 경기에서 다시 시도하지 않는다.

선택 결과의 피로도 기존 경기 피로 장부에 한 번 반영한다. 실제 타석·투구 결과로 생기는 피로는 별도다. 경기 사건은 모두 영구 능력 보상이 없으므로 이 다섯 사건에는 각성을 추첨하지 않는다.

## 10. 현행 이벤트와의 관계 및 필요한 작업

### 10.1 중복 발생 방지

| 현행 사건 | 새 카탈로그에서의 처리 |

| D02 코치의 추가 훈련 | PE04·PE08의 집중 훈련으로 통합 |
| D03 전력 분석실의 영상 | PE03·PE17로 구분 |
| D04 동료와의 약속 | PE19·PE30의 야구 활동으로 구체화 |
| PRO02 캠프의 새 보직 | PE09·PE10·PE11로 대상·목표를 나눔 |
| PRO04 평가 출전 전 준비 | 프로 일반 풀에서 제외하고 PE12의 기회 요청 흐름으로 재구성. 실제 평가 출전 통보는 유지 |
| PRO06 첫 1군 출전 전 취재 | PE13의 실제 출전 전 준비로 교체 |
| PRO07 1군 부진 뒤 분석실 | PE17로 통합 |
| PRO08·PRO15 베테랑 보직 조언·면담 | PE29와 공통 보직 평가로 통합 |
| PRO09 복귀 전 준비 | PE18로 교체 |
| PRO11 중요한 시리즈 전 준비 | PE25·PE26으로 구분 |

기존 D 사건을 공유하는 대학 커리어는 이번 프로 카탈로그 전환으로 바꾸지 않는다. 고교 30종도 그대로 별도 운영한다. 오래된 ID가 저장 이력에 남아 있어도 해석할 수 있어야 하며, 이미 발생·확정한 보상을 취소하거나 다시 추첨하지 않는다.

이 문서를 도입한 시즌의 기존 성장형 선택 횟수는 일반 통로의 시즌 예산에 포함한다. 기존 사건을 겪은 직후 이름이 다른 동등 사건으로 다시 보상받지 않도록 대응되는 새 ID의 간격도 이어받는다. 기존 PRO08 또는 PRO15를 겪었다면 그 시즌 PE29는 제외하는 식이다.

미선택 상태의 구버전 사건은 저장된 사건 버전으로 마무리하고 다음 사건부터 새 카탈로그를 쓴다. 단, 이미 제거된 고정 대폭 보상에 대한 현행 안전 마이그레이션은 유지한다. 해결된 과거 이력은 수정하지 않는다.

### 10.2 현재 재사용 가능한 부분과 확장이 필요한 부분

최근 14일 조건은 완료 경기의 날짜와 해당 시점 소속 레벨로 계산한다. 이적 전후 같은 레벨의 기록은 합칠 수 있지만 1·2군을 섞지 않는다. “출전 없음”은 타격 PA와 투구 BF가 모두 0인 상태이며, 시즌 시작 14일 미만이나 해당 레벨의 근거가 부족한 상태를 장기 무출전으로 해석하지 않는다.

선발 등판과 포지션별 출전 구분을 과거 기록에서 정확히 알 수 없는 경우에는 관련 사건을 추측으로 내지 않는다. 필요한 출전 유형 기록을 먼저 남긴다. 단순한 `lineup` 포함만으로 대타·대수비·선발 이력을 만들어 내지 않는다.

### 10.3 구현 순서 제안

1. **내용·공통 처리:** PE01–PE08·PE14–PE19·PE28·PE30의 결과와 대상 조건을 연결한다. 휴식·복귀 사건은 주초 훈련 조건에서 분리한 뒤 활성화한다.
2. **기회·보직:** PE09–PE13·PE29, 기존 요청 대기 공유, 평가 결과 통지, 첫 경기 준비 시점을 연결한다.
3. **경기:** PE20–PE24의 실제 장면 중단·한 승부 보정·경기당 한 번 판정을 연결한다.
4. **시즌 주요 일정:** PE25–PE27의 시리즈·결산 경로와 대표팀 명단을 연결한다.
5. **세이브·밸런스:** 구버전 진행 중 사건·보상·간격을 보존하고 시즌별 노출량을 비교한다.

미완성 경로는 해당 사건을 후보에서 제외한다. 예를 들어 프로 경기 사건 연결 전에는 PE20–PE24를 훈련일 텍스트 사건으로 대신 띄우지 않는다. 대표팀 명단 저장이 없을 때 임의의 평판 기준으로 PE27을 대체하지 않는다.

## 11. 저장·결과 화면·검증 기준

### 11.1 저장해야 할 정보

- 사건 버전·ID·발생 날짜·통로·시즌·선수 ID·당시 소속과 레벨.
- 상황에 사용한 동료·상대·목표 포지션·경기·시리즈·부상 건·대표팀 명단의 식별자.
- 사건 시작 때 고정한 약점·강점·보상 분야와 능력 기준 상태.
- 선택 ID·기본 결과 ID·각성 판정·실제 능력/평판/피로 변화·부상 상태.
- 이번 주 일반 통로 판정 여부·예약, 경기별 시도 여부, 통로별 시즌 횟수·최근 발생 날짜·동일 ID 간격.
- 보직 평가 시작·종료 예정일·정상 훈련일 수·종료 판단·최종 선택.
- 조건 소멸로 취소한 예약·경기 보정, 만료된 요청의 이유.

선택 전 난수를 미리 소비해 결과를 바꾸거나 결과 화면에서 다시 굴리지 않는다. 기존 이벤트 RNG를 사용하되 경기 RNG와 구분하고, 사건 조회만으로 어느 스트림도 바뀌지 않게 한다. 본문·선택지·결과는 저장한 버전으로 재현한다.

### 11.2 결과 화면

결과는 `선택한 행동 → 결과 문구 → 실제 변화 → 다음 단계` 순으로 읽히게 한다. 능력·평판·피로의 소수점 원본을 유지하고, 0이 아닌 작은 변화를 반올림해 “변화 없음”으로 표시하지 않는다. 고교와 동일하게 “아주 조금 상승·조금 상승·상승·크게 상승·매우 크게 상승·하락” 문구로 표시한다. 경기 판정 보정도 같은 문구를 사용하며 수치 계산에는 영향을 주지 않는다.

| 결과 유형 | 보여줄 것 |
| --- | --- |
| 영구 성장 | 대상 능력의 실제 증가량, 각성 문구, 피로·최종 평판 차이 |
| 회복 | 실제 회복량, 남아 있는 부상·강제 휴식 상태 |
| 부상 | 경미 부상 여부, 실제 적용 복귀 예정일, 기존 부상과 병합된 결과 |
| 경기 보정 | 이번 타석/상대 타자 한 번에 적용되는 판정 보정과 현재 경기 상황 |
| 보직 평가 | 목표 역할, 종료 예정일, 기존 역할 유지, 이후 평가·선택 안내 |
| 평가 요청 | 검토 만료일, 출전 미보장, 기존 신고 제한 유지 |
| 대표팀 | 훈련 초청 결과와 실제 보상. 가상의 국제대회 성적은 표시하지 않음 |

### 11.4 밸런스 확인

신고·2군·1군 후보·주전·베테랑, 타자·투수·겸업, 낮은·높은 능력치 구간을 나눠 여러 시즌을 비교한다. 같은 시드에서 사건을 끈 기준선과 켠 경우의 성장·피로·부상·등록·평판을 함께 본다.

- 일반 사건 12회·경기 사건 6회 상한과 실제 노출량, 특정 상태에서 사건이 전혀 나오지 않는 비율.
- 영구 능력의 총 주수·실제 증가량. PE08·PE27의 다중 능력 대성공과 각성을 따로 집계.
- 매번 추가 훈련·매번 회복·상황에 따른 선택의 결과 비교. 한 선택만 반복하는 것이 모든 상황에서 유리하면 조정.
- 정상 휴식만으로도 가능한 회복과 이벤트 추가 회복의 크기. 현재 훈련 피로 모델을 무력화하는지 확인.
- 신고선수의 평가 기회·정식 전환 시점. 기존 성과 조건이 실제 경기 기록으로 충족되는지 확인.
- 평판 보정 상한에 너무 빨리 도달하는지, 스카우팅 평가·계약이 사건 평판에 지나치게 좌우되는지 확인.
- 포지션 전환을 반복해 보상만 얻는지, 요청 대기·시즌 제한으로 막히는지 확인.
- 노화가 있는 베테랑에게도 기술·역할 선택의 의미가 남는지 확인. 노화를 제거하는 방식으로 해결하지 않음.
