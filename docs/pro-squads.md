# 프로 선수단

1군·2군·잔류군(3군)·육성선수로 나눈다. 공식 경기는 1·2군만 진행한다. 2군 경기는 **등록 2군과 3군 전체를 합친 선수단**으로 치른다. 같은 현재 포지션에서는 출전 가능한 2군 선수를 3군보다 우선하고, 휴식·부상·교체로 생긴 자리는 3군이 맡는다. 실제 출전은 2군 기록으로 쌓되 출전만으로 등록 군을 바꾸지 않는다. 육성선수는 기존의 별도 평가 기회가 있을 때만 참여하고 상위 군의 출전 우선권을 넘지 않는다. 통합 선수단을 40명으로 고정하지 않으며 계약·부상·등록에 따라 인원이 달라진다.

정식 신인은 잔류군에서 성장 효율 100%, 신고 신인은 육성선수에서 90%로 시작한다. 매년 새로 생성하는 신인 중 약 90%는 정식, 10%는 신고선수다(신고 인원은 전체 인원의 10%를 반올림). 같은 출전평가라면 잔류군을 육성선수보다 우선하여 2군 승격을 검토한다. 승격에는 포지션·정원·출전 가능 상태·최근 이동 제한도 반영한다.

3군에서 1군으로 바로 올라갈 수 없다. 먼저 2군으로 등록해야 하며 같은 날 임시로 2군에 놓고 곧바로 1군에 올리는 우회도 막는다. 정규 등록 심사는 이동 후 14일 제한을 적용한다. 부상 대체·명단 정규화·포스트시즌 특별 엔트리·이적도 3군의 1군 직행을 허용하지 않는다.

1·2군은 14일마다 같은 현재 포지션의 **현재 출전평가**로 비교해 높은 선수를 1군에 등록한다. 기량 8점 차이·별도 성적 표본·누적평가 추가 격차는 요구하지 않는다. 동점이면 기존 소속을 유지하며, FA 주전·보직 보장, 부상·강제 휴식과 재등록 제한은 별도로 적용한다. 누적 평가는 연봉·계약과 동점 우선순위에 계속 사용한다. 포지션 경쟁 화면은 출전평가순으로 표시하고 다음 심사일과 대기 사유를 설명한다.

기존 저장의 한 번뿐인 재편은 역할 능력 70%와 출전평가 30%를 기준으로 1군 29명, 2군 30명 이내로 정리한다. 기존 3군 선수는 이 과정에서도 1군으로 직행하지 않는다. 선수 ID·능력치·기록·계약·난수 상태를 보존한다. 새 게임은 신인의 초기 소속을 유지한다.
