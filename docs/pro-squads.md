# 프로 선수단

1군·2군·잔류군(3군)·육성선수로 나눈다. 공식 경기는 1·2군만 진행한다. 잔류군·육성선수는 자체 주전·후보 구분 없이 훈련하며, 간헐적인 2군 평가 경기에 실제로 출전하고 해당 2군 기록을 쌓는다. 평가 출전만으로 소속은 바뀌지 않는다.

정식 신인은 잔류군에서 성장 효율 100%, 신고 신인은 육성선수에서 90%로 시작한다. 매년 새로 생성하는 신인 중 약 90%는 정식, 10%는 신고선수다(신고 인원은 전체 인원의 10%를 반올림). 같은 출전평가라면 잔류군을 육성선수보다 우선하여 2군 승격을 검토한다. 승격에는 포지션·정원·출전 가능 상태·최근 이동 제한도 반영한다.

기존 저장은 진행 중인 주·경기가 끝난 뒤 한 번 재편한다. 역할 능력 70%와 출전평가 30%로 정식 선수의 포지션별 우선순위를 정해 1군 30명, 2군 30명 이내를 채우고 남은 정식 선수는 잔류군, 신고선수는 육성선수로 배치한다. 선수 ID·능력치·기록·계약·난수 상태는 보존한다. 새 게임은 신인의 초기 소속을 유지하며 이 재편을 반복하지 않는다.
