# 프로 1·2군 올스타

올스타 화면은 프로 **어워드 → 올스타**에서 직접 표시한다. 리그 페이지의 버튼과 모달은 제거했으며 1·2군, BLUE·WHITE, 투표·최종 명단·경기 결과 전환은 유지한다. 5월 전에는 투표 시작일을 안내한다.

## 진영과 선발

각 리그에 BLUE / WHITE 두 진영이 있다. BLUE는 베어스·자이언츠·라이온즈·랜더스·위즈, WHITE는 트윈스·다이노스·타이거즈·히어로즈·이글스다.

진영별 투표 선발은 선발투수·중간계투·마무리 각 1명과 포수·1루·2루·3루·유격수·좌익·중견·우익·DH 각 1명, 총 12명이다. 감독 추천 10명을 더해 22명, 두 진영과 두 리그를 합쳐 최대 88명이다. 같은 선수를 여러 부문·진영·리그에 중복 선발하지 않는다. 감독 추천은 투표 탈락자 중에서 고르며 백업 포수 1명과 교체 투수까지 총 6명 이상의 투수를 우선 확보하고 나머지는 포지션 제한 없이 평가한다. 실제 출전 가능한 선수가 부족하면 인원을 임의 생성하지 않는다.

5월 1·15·29일과 6월 12·26일에 집계하고, 6월 30일 경기와 훈련을 마친 뒤 남은 기간의 표를 합산해 명단을 확정한다. 각 집계에서 구단별·부문별 후보 1명을 내며 선수에게 표를 누적한다. 후보가 바뀌어도 이전 표는 유지하고 새 후보가 물려받지 않는다. 지명타자를 제외한 부문 후보는 현재 주 포지션을 따른다.

해당 군에서 실제 타석·상대한 타자가 있는 현역 1·2군 선수만 후보가 된다. 투표와 감독 추천은 역할 능력 45%·출전평가 40%·해당 군 성과 15%를 사용한다. 구간별 득표 증가량은 이 평가와 경과일에 비례하며, 난수 상태를 사용하지 않는다. 6월 말 소속 군으로 최종 선발하고 다른 군으로 표를 이전하지 않는다. 잔류·육성군의 일시적 2군 평가 출전만으로 후보 자격을 얻지는 않는다.

명단 확정 뒤 승격·강등이 있어도 확정된 올스타 군과 진영은 유지한다. 부상·강제 휴식·비활동 등으로 출전할 수 없으면 경기 당일 같은 진영에서 대체 선발한다. 대체된 선수도 기존 선발 이력과 보상은 유지한다.

## 일정과 경기

7월의 두 번째 금요일(8~14일)에 2군, 다음 토요일에 1군 경기를 연다. 금·토에는 양 리그의 정규경기를 편성하지 않고, 이어지는 일~목은 정규훈련도 쉬며 회복한다. 다음 금요일에 정규경기를 재개한다.

1군은 144경기와 화수목·금토일 3연전을 유지한다. 2군은 상대별 13경기, 팀당 117경기이며 목요일 휴식, 홈·원정 58/59경기다. 올스타 휴식은 두 리그 모두 지킨다. 기존 저장은 완료 경기·기록을 유지하고 미진행 2군 일정만 상대별 13경기에 맞춰 재편한다.

올스타는 기존 경기 엔진을 사용한 별도 9이닝 경기이며 무승부도 허용한다. 선발 야수는 투표 선수를 우선하고 4회부터 후보를 교체 투입한다. 처음 3명의 투수는 1이닝, 이후 투수는 2이닝을 기준으로 교체한다. 당시 경기 기록과 활약을 비교해 각 리그에서 미스터 올스타 1명을 선정한다. 동점 경기에도 선정하며 동일 점수는 선수 ID로 안정적으로 결정한다.

정규·포스트시즌 기록, 팀 순위, 최근 경기 성적 평가, 1군 데뷔와 경기 출전으로 인한 FA 근거에 합산하지 않는다. 올스타 경기의 난수는 고정된 별도 시드를 사용하여 정규 경기 난수 상태를 바꾸지 않는다. 실제 참가자는 피로가 생기고 기존 부상 확률의 1.5배에 1.5%p를 더한 위험을 적용한다. 명단에만 있고 실제로 뛰지 않은 선수에게 추가 부상 판정을 하지 않는다.

## 보상과 화면

프로 평판은 폐지했다. 선발 경험은 야구 지능 3주 훈련분, 미스터 올스타는 추가 2주 훈련분으로 보상하며 점수 보너스를 직접 더하지 않는다. 각각의 선발·수상에 한 번만 지급하고 성장 둔화·나이·신고선수 효율·능력 상한을 적용한다. 7월 초 사용자에게 준비 선택 이벤트를 제공하고 출전 후 실제 기록·미스터 올스타 결과 이벤트를 보여준다. 저장·재개나 중복 호출로 선발·보상을 다시 처리하지 않는다.

준비 이벤트의 기술 교류를 선택하면 60%로 주 역할 약점 3주분, 40%로 야구 지능 1주분을 배운다. 기존 루틴·회복 선택도 유지한다. 경기 뒤 기술 복습은 30%로 타자 컨택 또는 투수 제구 1주분을 얻고 나머지는 경험을 정리한다. 일반 이벤트와 같은 재능·성장 둔화·프로 성장·신고선수 효율·상한·각성 규칙을 적용하며 선발·수상 자체의 능력 보상과 구분한다.

5월부터 리그 최상단의 올스타 버튼으로 모달을 연다. 1·2군과 BLUE·WHITE를 전환하며 부문별 누적 상위 3명을 확인한다. 사용자가 4위 이하면 자기 순위와 득표도 표시한다. 확정 뒤에는 최종 명단과 선발 방식, 경기 뒤에는 진영별 실제 기록과 미스터 올스타를 조회한다. 메인 주간 일정에는 경기와 휴식기를, 커리어에는 개인 올스타 선발·출전·수상 이력을 남긴다. 시즌 결산 시 전체 올스타 자료도 함께 보관한다.

도입 전에 이미 지난 올스타 경기는 소급 진행하지 않는다. 도입 시점이 2군 경기 이후면 해당 경기 미개최 사유를 표시하고, 1군 경기까지 모두 지난 시즌은 다음 시즌부터 참여한다. 6월 말 이후 경기 전 도입은 도입 당시 선수단과 누적 성적으로 명단을 확정한다.
