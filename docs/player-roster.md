# 선수·로스터 표시

2026-11-09 변경. 고교·프로가 같은 선수 목록 컴포넌트를 사용한다.

- 투수·타자 목록을 분리하고 겸업 선수는 양쪽에 표시한다.
- 공통 정보는 선수·OVR·등급·학교 또는 구단·학년 또는 나이·포지션·출전평가 점수다. OVR은 등급 왼쪽에 표시하며 투수 목록은 투수 OVR, 타자 목록은 타자 OVR이다. 고교는 평판, 프로는 출전평가로 등급을 매긴다. 등번호와 주전·후보, 고교 전국 목록의 드래프트 라운드 표시도 유지한다. 잔류군·육성선수에는 주전·후보를 표시하지 않는다.
- 투수 기록: 출전경기·이닝·승·패·홀드·세이브·ERA.
- 타자 기록: 출전경기·타수·안타·홈런·타점·타율·OPS.
- 기본 정렬은 고교 평판·프로 출전평가의 내림차순이며 각 기록으로도 정렬할 수 있다. ERA는 낮은 순, 다른 기록은 높은 순이다. 미집계 값은 마지막에 정렬한다.
- 프로는 1군·2군·잔류군(3군)·육성선수·시즌 합계를 선택한다. 1·2군은 해당 리그 기록이 있거나 현재 소속된 선수를 표시한다. 잔류군·육성선수는 자체 경기 없이 간헐적으로 실제 2군 평가 경기에 출전하며 원래 소속을 유지한다. 표시 기록에는 포스트시즌을 섞지 않는다.
- 기존 저장에서 집계하지 않은 출전·승패 등은 `—`로 표시한다. 비율 기록의 분모가 0인 경우도 `—`다.

## 등급

| 등급 | 고교 평판 | 프로 출전평가 |
|---|---|---|
| S | 80 초과 | 81 초과 |
| A | 72 이상 80 이하 | 79 이상 81 이하 |
| B | 64 이상 72 미만 | 77 이상 79 미만 |
| C | 56 이상 64 미만 | 75 이상 77 미만 |
| D | 48 이상 56 미만 | 73 이상 75 미만 |
| E | 40 이상 48 미만 | 71 이상 73 미만 |
| F | 40 미만 | 71 미만 |

프로는 목록에 표시하는 소수 첫째 자리 점수로 등급을 판정한다. 76.0은 C, 81.0은 A다. 고교는 평판이며 미평가 상태는 등급도 `—`다. 프로는 현재 역할의 출전평가를 사용하므로 피로·최근 성적·등록 상태에 따라 등급이 바뀐다. 선택한 기록 리그는 등급 계산을 바꾸지 않는다. 두 점수 모두 역할 능력을 포함하므로 OVR을 다시 더하지 않는다. 조회는 선수의 능력·평판·난수 상태를 바꾸지 않는다.

메인 프로필의 기존 `OVR / 100` 자리에도 같은 등급을 표시한다. 배지는 목록과 같은 색·모양이며 메인에서만 크기를 조금 키운다. 투수·타자 OVR 숫자는 별도로 유지한다. 선수 상세에서는 포지션과 등급을 같은 줄에 놓는다.

고교·프로 메인 요약의 기존 평판 카드에는 현재 주 역할의 OVR을 표시한다. 프로필 아래의 중복 투타 OVR 줄은 제거하고 OVR 카드 안의 설명·투타 수치를 확대했다. 등급 배지에 마우스를 올리거나 키보드로 포커스하면 별도 Tooltip 컴포넌트가 고교는 평판 점수, 프로는 출전평가 점수를 `n/100`으로 즉시 표시한다. 목록의 스크롤 영역에 잘리지 않도록 포털로 표시한다. 출전평가 점수는 구단 공통이고 경쟁 선수에 따라 출전 기회가 달라진다. 드래프트의 구단 적합도는 구단 수요를 반영한다.

## 평판과 출전평가의 차이

평판은 이미 능력을 반영한다. OVR 숫자 자체 대신 포지션별 역할 능력(`roleScore`)을 사용하고, 최근 3시즌의 표본·리그 수준을 보정한 경기 성과를 최대 40%까지 혼합한 뒤 이벤트·경력·겸업 보너스를 더한다. 고교 성과와 프로 1군·2군 성과는 각각의 리그 기준으로 평가하며, 프로 2군 성과에는 비중 제한과 성과 점수 상한을 적용한다.

출전평가(`selectionScore`)는 고교와 프로에 모두 있는 별도 점수다. 역할 능력에서 피로·신고선수·관리 기간의 불이익을 빼고 최근 성적을 더한다. 실제 선발·교체 및 프로 등록 경쟁에 쓰이며 평판의 다른 이름이 아니다. 평가식 자체는 유지하고 프로 등급의 출처를 이 점수로 바꿨다.

## 프로 등록 안정성

강제 휴식은 1군에서 쉬는 사유이며 그것만으로 2군에 내리지 않는다. 장기 부상은 기존 대체 등록을 유지한다. 일반 등록 심사에서는 같은 포지션의 출전 가능한 정식 선수를 비교하며, 1군의 출전평가가 A 이상이거나 해당 시즌 1군 40타석 이상·타율 .300 이상이면 8점 초과의 평가 차이가 있을 때 조정한다. 그 외에는 3점 초과 차이를 요구한다. 14일 등록 재심사·최근 이동 제한은 유지하며, 정원과 포지션 공백도 함께 고려한다. 커리어 탭의 등록·이동 기록 패널은 제거했으며 내부 이력은 보존한다.
