# 프로 국가대표와 시범경기

| 대회 | 개최 주기 | 연령 | 선발 출전 평가 가산 |
| --- | --- | --- | --- |
| WBC | 2030년부터 4년마다 3월 1~20일 | 제한 없음 | +10 |
| 프리미어12 | 2027년부터 4년마다 11월 | 제한 없음 | +8 |
| 올림픽 | 2028년부터 4년마다 7월 | 25세 이하 | +6 |
| APBC | 2029년부터 4년마다 11월 | 25세 이하 | +3 |

기존 선발 기준인 출전 평가와 기량을 사용한다. 정식 계약·소속·가용 상태, 피로 80 미만 및 1군 타자 100타석·투수 30이닝 표본을 요구한다. WBC는 직전 연도 1군 표본, 나머지는 당해 표본이다. 주전·평판 보상과 독립적인 국대 출전 평가 가산을 적용하며 반복 합산하지 않고 선발 이력 중 가장 높은 가산 하나만 유지한다.

총 30명: 투수 15명(선발 5·중계 8·마무리 2), 타자 15명(포수 2·내야 7·외야 5·DH 1). 특정 자격자가 부족하면 해당 분야의 차순위로 보충하되 한 분야 15명을 넘기거나 가상 선수를 만들지 않는다. 겸업은 타격·투구 OVR 중 높은 쪽으로만 선발한다. 동률은 타격 쪽이다.

명단과 선발 당시 이름·소속·포지션·평가를 저장하고 독립된 국제대회 탭에서 대회별로 확인한다. 다른 해·대회로 넘어가도 기록을 유지한다. 올림픽은 시즌 중 차출을 거부할 수 있고 다른 대회도 기존 참가/소속팀 잔류 선택지를 유지한다.

국제대회 탭에서 조별리그·토너먼트 버튼으로 순위와 대진표를 확인한다. 조별리그는 조 선택 드롭다운을 사용한다. 그 아래 대한민국 대표팀의 투수·타자를 보직 순으로 분리해 경기 기록을 표시한다. 참가국 명단과 개인 기록 탭은 제공하지 않는다. 대진은 실제 경기 결과로 결정되며 국내 정규·포스트시즌·시범 기록과 분리한다. 국가별 선수는 가상 생성되고 다음 대회에는 나이·연령 제한을 반영해 잔류하거나 교체된다.

| 대회 | 게임 진행 방식 |
| --- | --- |
| WBC | 20개국, 5팀씩 4개 조, 상위 2팀 8강 → 준결승 → 결승 |
| 프리미어12 | 16개국, 4팀씩 4개 조 → 8팀 2차 라운드 → 4팀 슈퍼라운드 → 결승·동메달전 |
| 올림픽 | 6개국, 3팀씩 2개 조, 조 1위 준결승 직행·2/3위 교차 단판 → 준결승·메달전 |
| APBC | 4개국 총당리그 → 1/2위 결승·3/4위 순위전 |
| 청소년대표 | 12개국, 6팀씩 2개 조 → 각 조 상위 3팀 슈퍼라운드 → 메달전 |

프리미어12 2차 라운드와 청대 슈퍼라운드는 같은 조에서 함께 진출한 팀과의 결과를 승계한다. 승계 경기에는 새 개인 기록이 생기지 않는다. 조 순위는 승수·패수·승자승·득실차·득점·고정 국가 번호로 결정한다. 개최 연도·월·연령·30인 로스터는 사용자 설정이며 현실 규정과 차이가 있다. 세부 경기일과 동률 처리도 게임용이다. 성인 9이닝, 청대 7이닝, 연장에는 자동 주자를 두고 승부가 날 때까지 진행한다. 투수는 선발 4일 휴식을 우선하고 피로·가용 상태를 반영한다. 투구 단위 제한과 대회별 콜드게임 규정은 아직 별도 적용하지 않는다.

참가 선택은 합류만 확정하고 즉시 성장·부상·MVP를 지급하지 않는다. 경기 전 분석/회복/교류와 실제 접전 후반의 타자·투수 선택지를 제공한다. 승부처 선택은 해당 타석의 확률에 반영한다. 선택 중 커서·난수·기록을 저장해 재개 시 중복 경기를 막는다.

수상은 모든 국가를 대상으로 전체 기여도 70, 단판 경기 기여도 20, 우승 가산 10으로 계산한다. 투수/타자는 분야별 기여도 최대값으로 정규화하고 적은 출전 표본은 감액한다. MVP·최우수 투수·최우수 타자·포지션별 베스트팀을 보관한다. 성장 보상은 실제 출전자만 대회 종료에 한 번 지급한다. 일반 출전자는 위상별 기본 주수의 40~100%, MVP는 상위 주수 보상을 받고, BQ에도 수상 경험을 반영한다.

차출 선수는 사용자와 NPC 모두 국내 경기에서 제외되며 참가 사양 시 차순위 대체 선수를 사용한다. 한국의 탈락 또는 최종전 이후 복귀한다. 11월 대회는 시즌 결산 상태에서도 날짜를 진행하고 선택지에서 정지한다. 다음 캠프가 대회 결과를 건너뛰지 않는다. 청대와 고3 드래프트가 겹치면 지명은 원래 드래프트 날짜의 평가로 동결하고, 대회를 마친 뒤 진로 화면으로 이동한다.

시범경기는 매년 3월 4~20일 격일로 상대 9팀과 한 경기씩, 팀당 9경기(리그 45경기)다. 모든 군이 참가 가능하며 2군 → 3군·육성 동등 → 1군 하위 → 나머지 1군 순으로 기회를 준다. 시범 성적은 별도 보관하며 정규 성적에 합산하지 않는다. 성적의 신뢰도를 반영해 출전 평가에 가중치 0.65로 반영하고 정규 표본이 쌓이면 영향이 줄어든다. WBC 차출 기간에는 명단에 오른 모든 선수가 시범경기에서 제외되며, 사용자가 참가를 사양하면 소속팀에 남는다.

청소년대표는 매년 9월, 학년 구분 없이 평판·기량 순으로 투수 상위 15명과 타자 상위 15명을 선발한다. 겸업도 한 분야에만 포함한다. 명단 발표 후에는 다시 추첨하지 않으며 실제 국제경기와 성적 기반 결산으로 진행한다.
