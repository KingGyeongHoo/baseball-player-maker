# 프로 WBC 국가대표 이벤트

- 2026년을 시작으로 2030·2034·2038년처럼 4년마다 3월에 개최한다.
- 3월 1일부터 20일까지 첫 진행 시 대표팀 명단을 확정한다. 기존 통보나 선택이 남아 있으면 먼저 처리하고 다음 적격 날짜에 초청한다. 기간이 지난 저장 파일에서는 지난 대회를 소급 재생하지 않는다.
- 선발은 기존 성인 대표팀 기준을 공유한다. 정식 계약의 구단 소속 현역이며, 부상·강제 휴식 없이 활동 가능하고 피로 80 미만이어야 한다.
- 3월에는 시즌 기록이 초기화되므로 **직전 연도 프로 1군 기록**으로 타자 100타석 또는 투수 90아웃(30이닝)을 확인한다. 2군·포스트시즌·고교·다른 연도의 기록은 대체 표본으로 사용하지 않는다.
- 조건을 만족하는 선수 중 현재 평판, 역할 능력, 선수 ID 순으로 선발한다. 선발투수 6명, 구원·마무리 6명, 포수 2명, 내야 각 1명, 외야 4명, 추가 야수 1명으로 최대 23명이다. 적격 선수가 부족하면 해당 자리는 비운다.

고교 국가대표처럼 `WBC 국가대표 발탁` 선택 이벤트를 연다. 참가하면 MVP 5%, 인상적인 활약 23.75%, 부상 23.75%, 경험 47.5%의 결과를 받는다. 각각 역할 핵심 능력 8주분·6주분·없음·4주분이며 평판 보상은 10·8·0·2점, 피로는 12·10·5·8이다. 부상은 보통 부상으로 14일 결장한다. 성장에는 기존 나이·재능·신고선수·성장 둔화·상한·각성 규칙을 적용하며 프로 이벤트 평판의 기존 상한을 유지한다.

참가하지 않으면 소속팀에서 컨택/제구 3주분 훈련(50%) 또는 피로 12 회복(50%)을 받는다. 불참에 따른 평판 감점은 없다.

대회 연도별 명단·선정일·참가 여부·결과를 저장한다. 선택 중 저장 후 불러오기와 자동진행 재개에서도 명단이나 결과를 재추첨하지 않는다. 결과는 기존 커리어 이벤트 기록에 남는다. 고교 대표팀과 시즌 종료 후 PE27 합동훈련은 별개의 사건이다.

WBC는 고교 국가대표와 같은 경험 이벤트로 처리한다. 별도의 국제대회 경기 기록을 만들거나 정규리그 성적·팀 승패·FA 공헌일에 합산하지 않는다.
