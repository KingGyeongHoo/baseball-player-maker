# 선수별 저장과 삭제

2026-11-10 적용.

- 같은 커리어의 자동 저장·수동 저장·파일 불러오기는 하나의 저장 슬롯을 덮어쓴다. 이름 대신 커리어 시드와 원래 선수 ID를 식별자로 사용하므로 이름 변경·고교에서 프로 전환 뒤에도 같은 슬롯을 유지하며, 동명이인의 별도 커리어는 합치지 않는다.
- 기존 저장소를 열면 중복된 자동·수동·불러온 저장 중 저장 시각이 가장 최근인 것만 남긴다. 다른 선수의 저장은 유지한다. 이 변경은 IndexedDB 버전 2의 단일 업그레이드 트랜잭션에서 처리하며, 외부 JSON 파일의 형식 버전은 기존 1을 유지한다.
- 저장함의 삭제 버튼은 확인·취소를 제공한다. 삭제는 자동 저장과 같은 작업 큐를 거치며, 이미 진행 중인 쓰기를 마친 뒤 삭제하고 아직 대기 중인 과거 저장은 삭제 요청으로 대체한다.
- 현재 플레이 중인 선수의 저장도 삭제할 수 있다. 진행 중인 플레이 데이터는 유지되며 이후 새로 진행하거나 저장하면 다시 자동 저장한다. 저장함 삭제는 브라우저 안의 저장 슬롯에 적용되며 내보낸 JSON 파일에는 영향을 주지 않는다.
- 검증: 기존 저장 중복 통합·최신 기록 선택, 자동/수동/파일 불러오기 덮어쓰기, 삭제 취소·선택 삭제·현재 선수 삭제 후 재확인, 다른 커리어 보존을 실제 IndexedDB와 UI에서 확인했다. 저장 ID·이전 파일 호환·대기 중인 저장과 삭제 순서의 회귀 테스트를 추가했다.

## 저장 시간 초과 복구

저장 워커는 준비 완료 신호를 받은 뒤 데이터를 전송한다. 8초 안에 시작되지 않거나, 메시지 전송·실행에 실패하거나, 작업 중 30초 동안 응답이 없으면 워커를 종료하고 현재 대기 작업을 직접 IndexedDB에 저장한다. 이 세션의 후속 저장·삭제도 같은 순차 큐에서 직접 처리한다. 실제 저장소 오류는 숨기지 않고 표시한다.

기존 저장소 업그레이드는 처리한 커서와 저장 요청의 진행 신호를 보내므로, 작업이 계속 진행 중일 때 응답 대기 시간을 갱신한다. 저장 완료 표시는 트랜잭션 완료 후에만 보낸다. 응답하지 않는 워커를 브라우저에서 주입하여 대체 자동 저장·수동 덮어쓰기·단일 슬롯 유지를 확인했고 정상 워커 저장도 별도로 확인했다.
