# 프로 투구 피로와 회복

프로 커리어의 국내 정규·포스트시즌·시범경기에 적용한다. 고교·대학과 별도 샌드박스로 진행하는 국가대표 경기는 기존 경기 피로 규칙을 유지한다. 프로 선수의 일일 회복은 모든 보직에 적용한다.

## 투구 수와 피로

프로는 아웃당 피로를 제거하고 타석별 추정 투구 수를 기록한다. 볼넷 최소 4구, 삼진 최소 3구, 인플레이 최소 1구에 결과별 변동과 제구 보정을 더한다. 경기·투수·타석 식별자로 만든 별도 결정적 해시를 사용해 기존 경기 결과 난수를 추가 소비하지 않는다. 실제 투구 로그를 재현하는 모델은 아니다. 새 기록의 `pitching.pitches`를 경기·시즌·커리어 합산에 보존하며 과거 경기에는 소급 생성하지 않는다.

구당 피로는 선발·중계·마무리 공통으로 `1.6 - (스태미나 - 50) × 0.024`다. 스태미나 50은 1.6, 75는 1.0, 100은 0.4이며 50 미만도 같은 기울기를 연장한다. 장비 반영 후 스태미나를 사용하고, 기존 스태미나 누적 배율을 중복 적용하지 않는다. 컨디셔닝 코치의 현재 피로 절반 효과는 유지하며 향후 아이템 변경 때 조정한다.

## 강판과 출전 제한

- 선발은 피로 80 이상에서 다음 타석 전에 교체한다. 스태미나 50 미만은 선발 등록·전환·등판 대상에서 제외한다. 기존 해당 선수는 RP·CP 중 적성이 높은 보직으로 조정하고 기록·능력은 유지한다. 새로 생성하는 프로 선발 전용 보강 선수는 최소 스태미나 50으로 생성한다.
- 불펜·마무리는 피로 20 이상에서 다음 타석 전에 교체하며, 등판 전부터 20 이상인 선수는 투입하지 않는다.
- 타석을 중간에 끊지 않으므로 실제 종료 투구 수·피로가 계산상 한도를 넘을 수 있다. 별도 100구·120구 상한은 없다.
- 불펜은 등판 시작 때 `floor((20 - 시작 피로) / 보정된 구당 피로)`를 투구 여력으로 고정한다. 매 이닝 본인이 던진 공이 이 값의 30% 이하이면 다음 이닝도 가능하며, 초과하면 다음 이닝 전에 교체한다. 피로는 이닝 사이에 회복시키지 않는다. 20구 여력에서 5구·4구·6구는 각각 통과하고 7구는 다음 이닝 강판이다. 부분 이닝 투입에도 본인의 해당 이닝 투구 수만 사용한다.
- 기존 무작위 선발 4~8이닝·불펜 1~3이닝 상한과 불펜 부족에 따른 이닝 연장은 제거한다. 실점 강판(선발 12타자·4실점, 불펜 5타자·2실점), 부상, 마무리 투입, 2군 평가 등판은 유지한다. 투입 가능한 후속 투수가 없을 때는 기존 경기 진행 불가 처리를 사용하며 피로·이닝 강판을 우회하지 않는다.
- 선발 최소 4일 휴식·5선발 로테이션, 불펜 2일 연속 등판 후 하루 휴식은 유지한다.

## 회복과 훈련

프로의 하루 회복량은 장비 반영 후 `회복력 × 0.4`다. 무훈련·새 경기 부하가 없으면 회복력 50은 4일, 100은 2일에 피로 80을 회복한다. 기존 훈련 배분 계산의 양수 부하는 유지하고 음수 회복 부분을 이 고정 일일 회복으로 대체한다. 훈련 부하를 먼저 반영하고 회복하며, 실제 남은 피로까지만 회복한다. 부상 위험에는 회복 전 훈련 피로도 반영한다. 비시즌 날짜 건너뛰기에도 같은 일일 회복량을 적용한다. 기존 비율 회복을 중복 적용하지 않는다.

## 저장과 조정

`matchProgress.proPitchWorkload`에 등판별 구당 피로·투구 여력·현재 이닝 투구 수·다음 이닝 강판 여부를 보관한다. 중간 선택과 저장/불러오기는 이를 재사용한다. 구버전 진행 경기에서는 현재 피로에서 상태를 만들고, 이미 끝난 타석의 투구 수나 피로를 소급 적용하지 않는다. 완성된 과거 경기 기록은 변경하지 않는다.

설정은 `lib/sim/pro-pitching-fatigue.ts`의 `proPitchingFatigueRules`, 타석별 추정은 `estimatedProPitches`에 있다. 전체 시즌 밸런스 검증은 별도로 수행하지 않았다.
