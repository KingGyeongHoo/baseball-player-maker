# 평가 기준을 반영한 평판

2026-11-06 · `evaluation-reputation-v1`

고교·프로 평가의 역할 기량과 보정 성적을 실제 평판에 연결했다. OVR은 기존대로 일반 선수의 주력 분야 평균, 겸업 선수의 투수·타자 OVR 평균이며 최대 100이다. 평판을 계산해도 능력치나 OVR은 바뀌지 않는다.

## 기량과 성적

기량은 해당 역할의 기존 능력 가중치로 계산한다. 선발은 투구 능력·스태미나, 포수는 포수 역할 능력처럼 역할에 필요한 구성으로 평가한다. 피로·일시 부상, 숨겨진 재능과 미래 성장 시나리오는 기량 점수에 더하지 않는다. 20–80 툴을 OVR이나 평판에 그대로 넣지도 않는다.

```text
성적 반영 비중 = 0.4 × 성적 신뢰도
분야 평가 = 역할 기량 × (1 − 성적 반영 비중)
          + 보정 성과 × 성적 반영 비중
평판 = 분야 평가 + 이벤트·프로 경력·실제 겸업 참여 보너스
```

평판은 0~100으로 제한한다. 충분한 표본에서는 기량 60%·성적 40%에 가까워지고, 표본이 적으면 성적 비중을 줄여 기량에 배분한다. 실전 근거가 없으면 성과를 가상 50점으로 채우지 않고 역할 기량을 쓴다. 레거시 `performanceReputation` 숫자만으로 실전 근거가 있다고 판단하지 않는다.

성적 계산은 평가 리포트와 동일한 `performanceEvidence`를 사용한다. 타격은 사건별 분모로 보정한 OPS, 투구는 BF 기준 삼진·볼넷·피홈런을 동일 레벨 리그와 비교한다. 사전 표본은 고교 사건/안타/추가루타 60/90/150, 프로 50/90/150이다. 신뢰도는 `표본 / (표본 + 사건 사전 표본)`이다.

올해·전년·전전년의 사건 수와 분모를 6:3:1로 합산하며 빈 연도는 제외한다. 진급·시즌 초기화로 지난 실제 기록을 지우지 않는다. 과거 리그 기준은 보관된 당시 자료를 우선하며, 없는 과거 성적·시찰 기록을 만들지 않는다. 공식 기록 자체는 변경하지 않는다.

## 프로 1·2군

1군과 2군의 기록·리그 기준을 섞지 않는다. 같은 성적이라도 각 리그 환경에 맞게 평가하고 다음처럼 근거를 합친다.

```text
1군 근거 비중 = 1군 신뢰도
2군 근거 비중 = (1 − 1군 신뢰도) × 2군 신뢰도 × 0.5
성적 신뢰도 = 1군 근거 비중 + 2군 근거 비중
보정 성과 = 위 두 비중으로 평균한 성과
```

2군 성과의 상한은 70이다. 2군만 뛰었다면 성적이 평판에서 차지하는 비중은 최대 20%에 접근한다. 1군 표본이 늘면 1군 근거가 점차 우선되며 100PA·30IP에서 2군 근거를 갑자기 버리지 않는다. 승격·강등만으로 기록의 레벨이나 평가가 바뀌지 않는다.

## 겸업과 보너스

겸업은 투수 역할과 타자 역할을 각각 평가해 평균한다. 한쪽의 많은 출전량으로 반대쪽의 신뢰도를 채우지 않는다. 단일 역할로 전환해도 반대 분야 기록은 남고, 새 역할에서는 그 분야의 근거를 사용한다.

이벤트 평판, 프로 경력 보너스, 실제 투타 참여로 얻는 겸업 보너스는 기존 규칙대로 한 번만 더한다. 기존 기록과 보너스는 진급 시 초기화하지 않는다.

## 실제 게임에 미치는 영향

- 드래프트의 평판 80%·재능 10%·적합도 10% 합산은 유지하지만, 새 평판이 입력되므로 예상·실제 지명 순위는 바뀔 수 있다.
- 국가대표의 기존 평판 순위 기준과 정확히 23명인 자격 규칙은 유지한다. 새 평판이 순위에 반영된다.
- 계약의 기존 평판 5% 입력에도 영향을 준다. 출전·등록·계약의 다른 계산식을 별도 새 모델로 교체하지는 않는다.
- 프로 신인 후보 생성에도 같은 역할 기반 평판을 사용한다.

대시보드에 보정 성과와 실제 성적 반영 비중을 표시하고, 선수 평가 모달에서 역할별 기량·성과·비중·보너스를 확인한다. 날짜가 있는 평가에는 당시 평판 근거도 함께 저장한다. 이전 평가에 근거가 없으면 새 점수를 과거 값처럼 소급해 표시하지 않는다.

구버전 저장은 다음 진행 시 실제 남아 있는 기록으로 평가를 갱신한다. 평가 계산은 RNG를 소비하지 않으며 능력·기록을 변경하지 않는다.

## 검증 기록

전체 271개 회귀 검사를 실행해 3년 고교 커리어·프로 생활·지명·이벤트를 확인했다. 중립 성과 50점이 가중 계산의 부동소수 오차로 49.99999999999999가 되는 1건을 발견했고, 실제 수치를 반올림하지 않고 비교 차이의 계산 오차만 제거했다. 수정 후 관련 78개와 해당 중립 성과 검사를 재실행해 모두 통과했다. 타입 검사·lint·프로덕션 빌드를 통과했고, 실제 브라우저의 1주 진행·평판 설명·OVR 유지·390px 모달 표시를 확인했다.

로그: `test-results/reputation-all-final.log`(오차 수정 전 전체 실행), `reputation-final-check.log`(수정 후 78개), `reputation-neutral.log`, `reputation-lint-final.log`, `reputation-types-final.log`, `reputation-build-final.log`.
