# 신규 선수 포지션 비율

2026-11-16부터 고교 신입생, 프로 시즌별 드래프트 후보 생성, 시작 화면의 랜덤 고교·프로 선수에 같은 분포를 사용한다.

| 분류 | 비율 | 1,000명 기준 |
|---|---:|---:|
| 선발투수 | 17.5% | 175명 |
| 불펜투수 | 32.5% | 325명 |
| 포수 | 10% | 100명 |
| 내야수 | 20% | 200명 |
| 외야수 | 20% | 200명 |

불펜은 중간계투 275명·마무리 50명으로 나눈다. 내야수는 1루·2루·3루·유격수, 외야수는 좌·중·우익수에 배분한다. 자동 생성에는 지명타자를 넣지 않으며 직접 선택은 지원한다. 단일 랜덤 시작은 이 확률로 추첨하고, 후보군 전체는 정수 인원으로 배분한 뒤 섞는다. 지명 선수는 구단 수요와 기존 드래프트 평가에 따라 선택하므로 지명 결과의 비율을 강제하지 않는다.

고교는 학교별 신입생 10명 중 포수 1명·내야수 2명·외야수 2명·투수 5명을 배정한다. 학교와 입학 연도별 순환 배치로 전체 선발·불펜 비율을 맞추고, 세 학년이 함께 있을 때 전 수비 위치와 선발 5명 이상·마무리 1~2명을 확보한다. 시작 선수를 직접 선택하면 해당 선수의 포지션을 우선하며, 기존 저장의 생존 선수는 재배정하지 않는다.

포지션 배치는 독립된 시드 난수를 사용한다. 재능을 배정할 때와 실제 선수를 만들 때 같은 포지션표를 사용하며 기존 경기·훈련·드래프트 난수 스트림을 포지션 추첨에 소비하지 않는다.
