# 프로 포스트시즌

2026-11-09 사용자 지정. 새로 시작하는 포스트시즌은 정규리그 상위 5팀의 계단식 대진이다.

| 단계 | 대진 | 승리 조건 |
|---|---|---|
| 와일드카드 | 4위 대 5위 | 4위는 1승을 선취한 상태로 2선승, 실제 최대 2경기 |
| 준플레이오프 | 3위 대 와일드카드 승자 | 5전 3선승 |
| 플레이오프 | 2위 대 준플레이오프 승자 | 5전 3선승 |
| 한국시리즈 | 1위 대 플레이오프 승자 | 7전 4선승 |

- 와일드카드는 모두 4위 홈이다. 4위는 한 경기 승리 또는 무승부로 진출하며, 5위는 두 경기 모두 이겨야 한다. 선취 1승은 시리즈 점수에만 포함하며 실제 경기·선수 기록을 생성하지 않는다.
- 준플레이오프·플레이오프는 높은 순위 팀 홈 1·2·5차전, 한국시리즈는 정규 1위 팀 홈 1·2·6·7차전이다. 나머지 경기는 상대 홈에서 치른다. 구장 이동과 시리즈 사이에는 최소 하루 쉰다.
- 포스트시즌 연장은 최대 15회다. 와일드카드 외의 무승부는 승수를 올리지 않고 기록을 유지한다. 정규 편성 차전 뒤에 무승부가 발생한 홈구장에서 추가 경기를 순서대로 편성한다. 기권은 상대의 승리로 처리한다.
- 승자 확정 뒤에만 다음 단계를 생성한다. 1·2·3위 팀은 자기 단계까지 기다린다. 같은 날짜의 정산을 반복하거나 저장 후 재개해도 승수·경기·다음 대진을 중복 생성하지 않는다.
- 각 시리즈 개막 시 정식 선수 30명 이하의 고정 명단을 별도로 잡는다. 부상 대체와 대체된 선수의 재등록 제한은 기존 규칙을 유지한다.
- 정규리그·2군 기록과 포스트시즌 기록은 분리한다. 우승 확정 후 한 번만 시즌 결산·연봉 정산·커리어 보관을 진행한다.

## 화면

메인 대시보드와 리그에서 같은 대진표를 사용한다. 아직 시작하지 않은 단계도 직행 팀과 앞 단계 승자 자리를 보여준다. 현재 대진·시리즈 승수·다음 경기 날짜·진출 결과를 표시하고, 시즌 결산 때 우승 결과를 유지한다.

프로 상단 메뉴의 `훈련 센터`와 메인 상세 능력치의 `훈련 설정` 버튼은 같은 별도 페이지로 이동한다. 고교와 공통 화면을 사용해 주간 훈련 배분·경기 성향·선수 능력·성장 그래프·저장 버튼을 표시하며, 진행 중 설정 변경 제한은 유지한다.

## 기존 저장

새 포스트시즌에는 `format: kbo-v1`을 기록한다. 진행 중인 기존 4팀 포스트시즌도 즉시 새 5팀 대진으로 전환한다. 기존 대진·경기·포스트시즌 기록은 `proWorld.replacedPostseason`에 백업하고 새 공식 대진의 기록에서는 제외한다. 정규 기록·능력·계약·과거 커리어·난수 상태는 유지하며 오래된 경기/주간 커서는 정리한다. 이미 시즌 결산까지 끝난 과거 시즌은 다시 시작하지 않는다.

승률·승수가 같은 팀의 순위결정전이 남아 있으면 정규 시즌에 머물러 그 경기를 먼저 마친다. 1~5위가 확정된 뒤 포스트시즌을 시작한다. [순위와 일정 규칙](league-standings.md)을 함께 따른다.
