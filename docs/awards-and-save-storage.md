# 프로 수상과 저장 용량

신인왕은 입단한 해를 포함해 5시즌 이내이며 직전 시즌까지의 1군 통산 기록이 타자 60타석 이하, 투수 30이닝 이하인 선수 중 한 명을 선정한다. 수상 시즌에는 1군 규정 표본(타자 447타석, 선발 144이닝, 불펜 48이닝)을 채워야 한다. 분야별 실제 성적과 출전량으로 비교하며 나이·고교/육성 출신·첫 데뷔 연도로 제한하지 않는다.

12월 시상식은 MVP → 신인왕 → 골든글러브 순서다. 발표된 수상은 MVP +3, 신인왕 +2, 골든글러브 +2점을 현재 출전평가에 반영하며 수상 보너스의 합계는 최대 10점이다. 시즌·상 종류별 장부로 중복 적용을 막는다. 공식 경기 기록과 이미 확정된 시즌 WAR는 바꾸지 않는다.

시상식 모달을 닫으면 내 MVP → 신인왕 → 포지션 골든글러브 수상 모달을 각각 확인한다. 타이틀은 노란색으로 표시하고 보너스와 실제 출전평가 변화를 보여준다. 상한에 걸리면 실제 반영량을 안내한다. 수상이 없으면 별도 모달을 만들지 않으며 마지막 수상 확인 뒤 다음 시즌 안내로 넘어간다. 진행 위치와 남은 수상 모달은 저장된다.

와일드카드·준플레이오프·플레이오프·한국시리즈도 각각 승리 팀의 실제 시리즈 기록으로 MVP 한 명을 선정한다. 시리즈별 출전평가 +1점이며 정규시즌 수상과 합친 보너스 상한은 +10점이다. 대진표·어워드의 포스트시즌 MVP 탭·커리어에 기록한다. 실제 출전 기록이 없는 기권 시리즈에는 수상자를 만들지 않는다. 이전 시즌 경기 자료가 남지 않은 경우 시리즈 MVP를 추정해 만들지 않는다.

1·2군 타자 개인 타이틀은 타격왕·안타왕·홈런왕·타점왕·도루왕이다. 홈런은 안타에 포함되며 타율은 총 안타/타수로 계산한다. 예전 저장의 누락된 홈런왕과 신인왕은 남아 있는 해당 시즌 기록으로 복원한다. 기존 MVP·골든글러브와 경기 결과는 재추첨하지 않는다. 자료가 남지 않은 선수의 기록은 만들어내지 않는다.

2군 소속은 2군 포스트시즌 대진·안내를, 1군 소속은 1군 대진·안내를 본다. 두 대회는 각각 진행하며 늦어진 2군 일정 때문에 1군 개막을 미루지 않는다. 양쪽 일정이 끝난 뒤 시즌을 결산하고 포스트시즌 기록은 정규시즌과 분리한다.

## 저장

- 내 선수의 스카우팅·평가·능력 이력·연도별 기록은 보존한다.
- 다른 선수의 상세 평가·스카우팅 리포트는 생성·보관하지 않는다. 현재 능력과 출전·승격·계약 판정은 유지한다.
- 다른 선수의 지난 시즌은 연도·소속·최종 기록과 1/2군·포스트시즌 구분을 남긴다. 과거 능력 스냅숏·구단별 중복 분할·시범경기 기록은 정리한다. 예전 프로 기록의 능력 스냅숏은 확정 연간 평가를 복원한 뒤 정리한다.
- 겸업이 아닌 다른 선수의 사용하지 않은 반대 분야 0 기록은 파일에서 생략하고 읽을 때 복원한다. 실제로 뛰었던 전향 전 반대 분야 기록은 보존한다.
- 파일 형식 2는 `recordEncoding: npc-single-role-v1`로 생략을 표시하고 저장된 표현 자체의 체크섬을 검증한다. 예전 형식 1도 읽는다.
- 파일 내보내기와 IndexedDB는 gzip을 사용한다. 목록 정보는 별도로 남겨 저장 목록을 열 때 전체 압축을 풀지 않는다. 압축 API가 없는 브라우저는 JSON 저장을 사용한다.

원본을 유지하면서 수상 기록과 저장 형식을 갱신하려면 `npm run test:compile`과 `npx tsc -p tsconfig.creation-tests.json` 후 다음을 실행한다. 출력 경로가 이미 있으면 중단한다.

```sh
node scripts/upgrade-season-awards-save.mjs 원본.json 새저장.json
```

## 국제대회 표시

WBC·올림픽은 조별리그와 단계별 토너먼트를 표시한다. APBC는 4팀 단일 조 뒤 결승·3위전을 가로로 표시한다. 프리미어12는 12팀 A·B조 → 각 조 상위 2팀의 단일 슈퍼라운드 → 결승·3위전으로 진행하며 각 라운드는 별도 탭으로 표시한다. 단일 조에는 조 선택 메뉴를 표시하지 않는다. 이미 편성된 예전 프리미어 대회의 4개 조·2차 라운드와 실제 결과는 보존한다. 조별리그·슈퍼라운드 결과는 날짜순으로 묶어 세로로 표시한다. 토너먼트는 라운드별 영역과 제목을 분리하고 결승은 남색·금색, 3·4위전은 동색 카드로 구분한다.


외국 선수는 대회가 시작될 때만 생성한다. 대회별 국가 전력 기준에서 새로 생성하며 이전 청소년 대회의 낮은 능력을 이어받지 않는다. 새 성인 대회의 한국 대표팀은 경기 계산 때만 능력 2% 하향 보정을 적용하며 실제 선수 능력을 깎지 않는다. 이미 완료한 대회의 결과·수상·한국 대표팀 개별 기록은 바꾸지 않는다.

대회 종료 후 외국 선수 개체·개별 박스스코어·경기 준비 명단을 정리한다. 국가 이름·대진·날짜·최종 스코어·진출·수상자 이름은 보관한다. 기존 저장도 완료된 대회의 외국 선수 데이터를 같은 방식으로 정리하고 진행 중인 대회는 보존한다.

고교 대회도 조 순위·라운드별 대진과 결승 카드 스타일을 통일하고 학교의 실제 마지막 경기에서 16강·8강·4강 탈락, 준우승·우승을 판정한다. 부전승이 있는 대회는 전체 대진 크기와 라운드 번호를 사용하고 진행 중인 경기는 탈락으로 처리하지 않는다.

국가대표 커리어는 실제 대회 명단을 우선하여 올림픽·WBC·프리미어12·APBC 이름과 선발·참가·출전·불참을 구분한다. 해당 대회 기록이 있으면 예전 공통 PE27 이벤트를 별도 합동훈련 이력으로 중복 표시하지 않는다.

11월 국제대회는 포스트시즌 종료·우승 안내 → 국대 발탁 및 차출 수락·거부 → 프리미어12/APBC 참가 버튼 → 대회 결산 → 스토브리그 시작 순서다. 커리어와 하단 진행 영역에 대회별 참가 버튼을 표시하고, 미참가자는 결과 확인 버튼을 표시한다. 시즌 종료 안내를 확인하면 선발된 선수에게 발탁 선택창을 표시한다. 수락 결과를 확인한 뒤에는 아직 경기를 진행하지 않고 대회 참가 버튼을 표시한다. 그 버튼을 누르면 대회를 자동 진행한다. 거부하면 소속팀에 남으며 결과 확인 버튼으로 본인 기록 없이 대회 결과만 정리한 뒤 스토브리그로 넘어간다. 옛 저장에서 발탁 선택창을 놓쳤으면 참가 버튼에서 수락·거부를 먼저 복구한다. 준비·휴식 선택지는 만들지 않는다. 경기별 고정 추첨으로 승부처 후보 20%, 선택지 없는 경기 80%를 배정하며, 승부처는 실제 7회 이후 2점 차 이내에서 본인 타석·등판 때만 발생하므로 실제 빈도는 더 낮다. 고교 대회 결승과 국제대회 금메달 결정전에는 경기 시작 전 야구 승부 계획 이벤트를 한 번 보장한다. 국제대회 3·4위전은 이 보장 대상이 아니다. 결승 선택의 작은 확률 보정은 해당 경기 본인 타석·등판에만 적용한다. 국제대회 한 경기에는 최대 한 선택지만 뜨며 저장·불러오기나 다음 타석에서 재추첨하지 않는다. 선택 결과를 확인하면 자동 진행을 이어간다. 시즌 중 WBC·올림픽도 참가를 수락하면 자동 진행을 켜며, 이후 직접 일시정지한 상태는 이벤트 확인으로 다시 켜지 않는다. 대회 결산 후에는 스토브리그 시작 버튼을 표시한다. 그 전에는 계약 협상·스토브리그·캠프로 건너뛰지 못한다. 대회 진행 의도와 중단 위치를 저장하므로 불러온 뒤에도 남은 결과를 확인하고 이어간다. 계약을 자동 수락하거나 스토브리그를 자동 개장하지 않는다.

겸업 선수의 청소년대표·WBC·올림픽·프리미어12·APBC 발탁 선택창은 투수 참가·타자 참가·차출 거부 세 가지다. 참가 분야는 대회 명단과 실제 기용에 반영하고 저장한다. 소속팀 포지션·겸업 설정·기록은 바꾸지 않는다. 미결정 상태의 예전 발탁 선택창도 불러오면 참가 분야 선택지를 보완한다. 청소년대표 MVP와 국제대회 MVP는 개인수상으로 분류하며 국가대표 선발 이력과 시즌 MVP 집계와 구분한다.
