# 이벤트 확률 및 선택지 기준

도전·안정으로 일괄 분류하던 구성을 제거한다. 선택지에는 구체적인 행동을 표시한다.

- 일반 경기·훈련 이벤트의 각 행동 결과는 50:50으로 추첨한다. 단일 확정 결과였던 행동도 기존 결과 50%, 변화 없음 50%로 처리한다.
- 잘못 일괄 변경했던 기존 이벤트의 행동·보상·하락량은 원래 정의를 우선 복원한다. 기존 선택지 간 결과를 다르게 만든 수정과 경기의 타석·타자 확률 효과는 보존한다.
- 신규 훈련 이벤트의 고정 능력치 -2 하락은 -0.3으로 줄인다.
- 희귀 성장 예외는 보존한다. T10 트레이닝 센터와 PE08 집중 캠프의 폭발 성장은 기존 5%, 청소년 대표 및 국가대표 특수 사건도 고유 확률을 유지한다. 별도 각성 확률 5%도 유지한다.
- 훈련·경기 이벤트의 추가 피로 상승은 제거한 상태를 유지한다. 외부 일정의 피로·부상·신체·야구 지능 효과는 별도로 유지한다.
- 이미 확정된 이벤트 이력은 재추첨하지 않는다. 미선택 구버전 이벤트는 보상 버전 4의 선택지로 갱신한다.

이 문서가 이전 문서에 남아 있는 도전 35%·안정 85% 안내보다 우선한다.
