# 이벤트 확률 및 선택지 기준

도전·안정으로 일괄 분류하던 구성을 제거한다. 선택지에는 구체적인 행동을 표시한다.

- 일반 경기·훈련 이벤트의 각 행동 결과는 50:50으로 추첨한다. 단일 확정 결과였던 행동도 기존 결과 50%, 변화 없음 50%로 처리한다.
- 도전/안정은 타격폼 대개조(T21), 새로운 결정구(T22), 이중 키킹으로 만드는 균형(PE33), 슬라이더를 스위퍼처럼(PE36), 큰 레그킥을 토탭으로 줄이기(PE54), 구속 향상 프로젝트(PE76), 장타 생산 방식 변경(PE77)의 7개에만 적용한다. 도전은 성공 35%·실패 65%, 안정은 성공 85%·실패 15%다. 성공 보상은 각각 해당 능력 8주분·3주분이며 실패 손해는 해당 이벤트의 기존 정의를 유지한다. 선택지에는 구체적인 동작을 표시한다. 일반 기술 연습·외부 활동·경기 전략을 이 방식으로 일괄 변경하지 않는다.
- 성공·실패로 나뉜 일반 이벤트는 선택 행동의 관련 능력치에 따라 성공 확률을 보정한다. 보정은 `(관련 능력치 - 50) × 0.5%p`이며 능력치 0~100에서 -25~+25%p다. 기본 50%는 능력치 0일 때 25%, 50일 때 50%, 100일 때 75%다. 도전 35%·안정 85%에도 같은 보정을 적용하고 최종 성공률은 0~100%로 제한한다. 실패 확률은 나머지다.
- 장타·강한 스윙은 파워, 정확한 타격은 컨택, 도루는 스피드, 강한 공·삼진 승부는 구속, 코스 승부는 제구, 변화구 승부는 변화구를 본다. 훈련은 해당 선택에서 성장하는 능력을 사용하고 여러 능력을 함께 훈련하면 평균을 사용한다. 피로 보정 전 실제 능력치를 사용하며, 겸업은 해당 이벤트의 투수·타자 분야를 따른다. 참가·거절 등의 진로 결정, 두 결과가 모두 유익한 선택, 확정 결과, 캠프의 희귀 성장 및 별도 각성 확률은 유지한다. 추가 추첨 없이 원래 결과 추첨 한 번에 반영하며 미선택 저장에도 적용한다.
- 잘못 일괄 변경했던 기존 이벤트의 행동·보상·하락량은 원래 정의를 우선 복원한다. 기존 선택지 간 결과를 다르게 만든 수정과 경기의 타석·타자 확률 효과는 보존한다.
- 신규 훈련 이벤트의 고정 능력치 -2 하락은 -0.3으로 줄인다.
- 희귀 성장 예외는 보존한다. T10 트레이닝 센터와 PE08 집중 캠프의 폭발 성장은 기존 5%, 청소년 대표 및 국가대표 특수 사건도 고유 확률을 유지한다. 별도 각성 확률 5%도 유지한다. 비시즌 합동 캠프(PE84)는 T10과 같은 참가·불참 구조다. 참가 시 5%로 전체 11개 능력 각각 8주분, 95%로 현재 역할 핵심 능력 각각 4주분을 지급한다. 불참 시 50%로 정교함 3주분, 50%로 피로 10 회복이다. 기존 1·2·11·12월 경기 없는 날 조건을 유지하고 시즌당 한 번만 제안한다. 야구 집중 훈련으로 분류한다.
- 훈련·경기 이벤트의 추가 피로 상승은 제거한 상태를 유지한다. 외부 일정의 피로·부상·신체·야구 지능 효과는 별도로 유지한다.
- 이미 확정된 이벤트 이력은 재추첨하지 않는다. 일반 이벤트의 버전 4 갱신을 유지하며, 위 7개와 PE84의 미선택 버전 4 저장만 버전 5로 갱신한다. 기존 대표팀·후속 결정은 유지한다.

## 고교 학기·방학 구분

겨울방학은 1~2월, 여름방학은 7~8월로 처리하며 나머지는 학기다. 고교 카탈로그의 모든 이벤트는 `schoolPeriod`로 발생 시기를 명시한다.

| 구분 | 이벤트 |
| --- | --- |
| 학기 전용 | 축구부와 친선경기(X01), 육상부 합동훈련(X02), 체육대회 계주(X03), 친구와 걷는 귀갓길(L08) |
| 방학 전용 | 프로 선수의 트레이닝 센터(T10), 타격폼 대개조(T21), 새로운 결정구(T22), 선배의 개인 레슨(X04) |
| 공통 | 나머지 일반 훈련·경기·대회·가족 상담·휴식 이벤트 |

기존 경기·훈련일·포지션·피로·재등장 간격 조건도 함께 적용한다. 주간 예약은 현재 날짜가 아니라 실제 발생 예정일의 학사 구분을 사용한다. 이전 저장에 남은 미발생 예약이 구분과 맞지 않으면 실행하지 않으며, 이미 표시한 선택지와 확정 이력은 유지한다. 1~2월 트레이닝 센터의 학년당 한 번 보장도 유지한다. 프로 이벤트에는 이 학사 구분을 적용하지 않는다.


도전 35%·안정 85%는 위 7개에만 적용하며, 과거의 일괄 적용 안내보다 이 문서가 우선한다.
