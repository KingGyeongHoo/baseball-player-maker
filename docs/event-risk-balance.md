# 이벤트 선택과 보상 개편

2026-11-23. 고교 10개, 프로 12개를 추가했다. 전체 카탈로그는 고교 70개, 프로 87개다.

## 선택 구조

신규 이벤트와 기존 일반 기술 훈련은 도전 성공 35% / 실패 65%, 안정 성공 85% / 실패 15%를 사용한다. 기술 훈련의 성공 보상은 각각 8주분 / 3주분, 실패 손해는 각각 능력치 -2 / -0.3이다. 기존 재능·성장 둔화·능력 상한·각성 규칙을 적용한다. 대표팀 초청, 트레이닝 센터, 보직 변경 등 별도 커리어 결정의 고유 분기는 유지한다.

선택 전에는 행동만 표시하고, 선택 후 실제 결과와 변화량을 보여준다. 이미 저장된 선택과 확정 이력은 다시 추첨하지 않는다.

## 효과의 구분

- 훈련: 실제 능력치 성장·하락. 이벤트에 붙었던 추가 피로는 제거한다. 기본 훈련·경기 피로 계산은 유지한다.
- 경기: 영구 능력치와 추가 피로를 바꾸지 않는다. 해당 타석의 확률 보정과 고교 평판 / 프로 출전평가 보정만 적용한다. 도전은 평가 ±0.6, 안정은 +0.15 / -0.1이다. 안타·홈런·아웃 자체는 기존 경기 엔진이 판정한다.
- 외부: 피로·야구 지능·스태미나·회복력·경미한 부상만 사용한다. 평판·출전평가를 직접 지급하지 않는다. 경기 없는 훈련일 또는 휴식일에 등장하며 비시즌 캠프는 1·2·11·12월에만 등장한다.

프로 경기 평가 보정은 선수의 별도 저장 필드 `professional.eventSelectionBonus`에 누적하며 -5~+5로 제한한다. 실제 출전 경쟁 점수에 더하지만 국대 선발 점수, WAR, 경기 기록에는 더하지 않는다. 평판을 부활시키거나 출전을 확정하지 않는다. 결과 화면에는 실제 적용된 보정량을 표시한다.

## 신규 목록

| 구분 | ID | 이벤트 |
| --- | --- | --- |
| 고교 훈련 | T21, T22 | 타격폼 대개조, 새로운 결정구 |
| 고교 경기 | G07, G08 | 득점권 승부, 중심타선과 정면승부 |
| 고교 외부 | X01~X06 | 축구부 친선경기, 육상부 합동훈련, 체육대회 계주, 선배의 개인 레슨, 친구들과 나들이, 가족 상담 |
| 프로 훈련 | PE76~PE78 | 구속 향상 프로젝트, 장타 생산 방식 변경, 수비 범위 확장 |
| 프로 경기 | PE79~PE81 | 상대 에이스의 승부구, 만루 위기의 승부, 한 점 차 도루 승부 |
| 프로 외부 | PE82~PE87 | 팬 사인회, 방송 출연, 비시즌 합동 캠프, 자선 스포츠 행사, 후배와 개인 훈련, 후원사 회복 장비 테스트 |

G07은 득점권에 주자가 있는 자기 타석, PE79는 상대 구위가 높은 타석, PE80은 만루 등판에서 등장한다. PE81은 한 점 차 경기에서 본인이 1루 주자이고 2루가 비었을 때 등장한다. 도루 선택은 다음 실제 도루 판정 한 번에만 적용되며 SB/CS 기록은 그 판정으로 결정한다. 중단 커서를 저장해 선택 전후에 타석이나 도루가 중복 실행되지 않게 한다.

기존 일상 13개도 재설계했다. 예를 들어 집에서 온 전화는 상담을 통한 야구 지능 성장과 휴식을 통한 피로 회복으로 선택 목적을 구분한다. 활동 실패는 큰 피로, 휴식 실패는 작은 피로를 준다. 외부 이벤트 수가 늘어도 일반 주간 추첨의 야구 90% / 일상 10% 비율은 유지한다.
