# 프로 시즌 중 훈련

프로 정규리그 시작일(1·2군 중 빠른 날짜)부터 시즌 결산 전까지 집중 능력치 하나와 강도만 선택한다. 포스트시즌에도 적용한다. 고교·대학·프로 캠프와 비시즌은 기존 티켓 배분을 사용한다.

## 초기 수치

`lib/sim/pro-training.ts`의 `proTrainingRules`에서 조정한다.

| 강도 | 기존 훈련 성장 배율 | 하루 훈련 피로 최대 |
|---|---:|---:|
| 회복 위주 | 0.25 | 0 |
| 기본 | 0.65 | 2 |
| 추가 훈련 | 1 | 8 |

경기 중심 진행을 위해 기본 훈련의 성장과 피로를 낮추고, 추가 훈련은 기존 성장 수준을 제공한다. 경기 출전일은 기존 참여율 0.25, 벤치일 0.75를 성장과 훈련 피로에 적용한다. 예를 들어 기본 훈련은 출전일 피로 +0.5, 추가 훈련은 +2다. 비출전 선수도 훈련 성장 기회를 유지한다.

내부 배분은 자기 분야와 피지컬 각 1, 선택한 집중 항목 5로 환산한다. 겸업 선수는 양쪽 분야를 포함한다. 기존 재능·연령·아이템·성장 제한을 그대로 거치며, 재활 시 부위별 제한을 적용한 뒤 성장/부하를 줄인다. 훈련 부상 노출도 강도에 비례한다. 경기 경험에 따른 별도 성장 보너스는 이번 변경에서 추가하지 않았다.

훈련일에 실제로 훈련했을 때만 훈련 피로를 더한다. 휴일·올스타 휴식·치료·강제 휴식·훈련 생략에는 더하지 않는다. 경기 피로는 별도이며, 하루 종료 시 기존 `회복력 × 0.4` 회복과 컨디셔닝 코치 보정을 적용한다. 회복 위주는 출전을 막는 `mode: rest`와 다르다.

## 저장과 전환

`Policy.proSeason`에 집중 항목과 강도를 저장한다. 기존 `tickets`는 비시즌용으로 보존하며 비시즌에서 배분을 수정해도 시즌 설정은 유지한다. 기존 세이브는 가장 많이 배분했던 자기 분야 항목과 기본 강도를 사용하고, 첫 시즌 주간 진행/설정 저장 때 기록한다. 기존 명시적 휴식 설정은 회복 위주로 전환하며 이전 배분을 보존한다. 진행 중인 주간 저장은 기존 정책으로 재개한 뒤 다음 주부터 이 전환을 적용한다.

NPC도 같은 시즌 훈련/성장/피로 계산을 쓰며, 기존 자동 배분에서 집중 항목을 고르고 피로 60 이상은 회복 위주로 조절한다. 피로 60은 `proTrainingRules` 인접 설정에서 조정한다.

화면은 주간 순회복 게이지 대신 일일 최대 회복과 훈련 피로를 표시한다. 출전일·재활에는 실제 훈련 피로가 표시된 최대치보다 낮다.
