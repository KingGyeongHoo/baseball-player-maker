# 순위와 프로 일정

2026-11-09 사용자 지정.

## 순위

- 승률은 `승 / (승 + 패)`이며 무승부는 분모에서 제외한다. 경기는 승·패·무 합계다.
- 승률 내림차순, 승수 내림차순으로 비교한다. 승점과 득실차는 순위에 쓰지 않는다.
- 두 값이 같으면 시즌 중에는 같은 순위와 `T`를 표시한다. 정규 일정이 끝난 뒤 실제 타이브레이커 경기로 최종 순위를 결정한다. 팀 번호는 동률 행을 안정적으로 나열하는 데만 쓰고, 최종 진출 순위를 결정하지 않는다.
- 다팀 동률은 실제 경기 승패를 이용한 순위 삽입 방식으로 해결한다. 새 팀을 기존 결정 순서의 중간 팀과 붙이고 이기면 위 구간, 지면 아래 구간과 다음 경기를 치러 위치를 확정한다. 무승부는 보관하고 재경기를 편성한다.
- 순위결정전은 `Game.tiebreaker`로 구분한다. 정규 팀 승·패·무와 승률·게임차에는 합산하지 않고 동률 순서만 결정한다. 실제 개인 경기 기록은 해당 정규리그에 남는다.
- 게임차는 `((1위 승 - 해당 팀 승) + (해당 팀 패 - 1위 패)) / 2`이며 1위는 0이다.
- 고교·프로·대학의 순위표가 같은 함수를 사용한다. 고교 전국대회 참가 팀과 프로 포스트시즌 시드는 필요한 순위결정전이 끝난 뒤 확정한다. 경기 일정이 충돌하면 겹치지 않는 다음 날로 편성한다.

## 프로 3연전

- 월요일은 경기·정규 훈련을 편성하지 않는다.
- 화·수·목에 같은 상대와 같은 구장에서 3연전을 치르고, 금·토·일에는 다른 상대와 3연전을 치른다.
- 게임용 기존 경기 수인 1군 팀당 144경기, 2군 팀당 72경기는 유지한다. 홈·원정은 정확히 절반씩이다. 이에 따라 2군 일정은 1군보다 먼저 끝난다.
- 새 일정은 `Calendar.proSeriesVersion: 1`로 구분한다. 기존 저장은 완료한 경기·기록·선수와 팀별 남은 경기 수를 보존하고 이후 예정 경기만 재편한다. 진행 중인 주나 경기가 있으면 그 커서가 끝난 후 재편한다. 이전 일정의 잔여 경기 수가 3으로 나누어떨어지지 않는 경우 마지막 블록은 잔여 경기 수만큼 편성한다.
- 순위결정전과 포스트시즌의 추가 경기는 정규 3연전의 예외지만 월요일 경기는 피한다.
