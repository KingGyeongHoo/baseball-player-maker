# 상점

모든 화면에서 4열을 유지한다. 좁은 화면에서는 상점 목록을 가로로 스크롤한다.

| 분류 | 첫째 열 | 둘째 열 | 셋째 열 | 넷째 열 |
| --- | --- | --- | --- | --- |
| 투수 | 로진백 | 3X3 표적 | 악력기 | 투수 트레이너 |
| 타자 첫 줄 | 티볼 | 바벨 | 모래주머니 | 리바운드 체인 |
| 타자 둘째 줄 | 타자 트레이너 | | | |
| 공용 첫 줄 | 온열찜질기 | 피지컬 코치 | 컨디셔닝 코치 | 에이전트 |
| 공용 둘째 줄 | 훈련일지 | | | |

훈련일지는 10,000만원(100,000,000원)이다. 구매 시점부터 해당 시즌의 보직별 원래 출전평가 최고점을 저장하고, 그보다 낮아진 폭을 절반만 반영한다. 80점에서 원래 75점이 될 때 77.5점으로 평가한다. 더 높은 평가에 도달하면 기준점을 올리며, 같은 범위에서 등락을 반복해도 보너스가 누적되지 않는다. 능력치·경기 기록·WAR는 바꾸지 않고 실제 선발·등록 비교와 화면의 출전평가에 같은 값을 사용한다. 경쟁 선수보다 점수가 낮으면 주전이 바뀔 수 있다.

평가 조회 자체는 저장 상태를 바꾸지 않는다. 구매·경기 완료·일일 평가·이벤트 처리에서 최고점을 갱신하며 저장·불러오기에도 유지한다. 시즌 결산에서 다른 아이템과 같이 한 개를 소모하고 보호를 종료한다. 남은 재고나 결산 이후 구매한 재고는 다음 시즌에 새 기준점으로 적용한다. 여러 개 보유해도 감소율은 50%이며 중첩하지 않는다.
