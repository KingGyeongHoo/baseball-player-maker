# 프로 신체 전성기와 노화

게임용 성장 곡선이다. `lib/sim/pro-growth.ts`에서 실제 훈련·이벤트·시즌 전환이 같은 규칙을 사용한다.

## 선수별 전성기

프로 입단 때 파워·스피드·어깨·스태미나·회복력의 평균을 피지컬 기준으로 저장한다. 투수는 파워·스피드 대신 구속과 나머지 공통 3항목을 사용한다. 겸업은 신체 6항목 평균이다. 기존 저장은 보관된 개인 최고 신체 능력에서 처음 한 번 복원한다.

| 피지컬 기준 | 전성기 진입 | 완만한 하락 시작 |
| --- | ---: | ---: |
| 60 미만 | 28세 | 32세 |
| 60~75 미만 | 27세 | 33세 |
| 75~90 미만 | 26세 | 34세 |
| 90 이상 | 25세 | 35세 |

프로필을 한 번 저장하면 훈련·부상·보직 변경·새로고침으로 시점을 다시 계산하지 않는다. 재능은 기존 훈련 성장 계수에 반영한다. 현재 신분·실제 나이·계약·FA 나이를 바꾸지 않는다.

## 성장과 하락

신체 6항목은 20세 무렵 150%, 전성기 직전 110%의 성장 효율을 사용한다. 전성기 구간은 30%에서 15%까지 완만해지고, 하락 시작 이후에는 유지·회복 훈련 중심으로 줄어든다. 기술 능력은 별도 나이 계수로 계속 보완할 수 있다. 신체·기술 모두 기존 재능·성장 둔화·훈련 배분을 따른다.

새 시즌 시작 때 노화를 한 번 적용한다. 다음은 각 선수의 하락 시작 나이를 0년으로 본 연간 차감량이다.

| 하락 경과 | 스피드·구속 | 파워·어깨·스태미나·회복력 |
| --- | ---: | ---: |
| 0년 | 0.15 | 0.10 |
| 1년 | 0.25 | 0.175 |
| 2년 | 0.35 | 0.25 |
| 3년 | 0.45 | 0.325 |
| 4년 | 0.60 | 0.425 |
| 5년 | 0.75 | 0.525 |
| 6년 | 0.90 | 0.65 |

이후 스피드·구속은 매년 0.15씩 증가해 최대 2.2점, 나머지 신체 능력은 0.125씩 증가해 최대 1.8점을 차감한다. 기술은 하락 시작 3년 뒤부터 0.05점씩, 야구 지능은 8년 뒤부터 0.05점씩 시작해 더 늦고 완만하게 감소한다.

신체 훈련과 성장 이벤트는 `보관된 실제 최고치 − 누적 노화 차감`을 넘지 않는다. 다른 원인으로 낮아진 능력을 그 한도 안에서 회복할 수 있다. 전성기 뒤 기술 성장으로 OVR이 좋아질 수 있으나 신체 최고치를 계속 경신하지는 않는다. 부정 효과와 부상은 기존대로 적용하며, 신고 90%·무소속 60%는 성장량에만 반영한다.

## 저장과 표시

전성기 범위·피지컬 기준·신체별 누적 차감량·최종 노화 적용 연도를 저장한다. 같은 해 재진입은 중복 차감하지 않는다. 과거 저장은 현재 능력·급여·계약을 유지한 채 프로필만 추가하고, 이미 끝난 시즌의 노화를 재계산하지 않는다. 커리어 화면에 개인 전성기와 하락 시작 나이를 표시한다.
