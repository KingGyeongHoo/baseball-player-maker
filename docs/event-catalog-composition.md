2026-11-11 사용자 요청에 따라 추첨 확률이 아니라 카탈로그의 이벤트와 선택 행동 자체를 80:20으로 재편한다.

| 카탈로그 | 야구 이벤트 | 일상 이벤트 | 야구 선택 행동 | 일상 선택 행동 |
| --- | ---: | ---: | ---: | ---: |
| 고교 | 48 | 12 | 100 | 25 |

JSON의 `category: baseball / daily`가 내용 구분을 나타낸다. 기존 ID의 접두사와는 별개이며, 각 이벤트는 계속 선택 행동 2~3개를 가진다. 각 행동의 결과 분기 합계는 100%다.

## 실행과 저장

새 야구 사건은 실제 훈련일, 투타 분야, 수비 자격을 확인한다. 고교의 옛 L 계열 ID라도 훈련 내용은 `kind: training`으로 훈련 단계에서 열린다. 이야기만으로 시즌 기록이나 경기 결과를 가산하지 않는다. 학습 보상은 기존 3~4주분 환산과 성장·각성 규칙을 사용한다.

추첨 확률, 기존 발생 간격, 시즌 한도, 국가대표·첫 승격 등의 주요 사건은 유지한다. 80:20은 각 카탈로그와 선택 행동의 구성비이며, 실제 발생률을 강제하는 설정은 아니다.

확정 이력과 이미 열려 저장된 선택지는 원본을 유지한다. 다시 작성한 이야기는 `rule.revision: 2`를 쓰며 같은 개편판의 원인 사건에서만 후속 이야기를 만든다. 예전 공부나 게임 선택이 같은 ID를 사용하는 새 야구 훈련으로 임의 연결되지는 않는다.
