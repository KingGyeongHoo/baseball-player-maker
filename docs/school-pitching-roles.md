# 고교 투수 보직 배치

고교 생성 화면에서는 타자가 기존 수비 포지션을 선택하고, 투수는 ‘투수’만 선택한다. 생성된 구속·제구·변화구·스태미나·회복을 기존 `roleScore` 가중치로 비교해 선발(SP)·중간계투(RP)·마무리(CP) 중 가장 적합한 보직을 배정한다. 입학 배치에는 최소 능력치 조건을 두지 않는다. 동점이면 기존 생성 슬롯의 보직을 우선하며, 추가 난수는 사용하지 않는다. 랜덤 생성에도 같은 규칙을 적용한다.

고2·고3 진급 때 다시 비교한다. 다른 보직의 기량이 현재보다 2점 이상 높을 때만 변경하고, 그보다 작거나 동점이면 유지한다. 플레이어와 NPC 모두 같은 기준이다. 시작 시 생성되는 고2·고3 NPC도 입학 배치와 매년의 성장·재평가를 차례로 거친다. 구단 정원을 맞추기 위한 강제 배치는 하지 않는다. 고교 경기의 기존 대체 선발 기용은 유지한다.

플레이어는 진급 때 감독 안내에서 변경 또는 유지 결과를 확인한다. 능력치·재능·기록·훈련 설정은 보직 변경으로 초기화하지 않는다. 겸업 선수는 투수 쪽 보직만 평가하며 타자 포지션과 주 분야를 유지한다. 단일 역할 고교 투수의 시즌 중 투수 보직 제안은 연간 배치와 중복되지 않도록 제외한다. 기존 야수 포지션 제안과 투타 분야 전환·겸업 심사는 유지한다.

고교에서 프로로 진출할 때는 최종 보직을 그대로 가져간다. 프로 입단 후에는 자동 연간 배치를 적용하지 않고, 더 적합한 보직을 감독이 제안하는 PE10과 기존 보직 평가 절차를 사용한다. ‘프로 선수로 시작하기’에서는 기존처럼 보직을 직접 선택한다.

기존 저장은 불러올 때 보직을 바꾸지 않는다. 다음 고2·고3 진급부터 재평가하며, 이미 고3이거나 프로인 선수의 현재 보직을 소급 변경하지 않는다. 결과는 기존 `position`·`primaryRole`·`twoWay.pitchingPosition` 필드로 저장한다.

연간 변경 기준은 `lib/sim/school-pitching-roles.ts`의 `schoolPitchingRoleRules.annualMinimumAdvantage`에서 조정한다. 프로 제안 기준은 `lib/sim/pro-role-evaluation.ts`의 `pitchingRoleProposalRules`와 별도로 관리한다.
