# 자유 훈련 배분과 피로·회복

v0.7.4 · 2026-11-05

## 배분과 성장

투수 기술 3종, 타자 기술 4종, 공통 피지컬의 8개 항목에 각각 정수 0~5를 자유롭게 투자한다. 약한·보통·강한 강도 선택과 7/10/13장 총 예산을 제거했다. 모든 항목 5도 유효하며 총합 40은 항목 수에서 자연스럽게 생기는 최댓값이다.

- 실제 훈련일에 참가하면 투수·타자 기술 7종 모두 기본 성장한다. 항목당 주간 기준은 (기본 0.03 + 집중 성장) × 분야 재능 × 성장 둔화다. 집중 성장은 1개 0.1, 5개 0.25로 기존과 같다.
- 해당 항목이 0이어도 다른 항목에 투자해 실제 훈련하면 기술 기본 성장은 있다. 전체 0·부상·강제 휴식·비시즌은 훈련 성장을 지급하지 않는다.
- 피지컬 집중 성장은 스태미나·회복력·어깨로 3분할하고 BQ 자연 성장 0.025를 유지한다. 실제 훈련일·경기 참여량·재능·적응·나이·신고선수·무소속 계수는 성장에 종전처럼 적용한다.
- 훈련 집중·몇 주분 성장 이벤트도 같은 성장 공식을 사용한다. 겸업 자체의 추가 성장 배율은 없다.
- 표시만 정수 부분을 사용한다. 원본 소수점은 보존한다. 회복·쌓임의 방향이 있는 1 미만 변화는 '1 미만'으로 표시해 유지와 구분한다.

## 피로 모델

R은 주 시작 시점의 기본 회복력(기준점 검증은 0~100), T는 분야별 가중치를 반영한 환산 부하(0~40)다. 타격 4항목 티켓 합 B, 투구 3항목 합 A, 피지컬 H에 대해 가중 합 W=0.75B+A+H, 최대 W=35, 부하 비율 L=W/35, 환산 T=40L로 계산한다. 훈련 피로는 R과 T로 계산하며 성장 공식은 유지한다. 스태미나는 경기 피로의 기존 역할을 유지한다.

    최대 회복 C = 20 + 0.8R
    최대 쌓임 P = 100 - 0.5R
    균형 배분 Q = 40 × (0.2 + 0.001R)

    T ≤ Q: 주간 순변화 D = -C × (1 - T/Q)^2
    T > Q: 주간 순변화 D = P × (T-Q)/(40-Q)

| 회복력 | 전체 0 최대 회복 | 전체 5 최대 쌓임 | 균형 부하 |
| --- | ---: | ---: | ---: |
| 0 | -20 | +100 | 환산 8 / 20% |
| 50 | -60 | +75 | 환산 10 / 25% |
| 100 | -100 | +50 | 환산 12 / 30% |

회복 구간은 투자량에 따라 회복이 빠르게 줄어드는 제곱 곡선이다. 회복력 50에서 환산 T가 5이면 -15, 8이면 -2.4, 9이면 -0.6이며 10이면 유지다. 전체 0의 최대 회복과 양의 피로 구간은 유지한다. 회복력 50에서는 환산 T=0/5/10/20/40이 각각 -60/-15/0/+25/+75다. 회복력이 0이어도 훈련하지 않으면 기본 휴식 회복은 가능하다. 현재 능력의 생성 하한은 1이며 0은 수식의 기준점으로도 검증한다.

최대 회복과 최대 쌓임은 이론적 주간 용량이다. 실제 피로는 0~100에서 제한한다. 피로 10에서 회복 용량 60이어도 실제 회복은 10이며, 훈련 설정은 현재 피로에서 예상되는 종료 피로도 별도로 표시한다.

## 날짜별 적용과 경기

주간 계획의 순변화를 7일에 나눠 적용한다. 주중 5일의 훈련 성장과 주말을 포함한 7일의 누적 부하를 구분한다. 평일에 순피로를 먼저 모두 더한 뒤 주말 회복으로 기준점이 달라지는 방식을 사용하지 않는다.

- 해당 7일 주기에 예정 훈련일이 있으면 저장한 배분의 주간 부하를 적용한다. 훈련일이 전혀 없는 비시즌 주기는 전체 0 기준으로 회복한다.
- 주 시작 회복력을 선수별로 저장한다. 피지컬 훈련이나 선택 이벤트로 회복력이 오르더라도 진행 중인 주의 계산 기준은 바뀌지 않고 다음 주부터 반영한다.
- 중단한 날짜·선수 인덱스와 회복력 스냅샷을 저장한다. 이벤트·Worker·불러오기 재개가 같은 날짜의 피로를 다시 적용하지 않는다.
- 경기 피로와 이벤트의 직접 피로 변화는 별도로 더한다. 경기 출전으로 훈련 참여량이 줄면 성장 참여량에는 반영하지만, 배분량과 회복력으로 정한 주간 피로에 숨은 강도·스태미나 배율을 추가하지 않는다.
- 부상·강제 휴식·훈련 집중 이벤트의 당일 휴식은 그날 전체 0으로 처리한다. 피로를 즉시 0으로 만들지 않는다. 피로 100에서 강제 휴식하고 80 미만으로 회복하면 해제한다.
- 전체 0은 훈련 성장·훈련 기본 부상 위험이 없다. 출전 가능한 선수의 경기 자격을 막지는 않으므로 경기 피로·경기 부상은 생길 수 있다.
- 실제 훈련일의 기본 부상 확률 0.05%와 피로에 따른 활동 부상 위험, 부상의 결장 기간·복귀 후 수행 저하는 유지한다.
- NPC도 같은 피로 수식을 사용한다. 경기일·고피로 때 가중 부하를 균형 부하의 약 절반으로 줄여 회복하고, 부상·강제 휴식일에만 활동을 중단한다.

보고서의 훈련 피로는 주간 계획에서 실제로 증가한 양, 회복은 실제로 감소한 양이다. 훈련과 회복을 상쇄한 값을 적용하므로 균형 배분은 둘 다 0이다. 경기·이벤트·피로 상한을 포함해 다음 보존식을 만족한다.

    종료 피로 = 시작 피로 + 훈련 순누적 + 경기 피로 + 이벤트 변화 - 실제 회복

## 막대와 마커

훈련 센터와 대시보드 훈련 모달은 같은 편집기를 사용한다. 기존 '남은 티켓' 영역은 현재 배분·회복력·균형 경계·현재 설정의 주간 방향을 표시하는 남색 카드로 교체했다.

- 막대 왼쪽 초록은 최대 회복, 가운데 노랑은 유지, 오른쪽 빨강은 최대 쌓임이다.
- 실제 배분의 균형점 Q는 최대 가중 부하의 20~30%지만 막대에서는 항상 가운데 50%에 표시한다.
- 왼쪽 마커 위치는 50 + 50D/C, 오른쪽은 50 + 50D/P다. 즉 0~Q 배분을 왼쪽 절반, Q~40을 오른쪽 절반에 대응시킨다.
- 티켓 증감 때 마커와 회복/유지/쌓임 문구가 즉시 바뀐다. 색과 함께 텍스트와 읽기 전용 접근성 meter 값을 제공한다.
- 현재 배분은 실제 개수, 훈련 부하와 유지 경계는 가중 비율로 표시한다. 투타 구성에 따라 같은 개수의 피로가 다르므로 경계를 고정 개수로 안내하지 않는다. 능력이나 배분을 임의로 반올림해 유지로 판정하지 않는다.
- 항목의 +는 해당 항목이 5일 때만 막는다. 다른 항목을 줄일 필요가 없다. '모두 0으로'로 회복에 집중할 수 있다.
- 저장 전 수정은 초안이다. 모달의 취소는 저장된 배분을 유지하고 저장하면 훈련 센터와 같은 설정으로 적용한다.

## 구버전 호환

이전 light/normal/hard 태그와 배분은 읽을 수 있지만 태그에 따른 예산·피로 배율은 적용하지 않는다. 새 편집은 normal 태그에 배분만 저장한다. 이전 rest 설정은 전체 0과 경기 불참을 유지하고, 사용자가 배분을 추가하거나 이전 배분 복원을 눌러 직접 훈련을 재개한다. 강제 자동 복귀는 없다.

구버전 중단 주에는 아직 처리하지 않은 날짜부터 회복력 스냅샷을 추가해 새 계산을 적용한다. 처리한 경기·훈련·기록을 반복하지 않는다. 옛 보고서·이벤트 결과·밸런스 검증 수치는 과거 값으로 보존한다. JSON의 옛 강도별 피로 매개변수는 호환·과거 기록용이며 새 훈련 피로에서는 사용하지 않는다.

## v0.7.3 회복 조정과 선택 잠금

투자 중 회복량이 지나치다는 요청으로 회복 구간의 지수를 1에서 2로 바꿨다. 0개 최대 회복·20~30% 균형점·최대 쌓임 기준점은 보존한다. 왼쪽 마커는 단순 배분 비율이 아닌 실제 회복량에 대응한다.

선택지가 열린 상태에서는 예약된 다음 계산과 남은 요청 잠금을 정리하되 자동 진행 설정은 유지한다. 결과 확인이 끝나면 켜져 있던 자동 진행을 이어가며, 직접 일시정지한 경우에는 재개하지 않는다. 처리를 거절하거나 오류가 난 선택은 중복 클릭 잠금을 해제해 다시 시도할 수 있다. 버튼이 잠겨 있으면 선택 버튼 활성화로 현재 선택·기록·중단 위치를 보존하고 계산 잠금만 해제한다.

전체 210개 테스트·lint·빌드·실제 Worker 검증을 통과했다. 격리된 고교/프로 브라우저에서 응답을 지연시킨 Worker, 일시정지, 선택 표시를 겹쳐 버튼 활성화·늦은 응답 무시·더블클릭 1회 적용을 확인했다. 프로에서는 실제 Worker로 다음 주 진입도 확인했다. 이는 실제 사용자 창 상태를 직접 검사한 결과와 구분한다. [당시 비교표](../validation/training-v0.7.3.json)를 참고한다.


## v0.7.4 분야별 피로 보정

타격 4항목과 투구 3항목을 각각 같은 단계로 투자하면 같은 부하다. 타격 티켓은 피로에만 0.75배로 반영하고 집중 성장·양쪽 기본 성장·피지컬 성장은 유지한다. 선수의 주 포지션이 아니라 실제 투자한 항목에 가중치를 적용한다.

회복력 50에서 타격 4항목×5는 실제 20개, 투구 3항목×5는 실제 15개지만 둘 다 W=15, L=3/7, T=120/7이다. 경기·부상·이벤트가 없는 주의 순피로는 둘 다 +125/7(약 17.86)이다. 컨택 5+구속 5는 W=8.75, L=25%로 유지다. 전체 40개의 W=35, 전체 0의 W=0이므로 기존 최대 쌓임·최대 회복 기준점은 같다. 저장된 티켓 개수는 재배정하지 않는다.

전체 225개 테스트, lint·빌드·실제 Worker 검증 통과. 신규 tests/training-effort.test.mjs는 분야 동등성·혼합/피지컬 가중치·기준점·균형점·실제 주간/예측·성장 유지·편집기·NPC를 검증한다. [현행 가중 부하 비교표](../validation/training-v0.7.4.json)에 엔진 실측값을 보관한다.
