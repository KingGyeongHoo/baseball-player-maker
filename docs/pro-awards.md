# 어워드와 12월 골든글러브 시상식

프로 메뉴의 **어워드**에서 올스타·골든글러브·개인 수상을 전환한다. 시즌 선택으로 보관된 과거 기록도 확인한다. 리그의 올스타 버튼과 모달은 제거하고 동일한 투표·명단·결과 내용을 올스타 화면에 직접 표시한다. 1·2군 및 BLUE·WHITE 전환과 내 선수 선발 이력은 유지한다.

## 골든글러브

투수 통합 1명, 포수·1루·2루·3루·유격수·좌익·중견·우익·지명타자 각 1명으로 총 10명이다. 시즌 MVP 1명은 최상단에 표시한다. 1군 정규시즌 기록만 사용하며 능력치·평판·출전평가·팀 승수·포스트시즌·올스타 기록은 점수에 넣지 않는다.

- 야수 최소 200타석, 투수 최소 90아웃(30이닝).
- 야수 점수: `(개인 OPS − 리그 합산 OPS) × 타석 + (홈런 + 타점) × 0.15`.
- 투수 점수: `(리그 ERA − 개인 ERA) × 이닝 × 0.4 + 탈삼진 × 0.2 − 볼넷 × 0.15`.
- 야수 부문은 실제 1군 선발 출전이 가장 많았던 수비 위치를 사용한다. 수비 위치 기록이 없는 구버전은 시즌 종료 당시 포지션을 쓴다. 수비 원시 기록을 아직 별도 집계하지 않으므로 수비 능력치를 점수에 대신 넣지 않는다.
- 동점은 출전량, 고정 ID 순으로 결정해 부문당 1명으로 유지한다. 적격 선수가 없으면 해당 부문을 비운다.

MVP는 기존 분야별 리그 대비 성과·출전량 수식을 사용한다. 100타석 또는 30이닝 이상이 대상이며 동점 판정에서도 팀 승수를 제거했다. 구체적인 정규화 수식은 `pro-life.md`의 MVP·신인상 항목을 따른다. 이 점수는 WAR가 아닌 게임용 수상 점수다.

시즌 종료 때 이름·구단·수상 기록을 확정해 저장하고 **12월 6일** 스토브리그 진행에서 시상식을 연다. 캠프 바로가기를 선택해도 12월 시상식에서 잠시 멈추며, 확인하면 남은 시장 처리를 마치고 2월 캠프로 자동 이동한다. 이 중단 상태도 저장한다. 수상으로 추가 능력치나 평판을 지급하지 않는다.

## 개인 수상

1·2군, 투수·타자를 나누고 각 항목의 **1위만** 표시한다. 동률은 공동 1위 전원을 표시한다. 시즌 종료 시 기록을 확정하므로 다음 해 기록 초기화나 구단 이동으로 수상자가 바뀌지 않는다.

- 타자: 타율·출루율·장타율·OPS·홈런·안타·타점·득점·2루타·3루타·볼넷.
- 투수: ERA·WHIP·탈삼진율·이닝·탈삼진·다승·홀드·세이브.
- 비율 기록은 정규리그 경기 수에 따른 규정 타석(경기 수 × 3.1 올림)·규정 이닝을 요구한다. 1군 144경기, 2군 117경기를 사용한다.
- 누적 항목이 0뿐이면 해당 항목 수상자를 만들지 않는다. 시즌 진행 중에는 확정 전 안내를 표시한다.

## 선수 생성의 투타 손

투구 손(우투·좌투)과 타격 손(우타·좌타)을 독립적으로 선택한다. 위 줄은 **투구 손 / 타격 손**, 아래 유형 선택은 **투수 / 타자** 순서다. 고교·프로 직접 시작 모두 선택을 보존하며 대시보드와 선수 기록에 표시한다. 기존 저장에 값이 없으면 종전 표시인 우투우타로 읽는다. 손 선택은 선수 생성 난수나 능력치를 재추첨하지 않는다.
