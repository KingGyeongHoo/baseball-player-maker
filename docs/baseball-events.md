# 야구 이벤트 기획안

작성일: 2026-11-04

프로 전용 선택 사건은 [프로 선택 이벤트](pro-events.md)에 별도로 정리했다. 현재 고교 기본 60종, 프로 기본 75종이며 공통 주수 보상·각성 규칙을 사용한다.

상태: **60종 확장 적용 (2026-11-10).** 기존 30종에 훈련 10종·상황 2종·생활 18종을 추가했다. 별도 사건인 감독의 겸업·겨울 전학·집중 훈련도 유지한다. 겸업·전학은 12·13절, 훈련 강도와 피로는 [훈련 문서](training.md)에 기록했다.

## 1. 범위와 확정 요구사항

야구 훈련·관계자·대회·경기뿐 아니라 학교생활·학업·가족·동료와의 일상도 다룬다. 사적인 약속을 거절했다는 이유로 출전평가나 평판을 깎지 않는다.

| 분류 | 수 | 등장 시점 |
| --- | ---: | --- |
| 훈련 | 20 | 실제 훈련 중. 새 연습의 후속 점검 포함 |
| 야구 관계자·상황 | 10 | 훈련일·휴식일·경기일. 국가대표는 별도 조건 |
| 대회 | 6 | 자신이 참가하는 전국대회 주간 |
| 경기 중 | 6 | 자신이 실제 타석 또는 마운드에 있는 경기일 |
| 생활 | 18 | 자기 팀 경기 없는 날. 시험·축제는 해당 월 |
| 합계 | 60 | 선택 행동 123개. 별도 사건 S01–S03 제외 |

### 2026-11-10 추가 사건 운영

새 사건은 `event-definitions.json`의 `rule`로 훈련 여부·경기 없는 날·포지션·학년·월·최근 흐름을 확인한다. 기존 이벤트 발생 확률과 주간 간격은 유지한다. 새 사건의 동일 ID는 56일 동안 다시 나오지 않는다.

T16–T20과 L14–L18은 후속 사건 10종이다. 각각 T11–T15, L01–L05에서 첫 행동을 선택한 뒤 14–112일 사이에만 후보가 된다. 동일 팀·커리어 단계의 실제 선택 기록을 사용하며, 한 원인 사건에서 같은 후속 사건은 한 번만 열린다. 후보가 있으면 주간 추첨의 절반은 후속 후보군을 우선한다. 발생은 보장하지 않으며 조건을 잃거나 기한이 지나면 나오지 않는다.

새 피로 효과는 결과별 범위 안의 정수 추첨, 휴식은 현재 피로의 비율 회복이다. 능력치 보상은 기존 훈련 주수·재능·현재 능력치·각성 규칙을 따른다. 별도 동료 친밀도 수치를 만들지는 않고, 함께한 선택 자체가 후속 대화를 연다. 새로운 선택 기록은 저장되며, 메타데이터가 없는 옛 기록에 후속 관계를 임의로 만들지 않는다.

**생활 성장 보강:** L03·L06·L07·L12·L13·L17의 첫 선택은 30%로 상황에 맞는 능력 3주분을 배우고, 나머지 30%는 기존 좋은 결과, 40%는 기존 피로·휴식 결과다. 공부 계획은 야구 지능, 생활·산책은 체력·회복, 축제의 민첩성 놀이는 스피드, 캐치볼은 타자 컨택·투수 제구를 사용한다. 생활 사건 전체에 능력 보상을 주지는 않으며 휴식 선택과 기존 발생 간격을 유지한다.

사용자가 정한 공통 규칙:

- 한 이벤트에는 선택지 2개 또는 3개가 있다.
- 선택 전에는 상황과 행동 문구만 보여준다. 효과, 수치, 확률, 성공·실패 예고는 보여주지 않는다.
- 선택한 뒤 확률로 결과를 정하고, 결과 문구와 실제 적용된 변화를 보여준다.
- 국가대표 소집 수락은 MVP 5%, 인상적인 활약 23.75%, 부상 23.75%, 일반 경험 47.5%다. MVP를 제외한 95% 안에서 1:1:2 비율을 유지한다. 거절은 기존 25%·25%·50%를 유지한다.
- 프로 트레이닝 센터 등록은 5% 대성공·95% 일반 훈련, 미등록은 50% 개인 훈련·50% 휴식이다.
- 능력 상승 결과에는 공통으로 5% 각성·95% 원래 효과 규칙을 적용한다.
- 일반 능력 상승 결과는 **해당 능력에 티켓 5개를 배분한 3~4주치 훈련량**을 한 번에 지급한다. 큰 보상은 6~8주분이다. 각성은 최대 12주분의 훈련 환산 보상과 현재 능력치에 따른 최소 상승량 중 큰 값을 적용한다.

이 문서의 **정확한 보상 수치, 일반 이벤트 확률, 반복 간격, 동점 처리, 각성량은 초기 밸런스 제안**이다. 사용자 지정 조건·분기 확률은 유지하고, 제안 수치는 추후 테스트로 조정한다.

## 2. 화면과 진행 방식

### 선택 전

> **부러진 배트**
>
> 사용 중이던 배트가 망가졌다. 이참에 다른 브랜드의 배트를 사볼까?
>
> [새로운 브랜드로 바꿔본다] [원래 쓰던 브랜드를 쓴다]

버튼 설명, 색상, 아이콘, 툴팁, 접근성 이름에도 숨겨야 할 효과나 확률을 넣지 않는다. 선택지를 '안전', '성공 확률 높음', '추천' 등으로 표시하지 않는다.

### 선택 후

> **선택의 결과**
>
> 새로운 브랜드로 바꿔본다
>
> 새 배트가 손에 잘 맞는다.
>
> 컨택 +1.62 · 평판 +0.24
>
> [확인]

예시는 컨택 40, 타격 재능 5인 타자가 T01의 컨택 4주분 보상을 받은 경우다. 내부 컨택 상승량 약 1.617778이 OVR과 평판에 간접 반영된다. UI 표시는 적절히 반올림하되 내부 계산은 소수를 유지한다. 선택 전에는 이 수치나 훈련 주수도 보여주지 않는다.

각성이 발생했다면 결과 아래에 다음처럼 덧붙인다.

> **정교한 타격에 눈을 떴다!**
>
> 컨택 +8 · 평판 +1.2

공통 진행 규칙:

1. 발생 시 다음 계산을 대기하되 자동 진행 설정은 유지한다.
2. 선택 전에는 이후 날짜나 해당 경기 장면을 계산하지 않는다.
3. 선택을 한 번만 처리하고 결과를 저장한다. 연속 클릭이나 화면 재표시로 재추첨하지 않는다.
4. 결과 창에는 실제 변화량, 새 부상과 복귀 예정일, 포지션 변경, 해당 타석·타자에 적용할 경기 보정을 보여준다.
5. 선택·결과 확인을 마치면 자동 진행 설정이 켜져 있는 경우 이어간다. 직접 일시정지했다면 재개하지 않는다.
6. 경기 중 이벤트는 현재 이닝·공수·아웃·주자·점수를 함께 보여준다. 선택 이후 해당 장면부터 이어간다.

## 3. 효과 표기와 공통 계산

### 능력치와 역할

| 표기 | 의미 |
| --- | --- |
| 타자 핵심 능력 | 컨택·파워·스피드·수비 |
| 투수 핵심 능력 | 구속·제구·변화구 |
| 역할 핵심 능력 | 현재 주 역할에 따라 위 두 집합 중 하나 |
| 정교함 | 타자는 컨택, 투수는 제구 |
| 힘 | 타자는 파워, 투수는 구속 |
| 약점 | 역할 핵심 능력 중 가장 낮은 항목. 동점이면 고정된 능력치 순서 사용 |
| 전체 능력치 | 컨택·파워·스피드·수비·구속·제구·변화구·스태미나·회복력·어깨·야구 지능, 총 11개 |

타자 OVR은 타자 핵심 능력의 평균, 투수 OVR은 투수 핵심 능력의 평균이다. OVR을 직접 더하거나 빼지 않는다. 어깨·스태미나·회복력·야구 지능 상승은 경기나 관리에 영향을 주지만 OVR을 직접 올리지는 않는다.

### 일반 능력 상승: 티켓 5개 × 3~4주

이전 초안의 +0.1~+0.6은 훈련량에 근거하지 않은 임시 수치였다. 성장 둔화와 재능을 고려하면 같은 +0.3도 선수에 따라 전혀 다른 훈련 기간에 해당하므로, **일반 상승량을 고정 숫자로 지정하지 않는다.**

이 문서의 효과 표에서 `컨택 +3주분`은 현재 선수의 컨택에 티켓 5개를 배분하고 정상 훈련을 3주 수행했을 때의 컨택 증가량을 뜻한다. `+4주분`도 같은 방식으로 계산한다.

- 신중한 선택·기본적인 성과는 3주분, 도전의 성공·상대적으로 좋은 성과는 4주분을 기본으로 둔다.
- **상승 결과가 나왔을 때 받는 양**이 3~4주분이다. 실패·하락 확률까지 합친 선택의 기대값이 3~4주분이라는 뜻은 아니다.
- 여러 능력을 올리는 결과는 각 대상 능력에 표시된 주수만큼 지급한다. 이를 합쳐 3~4주분으로 나누지 않는다. 따라서 여러 능력을 올리는 결과의 총 보상은 더 크다.
- 계산 기준은 선택 직전의 현재 능력치·해당 계열 재능이다. 여러 능력 보상은 같은 시점의 선수 상태를 기준으로 각각 계산한다. v0.5.7부터 기술 능력의 기본 성장은 주 역할과 무관하게 양쪽 모두 적용한다.
- 기준 훈련은 주 5일, 매일 정상 훈련량 100%다. 3주는 15일, 4주는 20일로 계산한다.
- 경기 참가로 인한 훈련 축소, 비시즌, 부상, 휴식, 강제 휴식은 이 보상 기준량을 깎지 않는다. 실제 달력의 3~4주를 건너뛰는 것이 아니라 **정상 훈련 3~4주에 상당하는 능력 보상**을 지급한다.
- 훈련 강도는 같은 능력에 같은 티켓 5개를 배분했을 때 성장 배율을 별도로 바꾸지 않는다. 강도별 총 티켓 예산·피로 차이는 이 보상 계산과 별개다.
- 가상의 훈련 일수만큼 능력치 증가를 일별로 누적하고, 매일 성장 둔화 구간을 다시 확인한다. 시작 시점의 주간 증가량에 단순히 3 또는 4를 곱하지 않는다.
- 기준량 산정으로 시간, 다른 능력치, 재능 공개 경험, 훈련 티켓, 피로를 변경하지 않는다. 결과 표에 명시된 대상 능력과 별도 효과만 적용한다.
- 재능은 엔진의 실제 값을 사용하되 결과 화면에서 숨겨진 재능 수치를 직접 표시하지 않는다.

현재 성장 계수에서 티켓 5개의 집중 성장량은 0.25다. 투수·타자 기술 능력 모두 기본 성장 0.03이 더해진다.

`일별 증가량 = (0.25 + 0.03) × 해당 분야 재능 배율 × 현재 성장 둔화율 ÷ 5`

재능 배율은 `1 + (재능 - 1) / 9`이며, 재능 1~10에서 1~2배다. 위 식을 15일 또는 20일 반복하고 마지막 능력치에서 시작 능력치를 빼서 보상량을 얻는다. 실제 구현에서는 현재 밸런스 계수를 참조해 훈련 공식 변경과 함께 움직이게 한다.

| 현재 능력치 구간 | 성장 둔화율 |
| --- | ---: |
| 50 미만 | 1 |
| 50 이상~60 미만 | 0.5 |
| 60 이상~70 미만 | 0.25 |
| 70 이상~80 미만 | 0.12 |
| 80 이상~90 미만 | 0.06 |
| 90 이상 | 0.025 |

#### 실제 훈련 함수로 계산한 비교

주 역할 계열 능력, 해당 재능 5, 경기·부상·휴식 없는 정상 훈련 기준이다. 2026-11-04 현재 `train()` 함수를 15일·20일 반복해 계산했다.

| 시작 능력치 | 티켓 5개 1주 | 3주분 보상 | 4주분 보상 |
| --- | ---: | ---: | ---: |
| 40 | +0.4044 | +1.2133 | +1.6178 |
| 55 | +0.2022 | +0.6067 | +0.8089 |
| 65 | +0.1011 | +0.3033 | +0.4044 |
| 75 | +0.0485 | +0.1456 | +0.1941 |
| 85 | +0.0243 | +0.0728 | +0.0971 |
| 95 | +0.0101 | +0.0303 | +0.0404 |

같은 시작 능력치 40이어도 재능 1은 3~4주에 +0.84~+1.12, 재능 10은 +1.68~+2.24다. 49.9처럼 둔화 경계 근처에서 시작하면 훈련 도중 50을 넘으므로 재능 5의 3~4주분은 +0.6876~+0.8898로 계산된다.

#### 직접 티켓을 배분할 수 없는 능력

- **스태미나·회복력·어깨:** 피지컬 티켓 5개가 세 능력에 나뉘어 들어가는 현재 규칙을 사용한다. 대상 능력의 일별 증가량은 `0.25 / 3 × 해당 능력 성장 둔화율 / 5`이며 재능 배율은 없다. 한 능력 보상을 받는다고 다른 두 능력도 자동으로 오르지는 않는다.
- **야구 지능:** 전용 티켓이 없으므로 티켓을 사용한 정상 훈련의 자연 성장량을 기준으로 한다. 일별 증가량은 `0.025 × 야구 지능 성장 둔화율 / 5`이며 재능 배율은 없다.
- 예: 능력치 40에서 피지컬 개별 능력의 3~4주분은 +0.25~+0.3333, 야구 지능은 +0.075~+0.1이다. 능력치 65에서는 각각 +0.0625~+0.0833, +0.01875~+0.025다.
- **반대 역할의 기술 능력:** v0.5.7부터 해당 분야 재능과 기본 성장 0.03을 함께 적용한다. 동일 재능·현재 능력·티켓이라면 주 역할에 상관없이 같은 양이 오른다.

일반 보상은 3~4주분, 국가대표의 인상적인 활약은 6주분, 국가대표 MVP와 센터 대성공은 8주분이다. 훈련 환산 보상에는 같은 일별 성장 둔화·재능·역할·피지컬/BQ 공식을 적용한다. 각성의 별도 최소 상승량은 아래 규칙을 따른다. 국가대표의 보통 경험·팀 잔류, 센터 일반 훈련·개인 훈련은 기존 3~4주분을 유지한다.

원본 v0.3 기획의 개별 OVR 기준은 고교 60대 에이스급, 70대 청소년 대표급, 80대 매우 희귀한 유망주, 90 이상 극히 희귀한 예외다. 고교에 별도 60점 상한을 두는 대신 같은 절대 능력 척도와 성장 둔화로 미래 프로와의 격차를 유지한다. 합산 OVR 200점 척도와 두 개별 OVR의 100점 척도를 혼동하지 않는다.

### 평판·피로·상한

- 효과 표의 `평판 +N/-N`은 이벤트 평판 보정값의 변화다.
- 결과 화면의 평판 변화는 능력치 상승에 따른 OVR 변화까지 포함한 최종 평판의 전후 차이다. 보상을 이중 적용하지 않는다.
- 피로 `+`는 피로 누적, `-`는 회복이다.
- 능력치는 1~100, 평판과 피로는 0~100 범위로 제한한다.
- 상한·하한 때문에 표의 양을 전부 적용할 수 없으면 실제 변화량만 보여준다. 주수 보상은 일별 성장 둔화와 100점 상한을 모두 적용한다.
- `변화 없음`은 해당 기본 결과에 능력·평판·피로 보정이 없다는 의미다.
- 효과 표의 능력 변화는 별도 표기가 없으면 영구 능력치 변화다.
- 큰 성장도 기존 능력치 상한을 넘지 않는다. 센터·MVP의 일반 보상은 훈련 성장 둔화를 적용하며, 각성 최소 상승량은 현재 능력이 높아질수록 선형으로 감소한다.

## 4. 모든 능력 상승 선택에 적용하는 각성

### 판정 순서

1. 선택한 버튼의 기본 결과를 먼저 추첨한다.
2. 결정된 결과에 양수인 영구 능력치 변화가 있는지 확인한다.
3. 있으면 **결과 전체에 대해 한 번**, 1/20 확률로 각성을 판정한다.
4. 19/20이면 기본 결과를 그대로 적용한다.
5. 1/20이면 그 결과가 올리는 능력치의 상승량을 크게 바꾸고, 각성 문구를 추가한다.

판정은 능력치마다 따로 하지 않는다. 여러 능력을 올리는 결과도 각성 확률은 5%다. 각성이 나오면 그 결과의 모든 상승 대상 능력이 함께 강화된다.

### 상승량 — 2026-11-09 조정

```text
훈련 환산 보상 = min(12, 기본 보상 주수 × 2)주분의 정상 훈련량
각성 최소 상승량 = 3 × (100 - 선택 직전 능력치) / 40
최종 상승량 = min(100 - 현재 능력치, max(기본 보상, 훈련 환산 보상, 각성 최소 상승량))
```

- 기본 3주분은 6주분, 4주분은 8주분, 6주분과 8주분은 12주분으로 대체한다.
- 늘어난 주수에 대해 일별 훈련 공식을 다시 계산한다. 이미 계산한 최종 상승량에 단순히 2를 곱하지 않는다. 50·60·70·80·90 경계를 넘으면 다음 날부터 더 낮은 성장률을 적용한다.
- 능력치 60에서 각성하면 최소 +3이다. 최소분은 40에서 +4.5, 80에서 +1.5, 90에서 +0.75, 100에서 0으로 줄어든다. 기존 훈련 환산 보상이 더 크면 그 값을 사용한다.
- 최소분은 야구 지능·어깨·스태미나·회복력과 기술 능력 모두 동일하며 재능·나이·신고선수 배율로 줄이지 않는다. 훈련 환산 부분은 기존 성장 배율을 유지한다.
- 고정 +8 하한과 센터의 +12·각성 시 +24는 사용하지 않는다. 기본 보상과 각성 보상을 중복 지급하지 않는다.
- 평판·피로·부상·포지션·경기 보정 등 다른 효과와 기본 결과 확률은 유지한다.
- 양수인 영구 능력 보상만 각성 대상이다. 하락·회복·평판·부상만 있는 결과에는 각성을 판정하지 않는다.
- 결과 전체에 한 번만 5%를 판정하며 연쇄 추첨하지 않는다. 일반 훈련에 각성을 추가하는 규칙은 아니다.
- 센터 대성공과 각성의 동시 발생 확률은 0.25%, 국가대표 수락에서 MVP와 각성의 동시 발생 확률도 0.25%다. 이 경우에도 훈련 환산 부분만 최대 12주분이며 별도 최소분과 비교한다. 이미 확정한 과거 기록은 바꾸지 않고 이후 해결하는 사건부터 적용한다.

## 5. 발생 조건과 반복 제한

아래 간격과 발생률은 초기 제안값을 v0.5.3의 기본값으로 적용했다. 이벤트 수가 많다는 이유로 매일 선택 창을 띄우지는 않는다.

| 항목 | 제안 |
| --- | --- |
| 일반 이벤트 | 마지막 일반 이벤트로부터 2주 이상 지난 주에 35% 확률로 1회 기회 확보 |
| 주간 기회 처리 | 그 주의 실제 조건에 맞는 후보·발생 시점을 하나 배정. 조건 소멸 시 취소하며 반복 재추첨하지 않음 |
| 한 주 최대 | 일반 이벤트 1회. 국가대표는 별도 우선 이벤트 |
| 동일 이벤트 | 최근 5개 이벤트와 겹치면 우선 제외. 후보가 없으면 이번 기회 생략 |
| 센터 | 학년당 최대 1회 등장 |
| 국가대표 | 고2·고3 각각 최대 1회 제안. 수락·거절 모두 해당 학년의 제안을 소진 |
| 대회 이벤트 | 해당 대회당 최대 1회. 실제 참가 중인 팀에만 등장 |
| 경기 중 이벤트 | 한 경기 최대 1회. 본인의 실제 타석·등판이 없으면 발생하지 않음 |

훈련·관계자·대회·경기 이벤트를 같은 주에 중복 추첨하지 않는다. 주간 후보가 구성되는 경우 가능한 분류를 먼저 고르고, 그 분류 안에서 이벤트를 고르는 방식으로 특정 분류의 개수에 치우치지 않게 한다.

세부 조건:

- 훈련: 실제 훈련 가능한 날이며 훈련 티켓을 사용해야 한다. 부상으로 훈련 불가, 강제 휴식, 회복 방침이면 제외한다.
- 관계자: 이벤트별로 훈련·휴식·경기일을 허용한다. 대화·회복 이벤트는 휴식 중에도 가능하다. 실제 훈련하는 선택은 활동 가능한 선수에게만 제공되는 이벤트에 넣는다.
- 대회: 일정에 대회 이름이 있다는 이유만으로 발생시키지 않는다. 자신이 참가하고 있고 탈락·대회 종료 전이어야 한다.
- 경기: 타자 이벤트는 본인의 타석, 투수 이벤트는 본인의 등판 중 발생한다. 벤치에 있는 선수에게 타석·투구 선택을 띄우지 않는다.
- 국가대표: 일반 이벤트 확률이나 대회 참가 여부와 별개로 자격 충족 시 제안한다. 다른 선택 창이 열려 있으면 먼저 해결한 뒤 자격을 다시 확인한다.
- 진행 종료 후 새 이벤트를 만들지 않는다. 지명일을 이미 넘겼다면 소집을 새로 제안하지 않는다.
- 동시에 여러 조건이 맞으면 국가대표 → 예정된 경기 장면 → 일반 이벤트 순으로 처리하되, 한 번에 선택 창은 하나만 보여준다.

### P08. 청소년 국가대표 발탁 — 사용자 지정

#### 자격

두 조건을 동시에 만족해야 한다.

1. 플레이어가 고2 또는 고3이다.
2. 현재 존재하는 **전체 선수**의 평판 순위에서 TOP 23 안에 든다.

고2·고3 선수만 모아 순위를 매기지 않는다. 고1을 포함한 전 학년·전 학교·투타 전체가 비교 대상이다. OVR 순위, 드래프트 순위, 팀 내 순위로 대체하지 않는다.

동점은 내부 선수 ID 오름차순으로 정렬해 정확히 23명을 선발하는 안을 제안한다. 표시용 반올림 평판이 아니라 내부 평판값으로 비교한다. 아직 평판이 없는 선수는 평가된 선수 뒤에 둔다.

일반 이벤트 발생 확률과 무관하게 조건 충족 시 제안한다. 고2·고3 각각 한 번으로 제한하는 안을 제안한다. 선택을 기다리는 동안 게임 시간이 흐르지 않으므로 열린 소집 제안을 도중에 취소하지 않는다.

#### 처리 기준

- 부상은 문구나 피로 증가로 끝내지 않고 실제 부상 상태를 만든다. 훈련·출전 제한과 복귀 후 능력 회복도 기존 부상 규칙을 따른다.
- 부상 시작일은 선택한 날짜이며 결장 일수 계산은 기존 엔진의 날짜 규칙과 맞춘다.
- 기존 부상이 있다면 새 부상으로 더 빨리 회복되거나 기존 페널티가 줄지 않게 한다. 복귀일과 페널티 중 더 큰 부담을 유지한다.
- '감독에게 미운털'은 요청한 평판 하락으로 표현한다. 별도의 감독 호감도나 출전 금지 효과를 몰래 추가하지 않는다.
- '팀에 남아 전력 상승'은 본인의 능력 상승을 통해 팀 전력에 반영한다. 동료 전원의 능력을 올리는 효과가 아니다.
- 능력 상승을 포함하는 수락 3개 결과와 거절 1개 결과 모두 공통 각성 대상이다. MVP 여부는 첫 결과 추첨에서 확정되며 후속 각성은 MVP 수상 확률을 바꾸지 않는다.
- 이번 안은 소집 경험을 하나의 사건으로 처리한다. 별도 국가대표 대회 경기 시뮬레이션이나 달력 시간 점프는 포함하지 않는다.

## 9. 경기 중 선택 6종

### 경기 보정 공통 규칙

- 선택은 해당 타석 결과를 계산하기 전에 받는다. 이미 끝난 경기를 바꾸지 않는다.
- 아래 확률 보정의 단위는 **퍼센트포인트(%p)**다. 20% 판정에 +2%p면 22%다.
- 안타·볼넷·삼진은 기존 엔진의 각 판정 단계에 보정을 적용한다. 홈런은 기존 엔진의 안타 종류 판정에서 홈런 구간을 보정한다. 최종 타석 전체의 홈런 확률에 직접 더하는 의미가 아니다.
- 각 판정은 유효한 확률 범위를 유지해야 한다. 홈런·2루타·3루타의 종류별 구간 합이 100%를 넘지 않게 제한한다.
- 투수 이벤트에서 안타·홈런·볼넷·삼진은 **상대 타자의 결과** 기준이다.
- 경기 보정은 해당 타석 또는 상대 타자 한 명에만 적용하고 소진한다. 다음 경기나 시즌으로 넘기지 않는다.
- 결과 문구는 준비·접근의 변화를 설명한다. 실제 타석을 계산하기 전에 '홈런을 쳤다', '삼진으로 잡았다'고 확정하지 않는다.
- 경기 보정과 별개로 표의 3~4주분 영구 능력 상승은 경험 보상이며, 여기에 공통 각성 규칙을 적용한다.
- 각성까지 포함한 능력 변화를 반영한 뒤 해당 타석을 정상 시뮬레이션한다. 선택이 안타·삼진 등을 보장하지는 않는다.

1. 이벤트 정의를 30종 목록, 발생 조건, 2~3개 선택, 가중 결과 목록으로 분리한다.

5. 실제 경기 중 선택을 위해 주간·경기 계산을 중단하고 이어갈 수 있어야 한다. 재개하면서 경기·기록·피로·훈련·순위·난수를 중복 적용하지 않는다.
6. 국가대표의 전체 평판 순위, 학년별 제안 이력, 센터 반복 제한, 최근 이벤트 이력을 관리한다.
7. 결과와 각성 여부를 저장해 결과 창 재표시·연속 클릭으로 다시 뽑지 않게 한다.
8. 기존 감독 역할 제안과 P06이 겹치지 않게 통합 또는 상호 배제한다.

## 11. 검증 기준

- 이벤트 30개이며 모든 이벤트가 2개 또는 3개의 선택지를 갖는다.
- 각 선택지의 기본 결과 확률 합은 100%다.
- 선택 전 UI와 접근성 설명에 능력치 변화·확률이 노출되지 않는다.
- 선택한 결과만 적용하고, 결과 창에는 실제 변화량을 표시한다.
- 일반 능력 상승은 해당 능력에 티켓 5개를 둔 정상 훈련 15일·20일의 증가량과 일치한다. 둔화 경계를 넘는 경우에도 일별 재계산 결과와 같아야 한다.
- 일반·MVP·센터 및 각성의 훈련 환산 부분은 선수의 재능·주 역할을 반영하고, 피지컬의 3분할과 야구 지능의 자연 성장 규칙을 구분한다. 6·8·12주분은 실제 일별 훈련과 일치해야 하며 각성 최소분은 모든 능력의 60에서 +3을 검증한다.
- 보상 기준량 계산만으로 달력·피로·다른 능력·재능 공개 경험이 변하지 않는다. 결과에 명시된 효과만 적용한다.
- 국가대표는 고1에게 발생하지 않으며 고2·고3 중 전체 평판 23위까지 포함하고 24위는 제외한다.
- 국가대표 순위는 모든 학년을 대상으로 계산하며 동점 처리가 일관된다.
- 국가대표 수락의 5%·23.75%·23.75%·47.5%, 거절의 25%·25%·50%와 센터의 5%·95%, 50%·50%가 정확하다.
- 국가대표 부상은 실제 출전·훈련을 막고 기존 부상 회복 경로로 복귀한다.
- 센터 대성공은 11개 능력치 모두 8주분을 계산하고 재능·성장 둔화·상한에 따른 실제 증가만 기록한다.
- 모든 영구 능력 상승 결과에 공통 각성이 적용된다. 각성 확률은 능력 개수와 관계없이 5%다.
- 능력 하락·피로 회복·평판 변화·부상만 있는 결과에는 각성이 발생하지 않는다.
- 각성은 훈련 주수를 늘려 다시 계산한 상승량과 별도 최소분 중 큰 값으로 대체하며, 다른 효과와 사용자 지정 기본 결과 확률을 바꾸지 않는다.
- 부상·휴식 선수에게 불가능한 훈련이나 실제 출전 장면을 제시하지 않는다.
- 대회 탈락 팀이나 비참가 팀에게 해당 대회 이벤트가 발생하지 않는다.
- 경기 보정은 선택 이후의 해당 타석·상대 타자에게만 적용되며 한 번 소진된다.
- 경기 재개 시 앞선 이닝·경기·날짜의 기록이나 훈련을 다시 계산하지 않는다.
- 결과 확인 뒤 자동 진행 설정이 켜져 있으면 다시 이어간다.

## 12. 감독의 투타 겸업 제안 — S01

v0.5.5에서 기존 30종과 별도로 추가한 특별 이벤트다. 전학 여부와 관계없이 처음 입학한 학교에서도 발생한다.

- 3~9월 시즌 중 투수 OVR·타자 OVR이 **각각 55 이상인 상태를 2주 연속 유지**하면 다음 진행일 경기 전에 감독이 제안한다. 고1·고2·고3 모두 가능하며 고3은 드래프트 전까지만 가능하다. 중간에 기준 미달 또는 비시즌이 되면 연속 주수를 초기화한다.
- 이미 겸업 중이거나 부상·회복·강제 휴식으로 활동할 수 없는 날에는 제안하지 않는다. 거절하면 같은 학년에는 재제안하지 않으며 다음 학년에는 다시 받을 수 있다.
- 수락하면 기존 주 역할·포지션·훈련 설정을 유지하고 반대 분야 포지션 자격을 추가한다. 투수는 현재 투수 포지션, 타자는 현재 야수 포지션을 유지하며 반대 분야는 역할별 능력으로 정한다. 화면에는 `선발/2루수`처럼 표시한다.
- 팀 경기를 마칠 때마다 투수·야수 배정일을 번갈아 바꾼다. 배정은 출전 보장이 아니며 기존 주전 경쟁·컨디션·투수 휴식 조건을 적용한다. 같은 경기 동시 투타 출전은 지원하지 않는다. 중단된 경기나 몰수 경기에서는 배정을 바꾸지 않는다.
- 평판 보너스는 `3 × min(1, 시즌 PA/20, 시즌 BF/15)`로 양쪽 실제 출전이 있어야 쌓인다. 이미 얻은 보너스는 감소하지 않으며 진급 후에도 유지한다. 평판 상한은 100이다.
- 한 주에 타격 PA와 투구 BF가 모두 기록되면 **그 주 경기 피로의 20%**를 주간 종료 시 한 번 추가한다. 훈련 피로에는 가산하지 않으며 회복·벤치·한쪽만 출전한 주에는 가산하지 않는다.
- 기존 일반 포지션 전환 이벤트 P06은 겸업 선수에게 새로 제안하지 않는다.

## 13. 겨울 랜덤 전학 제안 — S02

전학 제안은 겸업 조건과 별개다. 고1 겨울·고2 겨울의 **12월에 각각 한 번 30%**를 판정한다. 실패해도 그 겨울에는 재판정하지 않으며, 두 번 모두 제안을 못 받을 확률은 **49%**다. 제안을 한 번 받으면 수락·거절과 관계없이 이후 다시 제안하지 않는다. 고3 겨울에는 제안하지 않는다.

- 현재 학교를 제외한 전력 상위권 학교와 다음 학년 포지션 경쟁이 적은 학교를 각각 한 곳 제시한다. 화면의 전력은 현재 로스터 기준이며 경쟁 능력은 다음 학년에 남는 해당 포지션 선수의 최고 역할 능력이다. 실제 출전은 보장하지 않는다.
- 양쪽 OVR 55 이상인 선수에게만 겸업 검토 문구를 표시한다. 전학 수락만으로 겸업을 부여하지 않으며, 감독의 별도 S01 제안으로 수락해야 한다. 이미 수락한 겸업은 전학해도 유지된다.
- 수락하면 **다음 해 1월 1일 합류를 예약**한다. 현재 시즌 기록을 기존 학교에 보관한 뒤 새 학년·새 학교로 이동하며, 합류 결과를 보여주며, 확인 후 자동 진행 설정에 따라 이어간다.
- 선수 ID·능력치·재능·평판·기록·훈련 설정을 유지한다. 기존 학교 팀 성적은 옮기지 않는다. NPC를 맞교환하지 않으며 전체 선수 수는 유지한다. 전학으로 학교별 인원은 달라질 수 있다.
- 전력 상위권 학교는 주 분야 핵심 능력 중 가장 낮은 하나에 **정상 훈련 3주분**의 코칭 효과를 준다. 재능·성장 둔화·상한을 적용하며 5% 각성 시 6주분과 공통 각성 최소분 중 큰 값으로 계산한다. 포지션 경쟁이 적은 학교는 별도 능력 상승 없이 경쟁 환경이 바뀐다.
- 합류 시 피로 **+3**, 첫 **실제 훈련 참여 2주**는 훈련 성장량 **90%**. 비시즌·회복으로 훈련하지 않은 주는 적응 주수를 소진하지 않는다. 재능 공개 경험은 실제 훈련 시간대로 쌓으며 이벤트 보상 기준량에는 적응 계수를 곱하지 않는다.
- 거절에는 능력·평판·피로 페널티가 없다. 선택 전에는 일반 이벤트와 동일하게 효과 수치·확률을 숨긴다. 학교의 현재 전력·경쟁 상황은 진로 판단 정보로 보여준다.
- 연도별 개인 기록에는 그 시즌의 학교명을 보관한다. 대시보드에는 합류 예약과 남은 적응 주수를 표시한다.
