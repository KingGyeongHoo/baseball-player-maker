# 투구·타격 손

선수 생성 시 손잡이를 무작위로 정한다. 고교 최초 선수·신입생, 대학·프로 NPC, 프로 신인 및 직접 시작 선수가 같은 규칙을 사용한다. 기존 저장의 손잡이는 다시 추첨하지 않는다. 손잡이가 없던 예전 선수는 우투우타로 표시한다.

- 투구 손은 우투 70%, 좌투 30%. 포수·2루수·3루수·유격수는 우투로 생성한다.
- 타격 손은 우타 45%, 좌타 45%, 양타 10%. 투구 손과 독립적으로 추첨한다.
- 좌투 선수는 포수·2루수·3루수·유격수 등록 및 전환이 불가하다. 전환·겸업 제안에서도 제외한다. 좌투 센터라인 전환은 중견수로 배정한다.
- 좌투 투수는 고교 평판의 투수 분야 점수에 5%를 가산하며, 고교·프로 선발 경쟁에서 투수 기본 평가에 5%를 가산한다. 타격 분야와 능력치·OVR에는 이 보너스를 적용하지 않는다. 프로의 평판 없는 평가 체계와 실제 기록·WAR는 유지한다.
- 양타는 생성 컨택 1.2배, 컨택 훈련·이벤트 성장 속도 1.2배다. 능력치 상한 100 및 기존 성장 둔화는 적용한다. 우타·좌타 사이에는 능력 보정이 없다.

규칙은 `lib/sim/handedness.ts`, 포지션 제한은 `lib/sim/position-eligibility.ts`에서 관리한다. 손잡이는 능력치·이름·후속 선수의 생성 난수 흐름에 영향을 주지 않는 선수별 전용 시드로 추첨한다.
