# 로스터 주전 표시와 드래프트

v0.6.1 기반 · 최종 갱신: 2026-11-06 · 고교 구단 순서 연도별 추첨 반영

평가 체계의 조사·개선 제안은 [고교 스카우팅·평가 리서치](high-school-scouting-evaluation.md)와 [프로 스카우팅·평가 리서치](pro-scouting-evaluation.md)를 참고한다. 두 문서의 평가 자료층·리포트·계산은 scouting-v1으로 적용했다. 실제 평판은 [역할 기량·보정 성과 기반](reputation-evaluation.md)으로 교체했다. 드래프트 80:10:10 합산 비중은 유지하며 새 평판이 지명 순위에 반영된다. 프로 등록·계약의 독립 모델 교체는 비교 단계다.

## 주전·후보

- 야수·지명타자 9자리(C·1B·2B·3B·SS·LF·CF·RF·DH)에 각 1명, 선발·중간계투·마무리에 각 1명을 선정한다. 정상 로스터는 주전 12명이며 나머지는 후보다.
- 포지션 출전 자격과 해당 역할의 기본 능력 점수로 선정한다. 동점은 선수 ID로 정한다. 같은 선수에게 두 자리를 주지 않는다. 겸업 선수도 주전 인원에는 한 번만 센다.
- 당일 피로·부상·휴식은 경기 명단에 반영되며 주전 딱지를 바꾸지 않는다. 이는 학교 내 능력 기준의 주전 구분이다. 성장·진급·전학 등 로스터나 능력이 바뀌면 재계산한다.
- 로스터 이름 옆의 MY를 주전(옅은 금색 `#f5e8bf`)·후보(회색 `#e9ecf0`) 딱지로 바꿨다. 내 선수는 배경색으로 표시하며 다른 선수 상세를 선택해도 유지한다.
- 검색·정렬 시에도 해당 학교의 전체 로스터로 선정한다. 검색 결과 안에서 새로 주전을 뽑지 않는다. 주전·후보 배지는 우리 학교 목록에 표시한다.
- 팀 전력도 같은 주전 구분을 사용해 주전 1·후보 0.5를 적용한다. 30명 로스터의 가중치 합은 21이다. 이전 선발 3·중간 2·마무리 1의 투수 6명 기준은 교체했다.

## 전국 목록의 예상 지명 라운드

- 전국 선수 목록은 주전·후보 대신 해당 연도 고3 중 예상 지명 선수에게 `n라운더 예상` 배지를 표시한다. 고1·고2와 미지명 예상 선수에게는 붙이지 않는다.
- 1라운더는 금색, 2라운더는 은색, 3라운더는 동색, 4라운더부터는 회색이다. 내 선수는 기존 배경색으로 구분한다.
- 기존 지명 계산을 복제한 RNG로 실행해 예상 전체 90~110명의 라운드를 구한다. TOP10 밖의 선수도 예상 지명 라운드가 표시되며 조회가 실제 RNG·결과에 영향을 주지 않는다.
- 드래프트 종료 뒤 결과 확인을 누르면 실제 결과의 `n라운더 지명` 배지로 표시한다. 공개 전에는 실제 지명 배지를 숨긴다.
- [라운드 배지 검증](../tests/roster-draft-badge.test.mjs)에서 전체 예상과 실제 계산 일치·고3 제한·RNG 보존·1/2/3/4 이상 색상 클래스와 종료 문구를 확인한다.

## 시즌 중 예상 드래프트 TOP10

- 현재 연도의 고3 선수가 대상이다. 내 선수의 졸업 연도와 구분하며 고1·고2 플레이 중에도 그 해 고3의 예상을 보여준다.
- 실제 지명과 같은 평판 80%·재능 10%·구단 적합도 10%로 1~10순위를 예상한다. OVR TOP10과는 다른 목록이다.
- 선수·학교·포지션·예상 구단·평판·평가 점수를 표시한다. 현재 능력과 평판으로 평가하며 시즌 진행에 따라 달라진다.
- 조회 시 RNG를 복제해 계산한다. 실제 RNG·선수·기록·지명 결과를 바꾸지 않으며, 같은 상태의 예상 첫 10명은 같은 상태에서 지명했을 때의 첫 10명과 같다.

## 고교 드래프트의 연도별 구단 순서

중간계투·마무리를 **불펜으로 묶는 것은 고교 드래프트 결과표와 지명 상세의 표시뿐**이다. 선수 생성·현재 포지션·평가·경기 운용·기록에서는 중간계투(RP)와 마무리(CP)를 구분한다. 내부 지명 보직과 저장 데이터를 표시 때문에 합치지 않는다.

프로 커리어에서 새 고교 선수를 지명할 때는 실제 구단별 현재 포지션 부족분을 먼저 채우며 지명할 때마다 수요를 줄인다. 신인 전체를 확보한 다음 신인이 채운 자리까지 고려해 기존 잉여 선수를 방출한다. [통합 2군·FA·신인 처리](pro-farm-and-fa.md)를 참고한다.

- 고교 드래프트의 구단 순번 1~10은 **커리어 시드와 해당 시즌 연도**를 바탕으로 Fisher–Yates 방식으로 추첨한다. 고정된 구단 배열 순서를 매년 그대로 쓰던 방식에서 변경했다.
- 한 번 정해진 해당 연도의 순서는 모든 라운드에서 같다. 지명을 마친 구단은 이후 라운드에서 건너뛰며 다른 구단의 순번을 다시 매기지 않는다.
- 순서 계산은 별도로 파생한 난수 상태를 사용하므로 실제 `rngStates`를 소비하지 않는다. 예상 조회, 훈련·성적 변화, 선수 배열 순서, 현재 드래프트 RNG의 진행 상태가 같은 연도의 구단 순번을 바꾸지 않는다.
- 연도나 커리어 시드가 바뀌면 그 조합의 순서를 계산한다. 다른 연도에 같은 순서가 우연히 나올 가능성을 금지하는 규칙은 아니다.
- 고정되는 것은 **구단이 지명하는 차례**다. 선수의 능력·평판·구단 적합도가 달라지면 같은 차례에서도 예상 지명 선수와 예상 소속 구단은 달라질 수 있다.
- 총 지명 인원·구단별 인원 배분·선수 선택에는 기존 드래프트 계산을 사용한다. 구단 순서 추첨이 실제 RNG를 소비하지 않는다는 설명을 실제 드래프트 전체가 난수를 사용하지 않는다는 뜻으로 해석하지 않는다.
- 프로 커리어 중 새로 합류하는 신인 드래프트는 **전년도 프로 성적 역순**을 유지한다. 이 고교 추첨을 프로 신인 순서에 다시 적용하지 않는다.

구현은 [구단 순서 계산·라운드 편성](../lib/sim/draft.ts)의 `draftClubOrder`와 `draftSlots`를 따른다.

## 지명일 결과

- 당일 지명을 한 번 계산하고 진행을 멈춘다. 드래프트 페이지의 **결과 확인**을 눌러야 지명표·고교 커리어·OVR TOP10과 다음 진로가 보인다. 확인은 결과·RNG를 다시 추첨하지 않으며 탭 이동 뒤에도 공개 상태를 유지한다.
- THE NEXT CHAPTER를 결과 요약 안으로 합치고 오른쪽에 다음 버튼을 둔다. 지명은 **프로 입단**, 신고선수 제안을 받은 미지명은 **신고선수 입단 / 은퇴**, 나머지 미지명은 **은퇴**다. 입단은 같은 창에서 프로 시즌을 시작하고 은퇴는 생성 화면으로 돌아간다.
- 신고선수는 지명 최저 평가와 중립 수요 기준 2점 이내 또는 개별 능력 전국 TOP5일 때 제안한다. 성장 90%·출전 불이익으로 시작해 2군 경기 성과로 정식 전환한다. 자세한 조건은 [프로 라이프](pro-life.md)에 정리했다.

- 총원을 매년 **90~110명 중 정수 하나로 균등 추첨**한다. 기존 고3 인원의 10% 고정 지명 규칙을 교체했다.
- 10개 구단 모두 9명까지 지명하고, 추가 인원을 임의의 구단에 한 명씩 배분한다. 구단별 최대 13명이다. 따라서 총원 범위와 구단별 9~13라운드가 함께 유지된다.
- 표의 행은 라운드, 열은 **그해 추첨된 구단 순번 1~10**이다. 각 라운드에서 지명 순번은 같은 구단을 가리킨다. 구단이 지명을 마친 다음 라운드는 ‘지명 종료’로 표시하고 이후 다시 지명하지 않는다.
- 결과표의 구단 머릿글은 저장된 지명 결과의 `club`·`slot`으로 복원한다. 현재 연도의 순서로 다시 추첨하지 않으므로 추첨 도입 전 고정 순서의 결과와 과거 보관 결과도 당시 순서로 표시한다. 아주 오래된 `round`·`slot` 없는 결과는 기존의 라운드당 10명 전제로 전체 순위에서 환산하는 표시 호환을 유지한다.
- 표는 최소 10라운드를 표시하며 필요한 해에는 11~13라운드를 추가한다. 실제 전체 순위는 종료 구단을 건너뛰어 1부터 총원까지 연속 부여한다. 종료 칸은 지명 인원에 세지 않는다.
- 내 선수 셀을 배경색으로 표시한다. 선수를 누르면 전체 순위·라운드·순번과 평판·재능·적합도·지명 점수를 모달에서 보고 개인 기록으로 이동할 수 있다.
- 결과 표를 넓게 먼저 보여주고 고교 커리어를 아래에 둔다. 커리어의 입학 이후 성장 상세는 접어서 열 수 있다. OVR TOP10 버튼은 실제 드래프트 결과 제목 오른쪽에 유지한다.
- 작은 화면에서는 표 내부를 좌우·위아래로 스크롤하며 열 제목과 라운드 열을 고정한다. 페이지 자체가 가로로 넘치지 않게 한다.
- 인원 배분·선수 선택의 재현성은 기존 draft RNG 스트림으로, 고교 구단 순서는 커리어 시드·연도로 유지한다. 다른 RNG·능력·기록을 변경하지 않고 동일 선수를 중복 지명하지 않는다. 테스트용으로 후보가 총원보다 적으면 실제 후보 수까지만 지명한다.

### 초기 v0.6.1 검증 기록

- 전체 120개 테스트 통과. 80개 시드의 지명 결과에서 90·110명 양 끝값, 구단별 9·10·11·12·13명, 중복 없는 순차 지명·종료 후 재진입 금지를 확인했다. 예상을 조회해도 RNG가 변하지 않고 실제 첫 10명과 같음을 확인했다.
- 실제 브라우저에서 주전 12·후보 18, 딱지 색과 내 선수 배경 유지, 평소 예상 10명, 총 105명의 13라운드 결과와 지명 평가 모달, 모바일 내부 스크롤을 확인했다.
- lint·프로덕션 빌드 통과. 실제 빌드된 Turbopack Worker에서도 지명일 종료·90~110명·라운드/순번 데이터가 순차 엔진과 같은지 확인했다.
