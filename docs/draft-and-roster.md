# 로스터 주전 표시와 드래프트

v0.6.1 · 2026-11-05

## 주전·후보

- 야수·지명타자 9자리(C·1B·2B·3B·SS·LF·CF·RF·DH)에 각 1명, 선발·중간계투·마무리에 각 1명을 선정한다. 정상 로스터는 주전 12명이며 나머지는 후보다.
- 포지션 출전 자격과 해당 역할의 기본 능력 점수로 선정한다. 동점은 선수 ID로 정한다. 같은 선수에게 두 자리를 주지 않는다. 겸업 선수도 주전 인원에는 한 번만 센다.
- 당일 피로·부상·휴식은 경기 명단에 반영되며 주전 딱지를 바꾸지 않는다. 이는 학교 내 능력 기준의 주전 구분이다. 성장·진급·전학 등 로스터나 능력이 바뀌면 재계산한다.
- 로스터 이름 옆의 MY를 주전(옅은 금색 `#f5e8bf`)·후보(회색 `#e9ecf0`) 딱지로 바꿨다. 내 선수는 배경색으로 표시하며 다른 선수 상세를 선택해도 유지한다.
- 검색·정렬 시에도 해당 학교의 전체 로스터로 선정한다. 검색 결과 안에서 새로 주전을 뽑지 않는다. 주전·후보 배지는 우리 학교 목록에 표시한다.
- 팀 전력도 같은 주전 구분을 사용해 주전 1·후보 0.5를 적용한다. 30명 로스터의 가중치 합은 21이다. 이전 선발 3·중간 2·마무리 1의 투수 6명 기준은 교체했다.

## 전국 목록의 예상 지명 라운드

- 전국 선수 목록은 주전·후보 대신 해당 연도 고3 중 예상 지명 선수에게 `n라운더 예상` 배지를 표시한다. 고1·고2와 미지명 예상 선수에게는 붙이지 않는다.
- 1라운더는 금색, 2라운더는 은색, 3라운더는 동색, 4라운더부터는 회색이다. 내 선수는 기존 배경색으로 구분한다.
- 기존 지명 계산을 복제한 RNG로 실행해 예상 전체 90~110명의 라운드를 구한다. TOP10 밖의 선수도 예상 지명 라운드가 표시되며 조회가 실제 RNG·결과에 영향을 주지 않는다.
- 드래프트 종료 뒤 결과 확인을 누르면 실제 결과의 `n라운더 지명` 배지로 표시한다. 공개 전에는 실제 지명 배지를 숨긴다.
- [라운드 배지 검증](../tests/roster-draft-badge.test.mjs)에서 전체 예상과 실제 계산 일치·고3 제한·RNG 보존·1/2/3/4 이상 색상 클래스와 종료 문구를 확인한다.

## 시즌 중 예상 드래프트 TOP10

- 현재 연도의 고3 선수가 대상이다. 내 선수의 졸업 연도와 구분하며 고1·고2 플레이 중에도 그 해 고3의 예상을 보여준다.
- 실제 지명과 같은 평판 80%·재능 10%·구단 적합도 10%로 1~10순위를 예상한다. OVR TOP10과는 다른 목록이다.
- 선수·학교·포지션·예상 구단·평판·평가 점수를 표시한다. 현재 능력과 평판으로 평가하며 시즌 진행에 따라 달라진다.
- 조회 시 RNG를 복제해 계산한다. 실제 RNG·선수·기록·지명 결과를 바꾸지 않으며, 같은 상태의 예상 첫 10명은 같은 상태에서 지명했을 때의 첫 10명과 같다.

## 지명일 결과

- 당일 지명을 한 번 계산하고 진행을 멈춘다. 드래프트 페이지의 **결과 확인**을 눌러야 지명표·고교 커리어·OVR TOP10과 다음 진로가 보인다. 확인은 결과·RNG를 다시 추첨하지 않으며 탭 이동 뒤에도 공개 상태를 유지한다.
- THE NEXT CHAPTER를 결과 요약 안으로 합치고 오른쪽에 다음 버튼을 둔다. 지명은 **프로 입단**, 신고선수 제안을 받은 미지명은 **신고선수 입단 / 은퇴**, 나머지 미지명은 **은퇴**다. 입단은 같은 창에서 프로 시즌을 시작하고 은퇴는 생성 화면으로 돌아간다.
- 신고선수는 지명 최저 평가와 중립 수요 기준 2점 이내 또는 개별 능력 전국 TOP5일 때 제안한다. 성장 90%·출전 불이익으로 시작해 2군 경기 성과로 정식 전환한다. 자세한 조건은 [프로 라이프](pro-life.md)에 정리했다.

- 총원을 매년 **90~110명 중 정수 하나로 균등 추첨**한다. 기존 고3 인원의 10% 고정 지명 규칙을 교체했다.
- 10개 구단 모두 9명까지 지명하고, 추가 인원을 임의의 구단에 한 명씩 배분한다. 구단별 최대 13명이다. 따라서 총원 범위와 구단별 9~13라운드가 함께 유지된다.
- 표의 행은 라운드, 열은 고정된 구단별 순번 1~10이다. 각 라운드에서 지명 순번은 같은 구단을 가리킨다. 구단이 지명을 마친 다음 라운드는 ‘지명 종료’로 표시하고 이후 다시 지명하지 않는다.
- 표는 최소 10라운드를 표시하며 필요한 해에는 11~13라운드를 추가한다. 실제 전체 순위는 종료 구단을 건너뛰어 1부터 총원까지 연속 부여한다. 종료 칸은 지명 인원에 세지 않는다.
- 내 선수 셀을 배경색으로 표시한다. 선수를 누르면 전체 순위·라운드·순번과 평판·재능·적합도·지명 점수를 모달에서 보고 개인 기록으로 이동할 수 있다.
- 결과 표를 넓게 먼저 보여주고 고교 커리어를 아래에 둔다. 커리어의 입학 이후 성장 상세는 접어서 열 수 있다. OVR TOP10 버튼은 실제 드래프트 결과 제목 오른쪽에 유지한다.
- 작은 화면에서는 표 내부를 좌우·위아래로 스크롤하며 열 제목과 라운드 열을 고정한다. 페이지 자체가 가로로 넘치지 않게 한다.
- 재현성은 기존 draft RNG 스트림으로 유지한다. 다른 RNG·능력·기록을 변경하지 않고 동일 선수를 중복 지명하지 않는다. 테스트용으로 후보가 총원보다 적으면 실제 후보 수까지만 지명한다.
