# Baseball Life

DOCX v0.3 기획·구현 명세를 바탕으로 만들고 사용자 요청을 `baseball_balance_v0_4.json`(현재 v0.6.1)에 반영한 야구 육성 시뮬레이션입니다. `design.md`의 네이비·화이트, KBO 서체, 작은 모서리와 기록표 스타일을 적용했습니다.

전체 구현 범위와 버전별 변경 이력은 [history.md](history.md), 대회 일정의 참고 출처와 게임 적용 규칙은 [docs/season-calendar.md](docs/season-calendar.md)에 정리했습니다.

v0.6.1부터 프로 라이프를 기본 앱에 통합했습니다. 고3 드래프트 종료 뒤 **결과 확인**을 누르면 결과표와 고교 커리어가 나타나며, 결과 요약 오른쪽에서 다음 진로를 선택합니다. 지명 선수는 **프로 입단**, 아쉽게 미지명된 유망주는 **신고선수 입단 / 은퇴**, 그 밖의 미지명 선수는 **은퇴**를 선택합니다. 입단하면 같은 창에서 기록과 능력치를 이어 프로 신인 시즌을 시작하고, 은퇴하면 첫 화면으로 돌아갑니다. [프로 샘플 체험](http://localhost:3000/pro)도 제공합니다.

신고선수 제안은 지명권과 평가 2점 이내 또는 개별 능력 전국 TOP5일 때 주어집니다. 성장은 90%, 출전 경쟁에 불이익이 있고, 2군 경기 성과를 달성하면 정식 선수 전환 이벤트로 성장·출전 제한이 풀립니다. 프로 1·2군과 신인 정규 시즌의 규칙은 [프로 라이프 문서](docs/pro-life.md)에 정리했습니다. 이전 테스트·대학 경로는 엔진에 남아 있으나 현행 고교 종료 화면에서는 제공하지 않습니다.

고교 v0.5.8에서는 점수를 정수 부분으로 표시하고, 효과를 ‘아주 조금 상승~매우 크게 상승 / 하락’으로 안내합니다. 훈련 집중 이벤트에서 5티켓 1주분 성장 또는 현재 피로의 10~20% 휴식을 선택합니다. 전국 목록에는 고3 예상 지명 선수의 라운드 배지를 금·은·동·회색으로 표시하며 우리 학교의 주전·후보 배지는 유지합니다.

## 실행

```sh
npm install
npm run dev
```

개발 중 기본 접속 주소는 [http://localhost:3000](http://localhost:3000)입니다. 수정 중에는 개발 서버를 유지합니다. `npm start`로 실행한 서버는 `npm run build`로 산출물이 바뀐 뒤 재시작해야 합니다. 이전 서버가 이전 JavaScript·CSS 파일명을 계속 참조하면 페이지가 열리지 않을 수 있습니다. 별도 검증용 서버는 검증 후 종료합니다.

`http://localhost:3000`에서 이름을 입력하고 타자·투수 유형을 선택합니다. 타자는 야구장 위 수비 위치를, 투수는 와인드업·셋포지션·역동적인 투구 실루엣 카드를 눌러 포지션을 고릅니다. 시작하면 학교와 능력치를 무작위로 배정합니다. 시작 전 능력치 미리보기·재추첨·시드 입력은 제공하지 않습니다. 서버 인증과 저장 기능은 없으며 새로고침하면 현재 플레이가 초기화됩니다.

## 플레이

- 선수 생성: 선택한 투수·타자 분야와 공통 능력은 기존 무작위 생성 로직을 유지합니다. 반대 분야는 평균 15 수준으로 생성하며, 0.1% 확률로 반대 분야도 기존 분포에서 별도로 추첨합니다. 이 경우에도 양쪽이 모두 평균 이상일 때만 뛰어난 투타 선수로 나타납니다. 플레이어·NPC·진급 후 신입생에 공통 적용하며 이미 생성된 선수는 재배정하지 않습니다.
- 종합 OVR: 투수 OVR + 타자 OVR의 합계이며 최대 200입니다. 대시보드·프로필·로스터·성장 그래프·드래프트 OVR TOP10에 같은 기준을 사용합니다. 개별 투수·타자 OVR과 평판은 최대 100이며 평판의 능력 기여는 기존 주 역할 OVR을 사용합니다.
- 훈련 센터: 약한 7·보통 10·강한 13장, 능력별 0~5장을 배분합니다. 별도 회복 타입은 빼고 약한 훈련이 회복을 겸합니다. 약한 훈련은 피로가 천천히 줄고, 보통은 천천히, 강한 훈련은 빠르게 쌓입니다. 큰 남색 남은 티켓 표시·배분 막대·초과 선택 방지와 현재 배분 유지를 훈련 센터·모달에 같이 적용합니다.
- 기본 성장: 실제 훈련일에는 포지션과 관계없이 투수·타자 기술 능력 7종 모두 기본 성장 0.03/주를 받으며, 티켓을 넣으면 더 빨리 성장합니다. 분야별 재능·성장 둔화·실제 참여량을 반영합니다. 항목 티켓 0장도 기본 성장은 있지만 전체 티켓 0장·부상·비시즌에는 훈련하지 않습니다. 플레이어·NPC와 훈련량 이벤트 보상에 같은 기준을 적용합니다.
- 훈련 항목은 투수 능력치(구속·제구·변화구), 타자 능력치(컨택·파워·스피드·수비), 공통 피지컬 순서로 구분합니다. 훈련 센터와 훈련 설정 모달에서 투수 항목을 위에 표시합니다.
- 주간 진행: Web Worker에서 날짜순으로 7일을 계산하되, 이벤트가 발생하면 해당 날짜·훈련 또는 타석 직전에서 멈춥니다. 선택 후 결과를 확인하고 계속 진행하기를 누르면 같은 주의 남은 일정을 이어갑니다. 진행 중인 주를 마친 뒤 훈련 설정을 변경할 수 있습니다. 요청 ID와 잠금으로 중복 실행을 막고 실패·시간 초과 시 요청 전 상태를 유지합니다.
- 자동 진행: 현재 설정으로 주간 계산을 이어가며 새 부상·강제 휴식·역할 제안·커리어 이벤트·드래프트·계산 오류 시 멈춥니다. 선택 결과를 확인해도 자동 재개하지 않습니다. 감독의 포지션 제안은 이벤트에서 처리하며 기존 대기 제안과 중복되지 않습니다. 이미 부상 중이라면 다시 자동 진행해 회복 기간을 보낼 수 있습니다.
- 피로 확인: 체력·회복력 50, 경기 없는 정규 주, 전체 티켓 사용, 피로 30 시작 기준 약한 훈련 -3.6·보통 +1.85·강한 +6.65입니다. 경기 피로는 별도로 더합니다. 훈련 설정에서 발생량·회복 가능량·현재 대비 변화·종료 예측을 확인합니다. 부상·한계 피로에 따른 강제 휴식은 유지하며 이때만 활동을 멈추고 비율 회복합니다. 상세 수식과 실측값은 [훈련 문서](docs/training.md)에 기록했습니다.
- 대시보드: 큰 상단 영역에 선수 프로필(학교·이름·포지션·우투우타·OVR·투타 OVR), 피로, 평판, 팀 정보(이름·전력·시즌 성적)를 모았습니다. 아래는 왼쪽 시즌 기록→일정, 오른쪽 상세 능력치로 배치합니다. 일정 제목 옆에 월을 표시하며 월을 걸치는 주는 두 월을 함께 표시합니다. 상세 능력치의 훈련 설정 버튼으로 모달을 열어 타입·티켓 배분을 변경합니다. 저장하면 훈련 센터와 같은 설정에 반영되며 취소하면 원래 배분을 유지합니다. 훈련 요약·주간 리포트·최근 경기는 대시보드에서 제거했고 성장 그래프는 훈련 센터 맨 아래에 표시합니다.
- 훈련 부상: 피로가 낮아도 실제 훈련일에는 하루 0.05%의 기본 부상 확률이 있습니다. 피로 부상 위험과 독립 결합하며 회복·비시즌·0티켓 훈련에는 기본 확률을 적용하지 않습니다. 새 부상은 자동 진행을 멈춥니다.
- 커리어 이벤트: [baseball-events.md](docs/baseball-events.md)의 훈련 10·관계자 8·대회 6·경기 중 6종을 적용했습니다. 선택 전에는 상황과 행동만 표시하며 효과·확률은 숨깁니다. 선택 후 결과를 추첨하고 실제 능력·평판·피로·부상·포지션·한 타석 보정을 표시합니다. 일반 성장은 티켓 5개를 둔 정상 훈련 3~4주분을 일별 공식으로 계산하며 상승 결과 전체에 한 번 5% 각성을 판정합니다. 일반 이벤트는 최소 2주 간격·주간 35% 기회·주당 최대 1회, 최근 5종 반복을 피합니다. 국가대표는 별도로 고2·고3의 전체 평판 TOP23 자격을 확인하고 각 학년 한 번 제안합니다. 센터는 학년당 한 번, 대회는 실제 참가·생존 중 대회당 한 번, 경기 중 선택은 실제 출전한 경기당 한 번입니다.
- 국가대표·큰 성장: 소집 수락은 MVP 5%·인상적인 활약 23.75%·부상 23.75%·일반 경험 47.5%이며, MVP를 제외한 95%의 비율은 1:1:2입니다. 거절의 25%·25%·50%는 유지합니다. MVP는 핵심 능력 8주분·평판 보정 +10, 인상적인 활약은 6주분, 센터 대성공은 전체 11능력 각각 8주분입니다. 각성은 기본 훈련 주수를 2배로 하되 최대 12주분으로 다시 계산합니다. 큰 보상도 원래 성장 둔화를 적용하며 고정 +8·+12·+24로 능력 구간을 건너뛰지 않습니다.
- 팀 전력: 야수·지명타자 포지션별 1명과 선발·중간계투·마무리 각 1명, 총 12명에게 주전 가중치 1, 후보에게 0.5를 적용합니다. 로스터 딱지와 같은 선정을 사용하며 당일 부상·휴식은 실제 출전 명단에서 따로 반영합니다. 타격·수비·투수 전력, 전국 순위와 선수별 가중 점수를 확인합니다.
- 투타 겸업: 시즌 중 양쪽 OVR이 각각 55 이상인 상태를 2주 유지하면 현재 학교 감독이 제안합니다. 고1·고2·고3 드래프트 전까지 가능하며, 수락 시 `선발/2루수`처럼 표시합니다. 실제 타격·투구 출전으로 평판 최대 +3, 양쪽 모두 출전한 주에는 경기 피로 20%가 추가됩니다. 완료된 팀 경기마다 배정 분야를 번갈아 바꾸며 출전은 경쟁·컨디션에 따라 결정됩니다.
- 전학: 고1·고2 겨울 12월마다 한 번 30%를 판정합니다. 졸업까지 제안을 못 받을 확률은 49%이며 한 번 제안받으면 반복하지 않습니다. 상위 전력 학교·포지션 경쟁이 적은 학교·잔류 중 선택하며, 수락하면 다음 학년 1월 1일 합류합니다. 상위 전력 학교는 핵심 능력 하나에 3주분의 코칭 효과(각성 시 6주분), 공통으로 피로 +3과 실제 훈련 참여 첫 2주의 성장 효율 90%를 적용합니다. 능력·평판·개인 기록은 보존하고 시즌별 학교명을 기록합니다. 전학과 겸업 제안은 별개입니다.
- 주전·후보 딱지: 이름 옆의 MY를 옅은 금색 주전·회색 후보로 바꿨습니다. 주전은 야수·DH 포지션별 1명과 선발·중간계투·마무리 각 1명입니다. 내 선수 배경색은 다른 선수 상세를 눌러도 유지합니다.
- 선수·로스터: 100팀·3,000명의 학년·포지션·기본/유효 능력·평판·재능 공개를 확인합니다. 목록의 OVR은 투수 OVR과 타자 OVR의 합계이며, OVR·투수 OVR·타자 OVR·평판 네 기준으로만 내림차순 조회합니다. 기본 정렬은 OVR순입니다. 포지션과 관계없이 투수·타자·공통 능력치와 출전 자격을 함께 표시하며 이름·학교 검색을 지원합니다. 역할 전환 후에도 기존 출전 자격을 유지하므로 경기별 투타 겸업이 가능합니다.
- 평판: 현재 주 역할 OVR 60% + 경기 성과 평가 40% + 이벤트 보정을 0~100으로 제한합니다. 출전 전 성과는 중립 50점으로 평가하므로 OVR에 따른 기본 평판이 있습니다. 마지막 성과 평가는 진급·역할 전환 후에도 유지하며 새 경기 기록에 따라 갱신합니다. 훈련이나 이벤트로 OVR이 바뀌면 평판에도 반영합니다. 최종 평판은 성과 백분위 자체가 아니므로 상위 몇 %라는 표시는 사용하지 않습니다.
- 개인 기록: 대시보드와 경기 상세에는 투수·타자 기록을 함께 표시합니다. 상단 탭에서 나의 연도별 타격·투구 기록, 시즌별 필터와 통산 합계를 확인합니다. 대시보드의 연도별 기록 및 드래프트의 상세 기록으로도 열 수 있습니다. 로스터에서 선수를 선택한 뒤 연도별 기록을 누르면 다른 선수의 기록도 열립니다. 시즌이 바뀌면 지난 기록을 보존하고 현재 시즌을 별도 행으로 표시합니다. 통산 타율·OPS·ERA·WHIP는 합산한 실제 기록으로 다시 계산합니다.
- 일정·기록: 전·후반기 주말리그와 이마트배·황금사자기·청룡기·대통령배·봉황대기를 진행합니다. 조별 순위로 참가 팀을 정하고, 전국대회는 부전승·진출·탈락·우승과 라운드별 대진을 반영합니다. 자동 경기 스코어·이닝 기록·나의 경기 기록을 확인합니다. NPC 감독은 경기 일정과 피로에 맞춰 일별 회복을 분산합니다.
- 드래프트: 평소에는 해당 연도 고3 선수의 예상 지명 1~10위를 표시합니다. 기존 평판 80%·재능 10%·적합도 10%로 계산하며 조회가 RNG나 결과를 바꾸지 않습니다. 실제 지명일에는 총 90~110명을 무작위로 정하고 구단별 9~13라운드까지 지명합니다. 결과는 라운드가 행, 순번 1~10의 구단이 열인 표로 표시하고 종료 구단은 지명 종료로 표시합니다. 선수 셀에서 지명 평가·개인 기록을 확인하며 내 선수는 배경색으로 강조합니다. 결과 제목 오른쪽의 OVR TOP10 버튼은 유지합니다. 자세한 규칙은 [드래프트·로스터 문서](docs/draft-and-roster.md)에 정리했습니다.

일정은 **2026 실제 개최 기간을 참고한 게임용 편성**입니다. 2027년 이후 공식 확정 일정은 아니며 학교·선수·조 편성·참가 기준·세부 대진은 가상입니다. [일정 출처와 게임 규칙](docs/season-calendar.md)에 참고 자료와 적용 차이를 기록했습니다. 각 시즌 3월 1일 시작, 40주 평일 훈련, 9월 첫 월요일 가상 지명일을 사용합니다. 실제 통계에 맞춘 최종 밸런스가 아닙니다.

## 구조

- `lib/sim/types.ts`: 게임·선수·훈련·달력·경기·보고 데이터
- `lib/sim/engine.ts`: RNG 스트림, 선수 생성·성장·피로·평판·진급·지명과 시뮬레이션 공개 함수
- `lib/sim/week-engine.ts`, `lib/sim/match-engine.ts`: 날짜·선수·경기·타석별 계산과 직렬화 가능한 중단·재개 상태
- `lib/sim/worker.ts`: 주간 계산과 오류 응답
- `lib/sim/career-events.ts`, `event-catalog.ts`, `event-definitions.json`: 문서에서 가져온 30종 선택·분기와 역할별 효과
- `lib/sim/event-system.ts`: 발생 조건·반복 제한·국가대표·훈련량 보상·각성·결과 적용
- `lib/sim/career-opportunities.ts`: 시즌 중 겸업 제안·겨울 전학 판정·다음 학년 합류·적응 기간
- `scripts/generate-events.mjs`: 기획 문서의 표를 이벤트 JSON으로 변환. 표 변경 후 실행하며 30종·선택 수·확률 합을 검증합니다.
- `app/components/baseball-life.tsx`: 생성·대시보드·훈련·로스터·일정·결산 UI
- `app/components/player-setup.tsx`, `position-picker.tsx`: 이름·유형·구장 포지션·투수 카드 선택. 원본 PNG를 직접 쓰지 않고 구장은 벡터로 그렸으며 투수 이미지는 새로 생성했습니다.
- `lib/player-creation.ts`: 시작할 때만 새 난수를 받아 학교와 선수 생성. 내부 seed는 자동으로 생성하며 UI에 노출하지 않습니다. 엔진의 결정론 검증 경로는 유지합니다.
- `app/baseball.css`: 반응형 화면 스타일
- `baseball_balance_v0_4.json`: 현재 훈련 피로·회복·드래프트·NPC 계수와 역할 가중치. v0.3 JSON/XLSX는 원본으로 보존하며 현재 엔진과 자동 동기화하지 않습니다.
- `lib/sim/calendar.ts`: 일정 참고 자료, 조별 리그, 대회 참가와 토너먼트 진행
- `lib/team-strength.ts`: 예상 주전·후보 가중 전력과 전국 순위

기본 능력은 소수로 유지하며, 부상 저하·피로·성향을 별도로 적용합니다. 투구 기록은 이닝 소수가 아닌 아웃 수로 저장합니다. 재능은 실제 훈련 경험 10주/30주에 공개합니다. 경기 기록이 없으면 성과 평가는 중립 50점이며 OVR로 기본 평판을 산정합니다. 타율·OPS·ERA는 기록이 없으면 미평가로 표시합니다.

v0.5.5는 전체 113개 테스트, lint·프로덕션 빌드·실제 빌드된 Worker 검증을 통과했습니다. 새 14개 시나리오에서 고1~고3 겸업 제안, 2주 조건·거절 후 재제안 제한, 양쪽 실제 출전의 평판·피로, 경기 중단·재개, 겨울 한 번 판정·49% 미제안 분포, 전학 예약·합류·학교별 기록·적응 기간을 확인했습니다. Worker에서도 겸업 수락·재개와 전학 합류·재개의 순차 엔진 동등성을 확인했습니다. 실제 브라우저에서 고2 겸업·전학 모달과 자동 정지, 수락 뒤 포지션 표시, 새 학년 합류 결과와 390px 모바일 표시를 확인했습니다.

`npm test`는 결정론·입력 검증·성장 수식·피로 경계·확률·달력·Worker 계산 동등성·부상 복귀·경기 기록 불변식·역할 제안·3시즌 종료를 검사합니다.

v0.4.1 검증에서는 일반 엔진·일정·피로·전력 54개와 드래프트 4개 시나리오를 확인했습니다. 서로 다른 6개 생성 집단의 능력치/지명 Top 10 교집합은 9·10·7·8·9·9명이었고, 실제 3시즌 종료 시나리오에서는 10명이 겹쳤습니다. 이는 개별 검증 결과이며 모든 커리어의 지명 순서가 같다는 뜻은 아닙니다. 이전 v0.4.1 브라우저 검증의 강한 훈련 한 주 피로 43.0·이후 회복 주간 0.0은 이전 계수의 결과입니다. v0.4.2는 피로 누적을 그 1/10로 낮췄습니다.

`npm run test:balance`는 기본 100개 seed를 3시즌 진행하고 `test-results/balance.json`에 OVR, 재능별 성장, 부상일, 기록 분포, 지명/미지명 집단과 주간 계산 시간을 기록합니다. `BALANCE_SEEDS`, `BALANCE_WORKERS` 환경 변수로 실행 규모를 조정할 수 있습니다. 이 시간은 Node Worker 측정값이며 브라우저 성능 측정값은 아닙니다.

**이전 v0.3의 가상 연습경기·피로·드래프트 수식**으로 실행했던 100개 시드의 요약은 [validation/balance-v0.3.json](validation/balance-v0.3.json)에 보관했습니다. 총 13,200주·150,000경기·고3 선수 100,000명을 측정했으며 모든 커리어가 2029년 9월 3일에 종료되었습니다. 8개 Node Worker를 함께 실행한 환경에서 주간 계산 p95는 약 611ms였습니다. 일반 훈련을 유지한 플레이어 집단의 평균 부상일은 0일이므로 높은 피로 방침의 부상 분포는 별도 시나리오로 검증해야 합니다.

`npm run build` 후 `npm start`로 서버를 실행한 상태에서 `npm run test:build`를 사용하면 HTTP 페이지·정적 파일 응답과 **실제 빌드된 Turbopack Worker**의 성공·오류 응답, 순차 엔진과의 동등성을 검사합니다. Playwright로 실제 브라우저에서 선수 생성, 팀 전력, 모바일 가로 넘침, 회복 선택 시 8개 티켓 자동 초기화, 대회 화면을 확인했습니다.

간소화 범위: 최대 12이닝 무승부, 사구·실책·도루·병살·희생타·야수선택 없음. 같은 경기 투타겸업과 투수 개인 승·패·세이브, 프로 커리어는 후속 범위입니다. 전국대회는 12이닝 무승부일 때 추첨으로 진출 팀을 정하며, 리그 기록에는 무승부를 유지합니다.
